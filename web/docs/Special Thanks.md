# 🙏 Special Thanks

GeoChemistry Nexus exists because of support from the community.

## Contributors

Thank you to everyone who has taken part in this project through a GitHub Issue, a discussion, or email, including but not limited to:

* Reporting bugs and suggesting features
* Contributing code, testing, and documentation
* Sharing or jointly building templates such as discrimination diagrams and thermobarometers

* Taking part in multilingual localization, and more

Every contributor who has agreed to be listed in public will appear in the project contributor list. If you have a personal homepage or a related link, tell us and we will display it as well.

# Settings

The settings area is varied, and more personalization options will be added as features grow.

## General program settings

Settings fall into four parts: file paths, internationalization and personalization, message notifications, and other. The main settings are summarized below.

### 🌍 Language & appearance

- **Language**: Simplified Chinese, Traditional Chinese, English, German, Spanish, Japanese, Korean, Russian, French, and Portuguese are supported today.
- **UI scale**: Scale settings for screens of different resolutions. The default is usually fine.

:::info

If you want to help localize the software for your country, we warmly invite you to join the translation work. Most of the current translation was assisted by AI, so some parts may be inaccurate. Your help is very welcome, and we appreciate it.

:::

### 🗨️ Message notifications

- **Auto-close duration**: How long a message pop-up stays open while the software is running. Error and warning messages must be closed manually.

### ⚙️ Other

- **Launch with the system**: The software starts automatically when the system starts.
- **Check for updates automatically**: The software checks for updates when it starts.
- **How to exit**: The software can exit in two ways: quit directly, or minimize to the system tray. If you choose minimize to tray, right-click the tray icon and choose Exit to close the software.

## Plotting module settings

Plotting module settings apply specifically to features inside the plotting module, including but not limited to:

* Third-party program path configuration
* The default third-party program
* The default language loaded for diagrams
* Automatic updates of diagram templates and the classification structure

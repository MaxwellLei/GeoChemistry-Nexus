# 🌍 Introduction

**GeoChemistry Nexus is an integrated research platform for researchers in geochemistry, petrology, mineralogy, and economic geology.**

The software brings common research calculations—discrimination diagrams, geothermobarometry, EPMA mineral chemistry, CIPW norm calculation, and Niggli norm calculation—into one workspace. It reduces switching between separate programs and makes geological data processing, calculation, and visualization more continuous and efficient.

Through its cloud template ecosystem, GeoChemistry Nexus also supports ongoing updates, sharing, and reuse of diagram templates and calculation algorithms, so the tools can keep expanding into an open, flexible, and sustainable geoscience workspace.

**Get started with GeoChemistry Nexus in 3 minutes** ⏱️.

## Prerequisites 🛠️

**GeoChemistry Nexus currently supports Windows only.** Native macOS and Linux versions are not available yet.

- **Windows**: use Windows 7 or later
- **macOS / Linux**: there is no native build yet. You can try running GeoChemistry Nexus inside a Windows virtual machine, but compatibility and performance depend on that virtual machine.

### 🚀 Cross-platform plan

We are planning cross-platform support and will explore a migration based on `Avalonia UI`, so that macOS, Linux, and other operating systems can be supported over time.

## Get started 🚀

[Click here](https://github.com/MaxwellLei/GeoChemistry-Nexus/releases) to open the download page. Choose a suitable version and download the installer.

After the download finishes, follow the installation wizard. When installation succeeds, double-click `GeoChemistry Nexus.exe` to start the software and begin using it. 🖱️

### Software errors and feedback 💬

GeoChemistry Nexus is still under active development. As the developer, I will inevitably miss some cases or make mistakes in implementation. Undiscovered issues may remain in feature design, calculation logic, data processing, and interface interaction. I will do my best to keep the software reliable and the calculations accurate, but I cannot promise that it is free of errors in every situation.

If you find a bug, an abnormal calculation, an unreasonable result, or have a better feature suggestion, please report it through GitHub Issues. Every report and suggestion is an important reason GeoChemistry Nexus keeps improving.

**The software cannot improve without help from the people who use it. Thank you for your understanding, support, and participation!**

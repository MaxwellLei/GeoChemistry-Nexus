# 🙏 Besonderer Dank

GeoChemistry Nexus besteht dank der Unterstützung der Community.

## Mitwirkende

Dank gilt jeder Person, die über GitHub Issues, den Diskussionsbereich oder per E-Mail an diesem Projekt mitwirkt, einschließlich, aber nicht beschränkt auf:

* Melden von Fehlern und Vorschlagen von Funktionen
* Beitragen von Code, Tests und Dokumentation
* Teilen oder gemeinsames Erstellen von Vorlagen für Diskriminationsdiagramme, Geothermobarometer und Weiteres

* Mitwirken an der mehrsprachigen Lokalisierung und Weiteres

Alle Mitwirkenden, deren Nennung genehmigt und öffentlich ist, werden in das Verzeichnis der Projektmitwirkenden aufgenommen. Wenn Sie eine persönliche Seite oder einen zugehörigen Link haben, teilen Sie uns dies gern mit, damit wir ihn ebenfalls zeigen.

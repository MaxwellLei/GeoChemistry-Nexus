# 🙏 Agradecimientos

GeoChemistry Nexus existe gracias al apoyo de la comunidad.

## Colaboradores

Gracias a cada persona que participa en este proyecto mediante GitHub Issues, el foro de discusión o el correo electrónico, incluidas, entre otras, las que:

* informan de bugs y proponen sugerencias de funciones
* aportan código, pruebas y documentación
* comparten o construyen en común plantillas de diagramas de discriminación, geotermobarómetros y otras

* participan en la localización a varios idiomas, etc.

Todas las personas colaboradoras cuya publicación esté autorizada figurarán en la lista de colaboradores del proyecto. Si tiene una página personal o un enlace relacionado, puede indicárnoslo para mostrarlo también.

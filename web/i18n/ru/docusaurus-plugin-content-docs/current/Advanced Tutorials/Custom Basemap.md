# Создание шаблона диаграммы

Если нужного шаблона ещё нет в онлайн-библиотеке шаблонов диаграмм, вы можете создать собственный шаблон. Создав его и упаковав в пакет шаблона, вы сможете быстро поделиться им с другими исследователями.

Вы также можете передать свой шаблон разработчику для включения в онлайн-библиотеку шаблонов диаграмм. Мы искренне благодарим каждого участника за вклад.

Теперь вы можете создать новый шаблон диаграммы через меню: `Файл` -> `Создать шаблон диаграммы`, как показано ниже:

У нового пользовательского шаблона диаграммы нужно настроить в основном три части:

1.  **Языки по умолчанию**: в списке справа можно выбрать встроенные быстрые варианты языка. Мы предоставляем десять языков, в том числе упрощённый китайский, традиционный китайский, американский английский, японский, русский, корейский и немецкий.

    > Следует пояснить: язык по умолчанию используется как запасной, если другой язык не переведён или возникает ошибка. Кроме того, в новой версии пользователям больше не разрешается задавать собственные языковые коды. Если вам нужна поддержка вашего языка, свяжитесь с разработчиком.

2.  **Классификация шаблона диаграммы (иерархия)**: мы предоставляем встроенную структуру быстрых категорий. Эта настройка определяет, на каком уровне иерархии ваш шаблон появится в списке шаблонов диаграмм.

3.  **Тип шаблона диаграммы**: сейчас поддерживаются два типа — **двумерная система координат** и тройная диаграмма.

После завершения настройки нажмите «ОК», чтобы перейти к интерфейсу пользовательского построения. Далее основное внимание уделяется панели **Правка**. После нажатия «Правка» система покажет диалог повторного подтверждения редактирования диаграммы. После подтверждения вы войдёте в режим редактирования, где можно просматривать и использовать инструменты панели правки.

## Построение диаграммы

В режиме редактирования доступны следующие действия:

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/graphical_toolbar.webp')}
    alt="Построение диаграммы"
    style={{width: '100%'}}
  />
</div>

* **Сохранить**: сохранить шаблон диаграммы. После нажатия программа по умолчанию создаёт соответствующую миниатюру по текущему состоянию чертежа.
* **Сохранить как**: сохранить шаблон диаграммы в другом месте.
* **Добавить линию**: после включения начинается режим «Добавить линию». Щёлкните первую точку в области построения, чтобы начать линию, и вторую точку, чтобы завершить объект линии.
* **Добавить текст**: также называется примечанием. После включения начинается режим «Добавить текст». Щёлкните нужное место на чертеже, чтобы создать объект. Текст по умолчанию — `Text`. Положение и содержимое можно изменить в разделе свойств панели слоёв.
* **Добавить многоугольник**: после включения начинается режим «Добавить многоугольник». Последовательными щелчками левой кнопки мыши задавайте вершины замкнутого многоугольника; щелчок правой кнопкой замыкает фигуру.
* **Добавить стрелку**: после включения начинается режим «Добавить стрелку». Добавление похоже на создание линии.
* **Добавить функцию**: после нажатия добавляется функция по умолчанию `sin(x)` с областью определения [-10, 10]. Формулу можно задать на панели свойств.
* **Отменить/Повторить**: если объекты чертежа не создавались и не удалялись, эти функции отключены. По умолчанию в истории хранятся только последние 10 операций.
* **Удалить**: удалить объект чертежа. Сначала выберите объект, например текст, затем нажмите «Удалить», чтобы убрать его.

### Добавление функции

Добавление функции отличается от предыдущих объектов: **после нажатия кнопки «Добавить функцию» сразу добавляется объект функции по умолчанию**. Функция по умолчанию — `sin(x)`. Формулу функции можно изменить на панели свойств и тем самым задать свою функцию.

Для объекта функции два самых важных параметра — **область определения** и **точки выборки**.

* **Область определения задаёт диапазон отображения функции на холсте**.
* **Точки выборки управляют точностью построения функции на холсте** и тем самым влияют на точность алгоритма захвата и выбора мышью. Значение по умолчанию — `1000`. Чем выше точность, тем тоньше отрисовка функции, но тем выше и нагрузка на отрисовку.

## Доработка шаблона диаграммы

После построения основных фигур полному шаблону ещё нужны:

1.  **Данные и сценарий**: задают входные данные шаблона диаграммы и алгоритм их расчёта, то есть указывают, как данные вычисляются и наносятся на диаграмму.
2.  **Документ диаграммы**: поясняет справочное содержание этой диаграммы.
3.  **Многоязычность**: если для шаблона диаграммы задано больше одного языка, многоязычную часть нужно перевести. Сюда входят предыдущий документ диаграммы, текстовые объекты на холсте и другое содержимое.

Дорабатывать шаблон можно и в интерфейсе работы с диаграммой, однако мы рекомендуем делать это в окне редактирования диаграммы: так удобнее.

### Данные и сценарий

Данные и сценарий — ключевая часть шаблона диаграммы, потому что они определяют, как данные на диаграмме вычисляются и в итоге отображаются.

Нужны два параметра: **переменные параметры** шаблона диаграммы и **алгоритм расчёта (сценарий)**, как показано ниже:

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/diagram_data_and_script.webp')}
    alt="Диаграмма: данные и сценарий"
    style={{width: '100%'}}
  />
</div>

Для **переменных параметров** шаблона диаграммы вверху можно добавить соответствующие столбцы, которые обозначают входные столбцы, нужные этой диаграмме. Есть два необязательных параметра.

1. Unit задаёт единицу измерения входного столбца. Он служит только для показа и пояснения и не влияет на алгоритм данных.
2. Group задаёт группу входного столбца. Он служит только для показа и пояснения и не влияет на алгоритм данных.

Важно: **заголовки столбцов, заданные в таблице данных, по умолчанию считаются зарегистрированными переменными, которые сценарий ниже может вызывать напрямую**. Это означает, что входные столбцы не нужно повторно объявлять в сценарии.

**Алгоритм расчёта (сценарий)** по умолчанию пишется на языке `JavaScript`. Содержимое примера сценария по умолчанию — `return [X,Y]`: входные столбцы `X` и `Y`, заданные в таблице данных, возвращаются двумерным осям координат.

Например, для диаграммы TAS параметрами должны быть `SiO2, Na2O, K2O`. Содержимое сценария будет таким:

```javascript
// Вычисление с использованием переменных K2O + Na2O
var result1 = K2O + Na2O;
// Использование SiO2
var result2 = SiO2;
// Возврат двух вычисленных значений. Обратите внимание: для стандартной двумерной координатной диаграммы возвращаются только два значения.
// Первая позиция — возвращаемое значение X, вторая — возвращаемое значение Y.
return [result2, result1]
```

Или сценарий можно записать так:

```javascript
var result = K2O + Na2O
return [SiO2, result]
```

Обратите внимание: позиции возвращаемых значений фиксированы. В `[x, y]` первое значение всегда соответствует X (нижняя ось), второе — Y (левая ось).

:::info

Для тройной диаграммы итоговый формат возврата — `[A, B, C]`: первое значение — A (нижняя ось), второе — B (левая ось), третье — C (правая ось).

:::

### Документ диаграммы

Документ диаграммы — необходимый шаг, чтобы другие исследователи могли быстро узнать основные сведения о диаграмме и способ её применения.

Документ диаграммы пишется на странице справочной документации. Мы предоставляем простую панель инструментов для обычных потребностей документа. Разумеется, содержимое можно подготовить в `Office Word`, а затем вставить сюда: большая часть форматирования совместима.

Для оформления документа диаграммы мы рекомендуем придерживаться следующего порядка:

*   **Введение**: объясняет основные понятия и функции шаблона диаграммы и помогает пользователю быстро понять его.
*   **Формат данных**: указывает формат входных данных и заголовки столбцов, необходимые для корректного чтения данных.
*   **Литература**: перечисляет источники, использованные при создании шаблона диаграммы и его содержания.
*   **Участники**: имена людей, участвовавших в подготовке шаблона диаграммы. Мы даже рекомендуем указать ваш личный сайт.

### Многоязычность

Мы предусмотрели два способа задать несколько языков.

Первый — пункт **Переключить язык** на верхней функциональной панели интерфейса диаграммы. Он позволяет задать особое содержимое для второго языка.

Второй способ — редактировать многоязычное содержимое в окне редактирования диаграммы, как показано на рисунке ниже.

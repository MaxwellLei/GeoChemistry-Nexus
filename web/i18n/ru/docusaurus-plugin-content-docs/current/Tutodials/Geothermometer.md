# Геотермобарометр

В ранних версиях этот модуль кратко назывался **GTM**. Затем название сменили на геологический термометр, а сейчас официальное название — геотермобарометр.

Ранние версии включали расчёт геологических термометров для таких минералов, как циркон, сфалерит, кварц, ксенотим, хлорит и биотит. Геотермобарометр новой версии ещё адаптируется и обновляется и вскоре будет синхронизирован.

## Интерфейс

Модуль геотермобарометра в целом делится на две части:

1. Слева — **список шаблонов геотермобарометров**. Здесь можно найти подходящий шаблон или создать собственный шаблон расчёта.
2. Справа — **справочный документ текущего выбранного шаблона геотермобарометра**.

## Функции

Модуль геотермобарометра с самого начала **устроен по образцу Excel**, чтобы снизить порог вхождения. **Геотермобарометром пользуются в основном в двух формах**:

1. **Онлайн-шаблоны геотермобарометров**: шаблоны **онлайн-геотермобарометров** по умолчанию пользователь изменить не может, но может просмотреть логику реализации алгоритма. Более новые шаблоны геотермобарометров можно получать по сети без обновления программы. Исследователь может искать, отбирать и выбирать подходящий шаблон, а затем заполнять данные и выполнять расчёт по руководству. **Этот способ прямее и быстрее и не требует знания программирования**.
2. **Отдельное окно расчёта**: через верхнее меню **Файл -> Открыть отдельную таблицу** можно открыть отдельное окно расчёта. В отдельном окне исследователю разрешено самостоятельно программировать и комбинировать разные геотермобарометры. Функции, соответствующие разным геотермобарометрам, см. в разделе продвинутых руководств. **Этот способ сложнее и при этом гибче**.

Разумеется, модуль геотермобарометра также позволяет исследователю создать собственный геотермобарометр. Готовый шаблон можно экспортировать и передать другим исследователям для быстрого использования.

## Пример использования

### Использование онлайн-шаблона геотермобарометра

Сначала в модуле геологического термометра отберите и выберите нужный шаблон расчёта на левой боковой панели:

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/select_and_apply_thermobarometer_template.webp')}
    alt="Выбор геотермобарометра"
    style={{width: '100%'}}
  />
</div>

На правой панели можно просмотреть пояснительный документ шаблона. Верхняя панель также показывает название и метки текущего выбранного шаблона геотермобарометра. После выбора нужного шаблона нажмите на верхней панели кнопку **Применить**, чтобы перейти к интерфейсу расчёта геотермобарометра.

В интерфейсе геотермобарометра видны соответствующие входные столбцы. Можно также нажать на верхней панели кнопку **Пример**, чтобы загрузить пример данных. Достаточно заполнить данные согласно требованиям заголовков столбцов, а затем **скопировать формулу расчёта** или **воспользоваться маркером заполнения «щёлкнуть и перетащить»** (как в Excel), чтобы автоматически завершить расчёт, как на анимации ниже.

> Следует пояснить: столбец `Sample` в расчёте не участвует и служит только примечанием для обозначения образца данных.

### Отдельное окно: пользовательские функции

Как сказано выше, отдельное свободное окно открывается через меню **Файл -> Открыть свободную таблицу**.

Таблица отдельного окна — пустая таблица с несколькими простыми кнопками панели инструментов.

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/thermobarometer_free_form.webp')}
    alt="Свободная таблица расчёта геотермобарометра"
    style={{width: '100%'}}
  />
</div>

Таблица отдельного окна используется так же, как привычная **таблица Excel: можно вводить любые числа и вызывать функции, вводя `=имя_функции(параметры)`**.

Отличие в том, что расчёты геотермобарометров зарегистрированы как соответствующие вычислительные функции, и исследователь может гибче задавать содержимое расчёта под свою задачу. Можно даже **сравнить результаты нескольких геотермобарометров в одной таблице**.

:::note

Обратите внимание: **в таблице отдельного окна нельзя просмотреть промежуточный ход расчёта соответствующей строки данных**.

:::

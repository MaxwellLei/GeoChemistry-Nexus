# Расчёт нормативных минералов CIPW

**Расчёт нормативных минералов CIPW** переводит оксиды главных элементов валового состава породы (wt%) в набор идеализированных нормативных минералов. Результат используется для сопоставления магматических пород и для оценки насыщенности кремнезёмом и глинозёмом. Норма CIPW предложена Кроссом, Иддингсом, Пирссоном и Вашингтоном в 1902 году. Этот модуль выполняет пакетный расчёт в таблице в стиле Excel и для каждой строки даёт диагностику и баланс масс.

## Интерфейс

Страница состоит из верхней панели и листа данных. Слева на верхней панели находится **Fe³⁺/ΣFe**, справа — **Справка**, **Пример**, **Экспорт**, **Очистить** и **Выполнить расчёт**.

Лист слева направо делится на четыре участка. Над заголовками столбцов указаны названия групп:

| Область | Группа | Единица | Назначение |
| --- | --- | --- | --- |
| Образец | — | — | Название образца, только идентификатор, в расчёте не участвует. Столбец закреплён и остаётся видимым при горизонтальной прокрутке |
| Оксиды | Главные элементы; прочие оксиды / летучие | wt% | Белая область ввода |
| Диагностика | Диагностика | — | `Насыщенность SiO2`, `Состояние Al2O3`, `Погрешность баланса масс (%)` |
| Нормативные минералы | Нормативные минералы CIPW | wt% | Светлая область результатов. В заголовке — сокращение и русское название, например `Q(кварц)` |

Между областью ввода и областью результатов есть узкий разделительный столбец. Столбцы результатов до расчёта пусты. Изначально в таблице 500 строк. Двойной щелчок по маркеру заполнения заполняет ячейки вниз, как в Excel.

### Верхняя панель

| Элемент | Назначение |
| --- | --- |
| **Fe³⁺/ΣFe** | Только при использовании валового железа `FeOT` разделяет FeO и Fe₂O₃ по этому отношению. Диапазон `0`–`1`, по умолчанию `0.15` (Le Maitre, 2002), показываются два десятичных знака |
| **Справка** | Открывает пояснение алгоритма внутри программы |
| **Пример** | Заполняет три строки примера: гранит, базальт, андезит, с измеренными Fe₂O₃, FeO и MnO |
| **Экспорт** | Сохраняет текущую таблицу как CSV в UTF-8; имя файла по умолчанию — `CIPW_Results.csv` |
| **Очистить** | После подтверждения удаляет весь ввод, результаты и подробности расчёта |
| **Выполнить расчёт** | Рассчитывает все строки, в которых есть допустимые оксиды |

### Состояние заголовка строки

Точка рядом с номером строки показывает состояние строки:

| Точка | Значение |
| --- | --- |
| Серый контур | Ввод уже есть, расчёт ещё не выполнен |
| Сплошная бирюзовая | Расчёт успешен, предупреждений нет, баланс масс тоже выполнен |
| Сплошная оранжевая | Расчёт успешен, но есть предупреждение, либо погрешность баланса масс больше `1×10⁻⁶` |
| Сплошная красная | Расчёт этой строки не удался. В диагностическом столбце указаны «Ошибка» и причина |
| Оранжевый контур | После расчёта оксиды были изменены, текущий результат устарел |

Во всех примерах есть MnO. MnO объединяется с FeO и порождает предупреждение, поэтому после расчёта строки примера оранжевые. Это ожидаемый результат. Изменение названия образца не делает результат устаревшим; изменение любого введённого оксида — делает.

## Ввод

Каждая строка — один образец валового состава. Заполняются массовые проценты оксидов (wt%). Программа читает только ячейки **больше 0**; пустые ячейки и 0 считаются не заданными. Пустые строки пропускаются автоматически.

Можно вставлять данные прямо из табличной программы. Порядок столбцов фиксирован; при вставке выравнивайте данные по заголовкам ниже.

### Столбцы оксидов

Главные элементы:

`SiO2`, `TiO2`, `Al2O3`, `Fe2O3`, `FeO`, `FeOT`, `MnO`, `MgO`, `CaO`, `Na2O`, `K2O`, `P2O5`

Прочие оксиды / летучие:

`ZrO2`, `Cr2O3`, `CO2`, `S`, `F`, `Cl`, `SO3`

`FeOT` — валовое железо в эквиваленте FeO. `S`, `F` и `Cl` вводятся как массовые проценты элементов.

### Обработка железа

| Что заполнено | Обработка |
| --- | --- |
| Есть и `FeO`, и `Fe2O3`, нет `FeOT` | Используется измеренное распределение; режим обработки железа — «измеренные значения» |
| Есть только `FeO` или только `Fe2O3` | Недостающий компонент принимается равным 0; режим — «частичное допущение», выдаётся предупреждение |
| Есть только `FeOT` | Разделение по Fe³⁺/ΣFe; режим — «оценка по FeOT» |
| `FeOT` указан вместе с `FeO` или `Fe2O3` | `FeOT` игнорируется; режим — «несогласованный ввод», выдаётся предупреждение |
| Данных по железу нет | И FeO, и Fe₂O₃ принимаются равными 0; режим — «отсутствует», выдаётся предупреждение |

Разделение, когда есть только `FeOT`:

```text
Fe2O3 = FeOT × (Fe³⁺/ΣFe) × 1.11134
FeO   = FeOT × (1 − Fe³⁺/ΣFe)
```

Коэффициент `1.11134` соответствует отношению молярной массы Fe₂O₃ к удвоенной молярной массе FeO и переводит трёхвалентное железо из эквивалента FeO обратно в массовый процент Fe₂O₃.

Перед расчётом `MnO` переводится в эквивалент FeO по отношению молярных масс и прибавляется к FeO:

```text
Эквивалент FeO = MnO × 71.844 / 70.937
```

Если MnO заполнен, в подробностях расчёта появляется запись «MnO переведён в эквивалент FeO по мольному отношению».

## Вывод

### Диагностические столбцы

| Столбец | Значения |
| --- | --- |
| **Насыщенность SiO2** | пересыщение, насыщение, недосыщение |
| **Состояние Al2O3** | перщелочной, метаалюминиевый, пералюминиевый |
| **Погрешность баланса масс (%)** | Отклонение замыкания массы минералов и введённых оксидов. Если значение меньше `0.01`, используется экспоненциальная запись, иначе сохраняются 4 десятичных знака |

Смысл трёх степеней насыщения:

- **Пересыщение**: после распределения SiO₂ ещё остаётся и записывается как кварц `Q`.
- **Насыщение**: SiO₂ израсходован точно; нет ни кварца, ни необходимости в десиликации.
- **Недосыщение**: SiO₂ недостаточно, и выполняются реакции десиликации ниже. Если вся цепочка реакций всё ещё не устраняет дефицит кремния, добавляется предупреждение с остаточным дефицитом (mol/100 g). Нормативные минералы в этом случае ненадёжны.

Состояние насыщения глинозёмом определяется до распределения полевых шпатов по оставшимся в этот момент молям оксидов:

- **Перщелочной**: Na₂O + K₂O > Al₂O₃
- **Пералюминиевый**: Al₂O₃ / (CaO + Na₂O + K₂O) > 1
- **Метаалюминиевый**: остальные случаи

Апатит, кальцит, фторит, галит и тенардит уже израсходовали соответствующий CaO или Na₂O, поэтому здесь используются остатки.

### Нормативные минералы

Результаты расположены в следующем порядке. Русские названия совпадают с заголовками таблицы в программе.

| Сокращение | Минерал | Сокращение | Минерал |
| --- | --- | --- | --- |
| `Q` | кварц | `Fo` | форстерит |
| `Or` | ортоклаз | `Fa` | фаялит |
| `Ab` | альбит | `Mt` | магнетит |
| `An` | анортит | `Hm` | гематит |
| `Le` | лейцит | `Ilm` | ильменит |
| `Ne` | нефелин | `Cm` | хромит |
| `Kp` | псевдолейцит | `Ru` | рутил |
| `Cor` | корунд | `Tn` | титанит |
| `Ac` | эгирин | `Pf` | перовскит |
| `Di` | диопсид | `Z` | циркон |
| `Hd` | геденбергит | `Ap` | апатит |
| `Wo` | волластонит | `Cc` | кальцит |
| `Cs` | ларнит | `Py` | пирит |
| `En` | энстатит | `Fl` | фторит |
| `Fs` | ферросилит | `Hl` | галит |
| `ns` | метасиликат натрия | `Th` | тенардит |
| `ks` | метасиликат калия | | |

Ортоклаз, альбит и эгирин внутри считаются в формульных единицах: 1 mol K₂O даёт 2 mol `Or`, 1 mol Na₂O даёт 2 mol `Ab` или `Ac`. Наружу всегда выводится массовый процент.

## Подробности расчёта

После выбора успешно рассчитанной строки инспектор справа показывает:

- Название образца. Если столбец образца пуст, показывается «строка N».
- Насыщенность кремнезёмом и глинозёмом. При недосыщении насыщенность кремнезёмом подсвечивается.
- **Режим обработки железа**. Подсвечивается во всех случаях, кроме «измеренных значений».
- **Погрешность баланса масс**, с 6 десятичными знаками. Подсвечивается, если превышает `1×10⁻⁶`.
- **Сумма минералов**, то есть сумма wt% нормативных минералов, с 4 десятичными знаками. Кислород, выделяющийся при образовании пирита, фторита и галита, в эту сумму не входит, но входит в баланс масс.
- **Главные минералы**: минералы с содержанием больше `0.01 wt%`, от большего к меньшему; записи больше `10 wt%` подсвечиваются.
- **Предупреждения**: отсутствие или несогласованность данных по железу, оценка по FeOT, пересчёт MnO, остаточный дефицит кремния и другое.

В правом верхнем углу инспектора эти подробности можно экспортировать в CSV или скопировать в буфер обмена.

## Ход расчёта

Ниже порядок соответствует фактической последовательности текущего кода расчёта. Апатит занимает кальций первым, и только затем образуются минералы летучих; титанит и рутил стоят после анортита.

Молярные массы всех минералов выводятся из молярных масс оксидов по химической формуле, чтобы ручное округление не нарушало баланс масс. Числовой допуск расчёта — `1×10⁻¹²`. Если на каком-либо шаге оксид, кроме SiO₂, становится явно отрицательным, строка завершается с ошибкой.

### 1. Безводная нормализация, железо и марганец

Все заданные неотрицательные оксиды нормализуются к 100%. Железо обрабатывается, как в предыдущем разделе, затем MnO переводится в эквивалент FeO, после чего выполняется **повторная нормализация**. Если сумма не больше 0, строка завершается с ошибкой.

### 2. Перевод в моли

Число молей каждого оксида = нормализованный wt% / молярная масса. Дальнейшее распределение идёт в масштабе mol/100 g.

### 3. Апатит

Апатит первым занимает кальций. 1 mol `P2O5` связывает `10/3` mol `CaO` (без OH и F):

```text
Ap = min(P2O5, CaO / (10/3))
```

### 4. Минералы летучих

В указанном порядке образуется столько, сколько может связаться:

| Минерал | Стехиометрия |
| --- | --- |
| кальцит `Cc` | `min(CO2, CaO)` |
| фторит `Fl` | `min(F/2, CaO)`, то есть 1 mol CaO связывает 2 mol F |
| пирит `Py` | `min(S/2, FeO)`, то есть 1 mol FeO связывает 2 mol S |
| галит `Hl` | `min(Cl, 2×Na2O)` |
| тенардит `Th` | `min(SO3, Na2O)` |

### 5. Циркон, хромит, ильменит

- Циркон `Z`: весь `ZrO2` и равное количество `SiO2`.
- Хромит `Cm`: `min(Cr2O3, FeO)`.
- Ильменит `Ilm`: `min(TiO2, FeO)`.

На этом шаге расходуется только тот титан, который может связаться с FeO. Оставшийся TiO₂ сохраняется до этапа после анортита.

### 6. Полевые шпаты, корунд и остаток щелочей

Сначала фиксируется состояние насыщения глинозёмом, затем выполняется распределение:

| Минерал | Условие и продукт |
| --- | --- |
| ортоклаз `Or` | `min(K2O, Al2O3)`, расходуется 6-кратное количество SiO₂, число молей продукта в 2 раза больше этого значения |
| альбит `Ab` | `min(Na2O, Al2O3)`, так же расходуется 6-кратное количество SiO₂, продукт в 2 раза больше |
| анортит `An` | `min(CaO, Al2O3)`, расходуется 2-кратное количество SiO₂ |
| корунд `Cor` | оставшийся Al₂O₃ |
| эгирин `Ac` | `min(оставшийся Na2O, Fe2O3)`, расходуется 4-кратное количество SiO₂, продукт в 2 раза больше |
| метасиликат натрия `ns` | оставшийся Na₂O и равное количество SiO₂ |
| метасиликат калия `ks` | оставшийся K₂O и равное количество SiO₂ |

На этапе полевых шпатов SiO₂ может сначала стать отрицательным: единая десиликация выполняется позже.

### 7. Титанит и рутил

Титанит использует только CaO, оставшийся после анортита, и **не ограничивается текущим остатком SiO₂**:

```text
Tn = min(оставшийся TiO2, оставшийся CaO)
```

`Tn` одновременно расходует равное количество SiO₂. TiO₂, который всё ещё остаётся в конце, записывается как рутил `Ru`.

### 8. Оксиды железа

```text
Mt = min(Fe2O3, FeO)
Hm = оставшийся Fe2O3
```

### 9. Пироксены и волластонит

Пусть `MgFe = MgO + FeO`. Суммарное количество моноклинного пироксена равно `min(CaO, MgFe)`, затем по отношению магния и железа оно делится на диопсид `Di` и геденбергит `Hd`. Каждая доля пироксена расходует 2 доли SiO₂.

Весь оставшийся MgO и FeO становится энстатитом `En` и ферросилитом `Fs`; каждый расходует 1 долю SiO₂. После того как магний и железо израсходованы, оставшийся CaO целиком становится волластонитом `Wo`.

### 10. Насыщенность кремнезёмом и десиликация

Порядок десиликации: гиперстен → титанит → альбит → ортоклаз → волластонит → диопсид/геденбергит → лейцит. Каждый шаг расходует только тот SiO₂, которого ещё не хватает в этот момент.

| Порядок | Реакция | Высвобождаемый SiO₂ |
| --- | --- | --- |
| 1 | 2 энстатит/ферросилит → 1 форстерит/фаялит | каждые 2 mol пироксена высвобождают 1 mol |
| 2 | титанит `Tn` → перовскит `Pf` | 1 mol `Tn` высвобождает 1 mol |
| 3 | альбит `Ab` → нефелин `Ne` | 1 mol `Ab` высвобождает 2 mol |
| 4 | ортоклаз `Or` → лейцит `Le` | 1 mol `Or` высвобождает 1 mol |
| 5 | 2 волластонит `Wo` → 1 ларнит `Cs` | каждые 2 mol `Wo` высвобождают 1 mol |
| 6 | диопсид/геденбергит → ларнит + оливин | 1 mol пироксена высвобождает 1 mol; магний переходит в `Fo`, железо — в `Fa` |
| 7 | лейцит `Le` → псевдолейцит `Kp` | 1 mol `Le` высвобождает 1 mol |

Если SiO₂ остаётся, образуется кварц, и состояние — пересыщение. Если SiO₂ в точности равен нулю, состояние — насыщение. Если выполняется десиликация из таблицы выше, состояние — недосыщение.

### 11. Массовые проценты и баланс масс

Масса нормативного минерала = число молей × молярная масса, выведенная из химической формулы, затем относительно суммы нормализованных оксидов переводится в wt%.

В пирите, фторите и галите S, F и Cl замещают кислород оксидов. Высвобожденный кислород не входит ни в один минерал, и при балансе масс его добавляют обратно:

```text
Число молей высвобожденного кислорода = Fl + Py + Hl / 2
Погрешность баланса масс = |100 − (сумма wt% минералов + wt% высвобожденного кислорода)|
```

Если погрешность больше `1×10⁻⁶`, для строки записывается предупреждение.

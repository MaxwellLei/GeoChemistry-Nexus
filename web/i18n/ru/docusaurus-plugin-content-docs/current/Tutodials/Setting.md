# Настройки

Раздел настроек программы весьма разнообразен и по мере расширения функций будет пополняться новыми параметрами персонализации.

## Общие настройки программы

Настройки в основном делятся на четыре части: пути к файлам, интернационализация и персонализация, уведомления и прочее. Ниже кратко описаны основные настройки:

### 🌍 Язык и оформление

-   **Язык**: сейчас поддерживаются упрощённый китайский, традиционный китайский, английский, немецкий, испанский, японский, корейский, русский, французский и португальский.
-   **Масштаб интерфейса**: разные параметры масштаба для экранов с разным разрешением; обычно достаточно значения по умолчанию.

:::info

Если вы хотите помочь с локализацией для своей страны, мы горячо приглашаем вас присоединиться к переводческой работе. Сейчас большая часть перевода выполнена с помощью ИИ, поэтому отдельные фрагменты могут быть неточными. Ваша помощь очень нужна, и мы благодарны за неё.

:::

### 🗨️ Уведомления

-   **Длительность автоматического закрытия**: время, через которое всплывающее уведомление автоматически закрывается во время работы программы. Сообщения об ошибках и предупреждения нужно закрывать вручную.

### ⚙️ Прочее

-   **Запуск вместе с системой**: программа будет автоматически запускаться при запуске системы.
-   **Автоматическая проверка обновлений**: программа будет автоматически проверять обновления при запуске.
-   **Способ выхода**: выйти из программы можно двумя способами — выйти сразу или свернуть в системный лоток. Если выбран лоток, закройте программу, щёлкнув значок в лотке правой кнопкой мыши и выбрав выход.

## Настройки модуля диаграмм

Настройки модуля диаграмм относятся именно к функциям внутри этого модуля и включают, помимо прочего:

*   пути к сторонним программам
*   стороннюю программу по умолчанию
*   язык загрузки диаграмм по умолчанию
*   автоматическое обновление шаблонов диаграмм и структуры категорий

# Минеральный расчёт EPMA

**Минеральный расчёт EPMA** обрабатывает составы минералов, полученные на электронно-зондовом микроанализаторе. Содержания оксидов для набора аналитических точек пересчитываются выбранным минеральным методом в результаты минеральной химии. Они нужны для диагностики минералов, сравнения составов и последующей геологической интерпретации.

## Интерфейс

Минеральный расчёт EPMA разделён на два интерфейса: **библиотеку шаблонов минерального расчёта EPMA** и **интерфейс расчёта EPMA**.

В библиотеке можно искать, фильтровать и выбирать подходящий расчёт EPMA для минерала. На панели описания справа видны основные сведения об этих шаблонах. Нажмите **Перейти к расчёту**, чтобы начать расчёт.

## Пример

Например, выберите шаблон расчёта EPMA для оливина и откройте интерфейс расчёта. Страница делится на верхнюю и нижнюю части. На верхней панели можно открыть подробное описание шаблона или загрузить пример данных.

Введите данные, которые требует таблица, и нажмите **Выполнить расчёт** на верхней панели.

Бело-серая область предназначена для ввода, сине-фиолетовая — для вывода результатов. Результаты можно просматривать свободно, а кнопка **Проверить** показывает промежуточные шаги расчёта.

Цветная точка перед заголовком каждой строки показывает состояние расчёта этой строки:

* **Серый**: в строке есть данные, но расчёт ещё не выполнен
* **Зелёный**: строка рассчитана нормально, без предупреждений и ошибок
* **Оранжевый**: расчёт завершён, но есть предупреждение
* **Красный**: расчёт этой строки завершился ошибкой

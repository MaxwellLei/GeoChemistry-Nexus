# 🛣️ Дорожная карта

Цель GeoChemistry Nexus — постепенно выстроить единую научно-исследовательскую цепочку инструментов для геохимии и петрологии: **данные · диаграммы · расчёты · сотрудничество**.

## ✅ Выполнено


### Основной рабочий процесс
- [x] **Главная страница**: быстрые ссылки и практичные виджеты
- [x] **Дискриминационные диаграммы**: в библиотеке шаблонов встроено большое число дискриминационных диаграмм, включая, помимо прочего, диаграммы тектонических обстановок, диаграммы классификации пород и другие; помимо этого поддерживаются спайдер-диаграммы микроэлементов и редкоземельных элементов, а также большое число встроенных схем нормализации; поддерживается нанесение точек на многопанельные диаграммы Харкера
- [x] **Геотермобарометр**: встроенные онлайн-шаблоны расчёта геотермобарометров для многих минералов и пользовательские функции в стиле Excel
- [x] **Минеральные расчёты EPMA**: встроенные онлайн-шаблоны расчёта EPMA для разных минералов с обновлением в реальном времени; можно скачивать и сразу использовать
- [x] **Расчёт нормативных минералов CIPW**: нормализация данных главных элементов валового состава и экспорт результатов
- [x] **Расчёт нормативных минералов Ниггли**: нормализация данных главных элементов валового состава и экспорт результатов
### Возможности платформы
- [x] **Зависимости по производительности**: очень низкое потребление памяти и очень малый объём установки; локальный объём программы без среды выполнения `.NET` составляет всего 9 МБ
- [x] **Экосистема шаблонов**: динамическое обновление онлайн-шаблонов из облака; создание, импорт и упаковка пользовательских шаблонов для обмена; можно просматривать подробности хода расчёта для удобной проверки
- [x] **Многоязычность**: локализация интерфейса (китайский / английский / немецкий / русский / японский / корейский и другие); переключение языка шаблонов диаграмм одним действием
- [x] **Экспорт и интеграция**: экспорт в PNG / JPG / BMP / SVG; совместная работа со сторонними программами, такими как CorelDRAW, Inkscape и Adobe Illustrator

### Анализ с помощью машинного обучения
Ввести распространённые процессы машинного обучения, чтобы помогать различать и классифицировать геохимические данные и выводить оценку модели, важность переменных, кривые ROC, матрицы ошибок и другие наглядные результаты — **без самостоятельной настройки среды Python**.
### Дискриминационные модели типа «новой диаграммы»
Поддержать загрузку расширяемых дискриминационных моделей машинного обучения, например новых дискриминационных диаграмм, обученных на больших данных, чтобы исследователь мог напрямую применять «новую диаграмму» и при этом не обязан владеть полным стеком разработки ML.

# 🌍 소개

**GeoChemistry Nexus는 지구화학, 암석학, 광물학, 광상학 연구자를 위한 통합 연구 작업 플랫폼입니다.**

판별 도해 작성, 지질 온압계 계산, EPMA 광물 화학 계산, CIPW 표준 광물 계산, Niggli 표준 광물 계산처럼 자주 쓰는 연구 계산을 하나의 작업 환경에 모읍니다. 여러 소프트웨어를 오가는 일을 줄여, 지질 데이터 처리와 계산, 시각화를 더 이어서 효율적으로 할 수 있습니다.

GeoChemistry Nexus는 클라우드 템플릿 생태계를 통해 도해 템플릿과 계산 알고리즘을 계속 업데이트하고 공유하며 다시 쓸 수 있게 합니다. 연구 도구를 넓혀 가며, 열려 있고 유연하며 오래 이어갈 수 있는 지구과학 작업 환경을 만들어 갑니다.

**3분 안에 GeoChemistry Nexus 시작하기** ⏱️.

## 사전 조건 🛠️

현재 **GeoChemistry Nexus는 Windows만 지원**하며, macOS와 Linux 네이티브 버전은 아직 없습니다.

- **Windows**: Windows 7 이상을 사용해 주세요
- **macOS / Linux**: 아직 네이티브 실행 방안은 없습니다. 가상 머신에 Windows를 설치한 뒤 GeoChemistry Nexus를 실행해 볼 수 있지만, 호환성과 성능은 그 가상 머신 환경에 따라 달라집니다.

### 🚀 크로스 플랫폼 계획

여러 운영체제를 지원할 계획을 세우고 있으며, 앞으로 `Avalonia UI` 기반 이전을 검토해 macOS와 Linux 등을 단계적으로 지원하려 합니다.

## 시작하기 🚀

[여기를 클릭](https://github.com/MaxwellLei/GeoChemistry-Nexus/releases)하면 다운로드 페이지로 이동합니다. 알맞은 버전을 고르고 해당 설치 파일을 받으세요.

다운로드가 끝나면 설치 마법사를 따라 설치합니다. 설치가 끝나면 `GeoChemistry Nexus.exe`를 두 번 클릭해 소프트웨어를 실행합니다. 🖱️

### 소프트웨어 오류와 피드백 💬

GeoChemistry Nexus는 계속 개발하고 다듬는 중입니다. 개발자인 저도 미처 생각하지 못하거나 구현에서 빠뜨리는 부분이 있을 수 있습니다. 기능 설계, 계산 논리, 데이터 처리, 화면 조작에서 아직 발견되지 않은 문제가 남아 있을 수 있습니다. 신뢰성과 계산의 정확성을 위해 노력하지만, 모든 상황에서 오류가 전혀 없다고 약속할 수는 없습니다.

사용 중 버그, 계산 이상, 납득하기 어려운 결과, 더 나은 기능 제안이 있으면 GitHub Issues로 알려 주세요. 하나하나의 피드백과 제안이 GeoChemistry Nexus를 계속 개선하는 힘입니다.

**소프트웨어는 사용하는 분들의 도움이 있어야 나아집니다. 이해와 지원, 참여에 감사드립니다.**

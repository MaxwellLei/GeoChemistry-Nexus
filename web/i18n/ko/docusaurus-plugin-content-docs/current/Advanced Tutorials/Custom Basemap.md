# 도해 템플릿 만들기

온라인 도해 템플릿 라이브러리에 아직 수록되지 않은 도해 템플릿은 사용자 지정 도해 템플릿으로 만들 수 있습니다. 사용자 지정 템플릿을 템플릿 패키지로 묶으면 다른 연구자와 빠르게 공유할 수 있습니다.

만든 템플릿을 개발자에게 제공하여 온라인 도해 템플릿 라이브러리에 수록할 수도 있습니다. 참여하는 모든 분의 기여에 진심으로 감사드립니다.

## 빠르게 만들기

이제 메뉴 막대에서 `파일` -> `새 도해 템플릿`을 선택하여 새 도해 템플릿을 만들 수 있습니다. 아래와 같습니다.

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/new_graphic_template.webp')}
    alt="도해 설정"
    style={{width: '50%'}}
  />
</div>

【새 도해 템플릿】을 클릭하면 새 도해 템플릿을 만드는 팝업이 나타납니다.

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/new_graphic_template_interface.webp')}
    alt="새 도해 화면"
    style={{width: '100%'}}
  />
</div>

새 사용자 지정 도해 템플릿에서 주로 구성할 부분은 세 가지입니다.

1.  **기본 지원 언어**: 오른쪽 선택 상자에서 내장된 언어 바로 가기를 선택할 수 있습니다. 중국어(간체), 중국어(번체), 미국 영어, 일본어, 러시아어, 한국어, 독일어 등 10개 언어를 제공합니다.

    > 기본 언어는 다른 언어가 번역되지 않았거나 오류가 발생했을 때 되돌아가는 언어입니다. 또한 새 버전에서는 사용자가 언어 코드를 직접 지정하는 것을 더 이상 허용하지 않습니다. 사용하는 언어의 지원이 필요하면 개발자에게 연락해 주십시오.

2.  **도해 템플릿 분류(계층)**: 내장된 빠른 분류 구조를 제공합니다. 이 설정은 도해 템플릿 목록에서 템플릿이 놓이는 계층 위치에 영향을 줍니다.

3.  **도해 템플릿 유형**: 현재 두 가지 유형을 지원합니다. **2차원 좌표계**와 삼각도입니다.

설정을 마친 뒤 【확인】을 클릭하여 사용자 지정 작도 화면으로 들어갑니다. 이후 조작의 중심은 【편집】 기능 막대에 둡니다. 【편집】을 클릭하면 도해를 편집하기 위한 재확인 대화 상자가 표시됩니다. 확인하면 편집 모드로 들어가며, 여기서 편집 기능 막대의 여러 도구를 보고 사용할 수 있습니다.

  <img
    src={useBaseUrl('/img/v0.9.0/en-US/empty_diagram_template.webp')}
    alt="빈 도해"
    style={{width: '100%'}}
  />
</div>

## 도해 그리기

편집 모드에서는 다음 조작을 할 수 있습니다.

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/graphical_toolbar.webp')}
    alt="도해 그리기"
    style={{width: '100%'}}
  />
</div>

* **저장**: 도해 템플릿을 저장합니다. 클릭하면 프로그램은 기본적으로 현재 작도 상태에 따라 해당하는 썸네일을 생성합니다.
* **다른 이름으로 저장**: 도해 템플릿을 다른 파일 위치에 저장합니다.
* **선 추가**: 켜면 "선 추가" 모드로 들어갑니다. 작도 영역의 첫 번째 점을 클릭하여 선을 그리기 시작하고, 두 번째 점을 클릭하면 선 객체가 완성됩니다.
* **텍스트 추가**: 주석이라고도 합니다. 켜면 "텍스트 추가" 모드로 들어갑니다. 작도 중의 특정 위치를 클릭하면 만들어집니다. 기본 텍스트는 `Text`입니다. 레이어 패널의 속성 부분에서 위치나 내용을 수정할 수 있습니다.
* **다각형 추가**: 켜면 "다각형 추가" 모드로 들어갑니다. 마우스 왼쪽 단추를 연속으로 클릭하여 꼭짓점을 만들고 닫힌 다각형을 추가하며, 마우스 오른쪽 단추를 클릭하면 도형을 닫습니다.
* **화살표 추가**: 켜면 "화살표 추가" 모드로 들어갑니다. 추가 과정은 선을 만드는 것과 비슷합니다.
* **함수 추가**: 클릭하면 기본 함수 `sin(x)`가 추가되며, 정의역 범위는 [-10, 10]입니다. 속성 패널에서 수식을 직접 지정할 수 있습니다.
* **실행 취소/다시 실행**: 작도 객체를 만들거나 삭제하지 않았으면 이 기능은 비활성화됩니다. 기본적으로 이력에는 최근 10회 조작만 저장됩니다.
* **삭제**: 작도 객체를 삭제합니다. 먼저 객체(예: 텍스트)를 선택한 뒤 삭제를 클릭하여 제거합니다.

### 함수 추가

함수 추가는 앞의 객체와 다릅니다. **함수 추가 단추를 클릭하면 기본 함수 객체가 즉시 추가됩니다**. 기본 함수는 `sin(x)`입니다. 속성 패널에서 함수 수식을 수정하여 함수를 정의할 수 있습니다.

함수 객체의 속성에서 가장 중요한 두 매개변수는 **정의역**과 **샘플링 점**입니다.

* **정의역은 함수가 캔버스에 표시되는 범위를 정합니다**.
* **샘플링 점은 함수가 캔버스에 그려지는 정밀도를 제어하며**, 이어서 마우스 포착 선택 알고리즘의 정확성에도 영향을 줍니다. 기본값은 `1000`입니다. 정밀도가 높을수록 함수 렌더링은 더 세밀해지지만, 프로그램의 렌더링 부담도 커집니다.

## 도해 템플릿 다듬기

기본 도형을 그린 뒤, 완전한 템플릿에는 다음이 더 필요합니다.

1.  **데이터와 스크립트**: 도해 템플릿의 입력 데이터와 데이터 계산 알고리즘을 정의합니다. 즉, 데이터를 어떻게 계산하여 투점을 마칠지 지시합니다.
2.  **도해 문서**: 해당 도해의 도움말 설명 내용을 적습니다.
3.  **다국어**: 도해 템플릿이 두 가지 이상의 언어로 설정되어 있으면, 다국어 부분을 번역해야 합니다. 앞의 【도해 문서】와 도해 캔버스의 텍스트 객체 등이 포함됩니다.

도해 템플릿을 다듬는 작업은 도해 작업 화면에서도 할 수 있습니다. 다만 도해 편집 창에서 진행하면 더 편리합니다.

### 데이터와 스크립트

데이터와 스크립트는 도해 템플릿의 핵심입니다. 도해의 데이터가 어떻게 계산되어 최종적으로 그림에 나타나는지를 정의하기 때문입니다.

두 매개변수가 필요합니다. 도해 템플릿의 **변수 매개변수**와 **계산 알고리즘(스크립트)**이며, 아래와 같습니다.

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/diagram_data_and_script.webp')}
    alt="도해-데이터와 스크립트"
    style={{width: '100%'}}
  />
</div>

도해 템플릿의 **변수 매개변수**에서는 위쪽에 해당하는 열을 추가하여, 그 도해에 필요한 입력 열을 나타낼 수 있습니다. 선택 매개변수는 두 가지입니다.

1. Unit는 입력 열의 단위를 나타내며, 표시와 설명용일 뿐 데이터 알고리즘에는 영향을 주지 않습니다.
2. Group은 입력 열의 그룹을 나타내며, 표시와 설명용일 뿐 데이터 알고리즘에는 영향을 주지 않습니다.

**데이터 표에서 정의한 열 제목은, 아래 스크립트에서 바로 호출할 수 있는 등록된 변수로 기본 취급됩니다**. 따라서 스크립트에서 입력 열의 변수를 다시 정의할 필요가 없습니다.

**계산 알고리즘(스크립트)**은 기본적으로 `JavaScript`로 작성합니다. 기본 스크립트 예시는 `return [X,Y]`이며, 데이터 표에 정의한 입력 열 `X`와 `Y`를 2차원 좌표축에 반환합니다.

예를 들어 TAS 도해의 매개변수는 `SiO2, Na2O, K2O`여야 합니다. 스크립트 내용은 다음과 같습니다.

```javascript
// 변수 K2O + Na2O로 계산합니다
var result1 = K2O + Na2O;
// SiO2를 사용합니다
var result2 = SiO2;
// 계산값 두 개를 반환합니다. 기본 2차원 좌표 도해는 반환값이 두 개뿐입니다.
// 첫 번째 위치는 X 반환값이고, 두 번째 위치는 Y 반환값입니다.
return [result2, result1]
```

또는 스크립트를 다음과 같이 작성할 수 있습니다.

```javascript
var result = K2O + Na2O
return [SiO2, result]
```

반환값의 위치는 고정되어 있습니다. `[x, y]`에서 첫 번째 값은 항상 X(아래 축)이고, 두 번째 값은 Y(왼쪽 축)입니다.

:::info

삼각도의 최종 반환 형식은 `[A, B, C]`입니다. 첫 번째 값은 A(아래 축), 두 번째 값은 B(왼쪽 축), 세 번째 값은 C(오른쪽 축)입니다.

:::

### 도해 문서

도해 문서는 다른 연구자가 그 도해의 기본 정보와 사용법을 빠르게 이해하도록 돕는 필수 단계입니다.

도움말 문서 페이지에서 도해 문서를 작성합니다. 일반적인 문서 요구를 충족하는 간단한 도구 막대 기능을 제공합니다. `Office Word`에서 문서 내용을 작성한 뒤 여기에 붙여 넣을 수도 있으며, 형식의 대부분은 서로 통용됩니다.

도해 문서의 작성 형식은 다음 기준을 따르기를 권합니다.

*   **소개**: 도해 템플릿의 기본 개념과 기능을 설명하여, 사용자가 빠르게 이해하도록 돕습니다.
*   **데이터 형식**: 유효한 데이터를 읽는 데 필요한 입력 데이터 형식과 열 제목을 지정합니다.
*   **참고문헌**: 도해 템플릿과 그 내용을 만드는 데 사용한 참고문헌을 나열합니다.
*   **기여자**: 도해 템플릿 제작에 참여한 사람의 이름입니다. 개인 웹사이트를 넣는 것도 권합니다.

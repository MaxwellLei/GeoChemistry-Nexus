# 🛣️ 로드맵

GeoChemistry Nexus의 목표는 **데이터 · 도해 · 계산 · 협업**이 하나로 이어진 지구화학·암석학 연구 도구 사슬을 단계적으로 갖추는 것입니다.

## ✅ 완료


### 핵심 작업 흐름
- [x] **홈**: 빠른 링크, 실용적인 위젯
- [x] **판별 도해**: 템플릿 라이브러리에 많은 판별 도해를 내장합니다. 지구조 환경 판별도, 암석 분류도 등을 포함하되 이에 국한되지 않습니다. 이 밖에도 미량 원소와 희토류 원소 거미줄 도해를 지원하고, 많은 표준화 방안을 내장합니다. 하커 도해의 다중 패널 투점도 지원합니다.
- [x] **지질 온압계**: 온라인 다광물 지질 온압 계산 템플릿과 Excel형 사용자 지정 함수를 내장합니다
- [x] **EPMA 광물 계산**: 여러 광물의 EPMA 계산 템플릿을 온라인에서 실시간으로 업데이트하며, 다운로드하면 바로 사용할 수 있습니다.
- [x] **CIPW 표준 광물 계산**: 전암 주원소 데이터의 표준 광물 계산과 결과 내보내기
- [x] **Niggli 표준 광물 계산**: 전암 주원소 데이터의 표준 광물 계산과 결과 내보내기
### 플랫폼 능력
- [x] **성능**: 메모리 사용량이 매우 낮고, 설치 용량도 매우 작습니다. `.NET` 런타임을 포함하지 않은 소프트웨어 자체 용량은 9 MB에 불과합니다.
- [x] **템플릿 생태계**: 온라인 템플릿의 클라우드 동적 업데이트, 사용자 지정 템플릿 만들기·가져오기·패키지 공유를 지원합니다. 계산 과정 세부 내용을 보아 검증할 수 있습니다.
- [x] **다국어**: 인터페이스 현지화(중국어 / 영어 / 독일어 / 러시아어 / 일본어 / 한국어 등). 도해 템플릿의 다국어를 한 번에 전환
- [x] **내보내기와 연동**: PNG / JPG / BMP / SVG 내보내기. CorelDRAW, Inkscape, Adobe Illustrator 등 타사 소프트웨어와의 협업을 지원

## 🔭 중장기 전망
### 기계 학습 보조 분석
자주 쓰는 기계 학습 흐름을 도입하여 지구화학 데이터의 판별과 분류를 돕고, 모델 평가, 변수 중요도, ROC 곡선, 혼동 행렬 등의 시각화 결과를 출력합니다. **사용자가 Python 환경을 직접 구성하지 않아도 됩니다**.
### 「새 도해」형 판별 모델
확장 가능한 기계 학습 판별 모델(대규모 데이터로 훈련한 새로운 판별 도해 등)을 불러올 수 있게 합니다. 연구자가 완전한 ML 개발 스택을 갖추지 않아도 「새 도해」를 바로 적용하여 분석할 수 있습니다.
### AI 연구 보조(단계별)
1. **1단계**: 내장 도움말 문서와 지식 기반의 RAG 질의응답. 키워드와 상황에 따라 조작 제안을 제시합니다
2. **2단계**: 데이터 처리와 분석 흐름을 더 돕고, 반복 조작을 줄입니다

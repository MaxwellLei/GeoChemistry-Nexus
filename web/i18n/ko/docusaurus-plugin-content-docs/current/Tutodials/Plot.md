# 도해

도해 모듈에서는 기초 지구과학 도해 템플릿을 더 많이 통합합니다. 지구조 환경 판별도, 암석 분류도 등을 포함하되 이에 국한되지 않습니다. **최종 목표는 지구과학을 위한 포괄적인 도해 작성 도구 모음을 만들어, 연구자에게 최대한의 편의를 제공하는 것입니다.** 🧪

:::info

지질 도해 등의 분야를 연구하는 연구자로서 자신의 도해 성과를 알리고 싶다면, 연락해 주십시오. 도해 성과가 더 넓은 연구 집단에 닿도록 돕고, 학술 성과의 전파 효율과 영향력을 한층 높이겠습니다.

:::

## 빠른 시작

소프트웨어의 도해 모듈은 주로 두 부분으로 이루어집니다. 도해 템플릿 라이브러리와 도해 작업 화면입니다. 먼저 도해 템플릿 라이브러리에서 필요한 도해 유형을 선택한 뒤, 해당하는 작업 화면으로 들어가 데이터 입력, 도해 처리, 결과 내보내기 등을 수행합니다.

### 템플릿 라이브러리

도해 모듈은 세 범주로 나뉩니다. **온라인 클라우드 템플릿**, **내 템플릿**, **도구 도해 템플릿**입니다.

**온라인 클라우드 템플릿**: 계속 업데이트하고 유지합니다. 소프트웨어를 업데이트하지 않아도, 네트워크에 연결된 상태에서 업데이트된 도해 템플릿을 받을 수 있어, 항상 가장 포괄적이고 권위 있는 템플릿 자원을 갖출 수 있습니다.

**내 템플릿**: 특정 연구 필요에 맞춰 사용자 지정 템플릿을 만들어야 할 때 씁니다. 템플릿을 직접 만들 수 있을 뿐 아니라, 내보내 다른 연구자와 쉽게 공유하여 학술 교류와 전파를 도울 수 있습니다.

> *앞으로는 도해 템플릿 커뮤니티를 따로 만들어, 사용자가 여러 **개인 사용자 지정 템플릿**을 쉽게 만들고, 올리고, 공유하고, 다운로드할 수 있게 하여, 시스템의 유연성과 확장성을 한층 높일 계획입니다.*

**도구 도해 템플릿**: 고정된 일반 도해를 따로 분리한 것입니다. 현재 **희토류 원소 거미줄 도해, 미량 원소 거미줄 도해, 하커 다중 도해**, 그리고 일반적인 2차원 및 삼각 산점도를 포함합니다.

#### 화면

기본적으로 작도 모듈에 들어가면 내장 지구과학 템플릿 라이브러리가 표시됩니다. 화면은 세 주요 부분으로 나뉩니다.

*   **왼쪽 - 도해 분류**: 모든 템플릿 계층과 해당하는 템플릿을 표시하며, 사용자 지정 템플릿 목록도 포함합니다.
*   **오른쪽 - 도해 카드**: 현재 계층의 도해 카드를 표시하며, 이름과 미리보기 이미지를 포함합니다.
*   **위쪽 - 탐색 막대**: 소프트웨어는 테두리 없는 설계이므로, 위쪽 탐색 막대가 각 페이지의 일부 기능을 맡습니다. 도해 화면에서 위쪽 탐색 막대는 현재 도해 템플릿 경로와 도해 템플릿 검색 등의 기능을 표시합니다.

![graphical_interface](/img/v0.9.0/en-US/graphical_interface.webp)

적합한 도해 템플릿을 선택하고 도해 템플릿 카드를 클릭하면 도해 작업 화면으로 들어갑니다. 도해 템플릿 카드에서는 마우스 오른쪽 단추로 내보내기, 삭제, 즐겨찾기 등의 추가 조작을 할 수도 있습니다.

:::tip

오른쪽 <kbd>Alt</kbd> 키를 눌러 도해 템플릿을 빠르게 삭제하거나 즐겨찾기에 넣을 수 있습니다.

:::

#### 위쪽 메뉴 막대

위쪽 **파일** 메뉴 막대에는 다음이 있습니다.

1.  **새 도해**: 사용자 지정 도해 템플릿을 만듭니다.
2.  **도해 열기**: 도해 템플릿을 임시로 엽니다. `.diag.zip` 파일만 지원합니다.
3.  **도해 가져오기**: 외부 도해 템플릿 패키지(`.diag.zip`)를 로컬의 내 템플릿 목록으로 가져옵니다.

### 도해 작업 화면

#### 화면

도해 화면은 다섯 주요 부분으로 나뉩니다.

-   **도구 모음**: 빠른 단추와 세 기능 탭인 작도, 데이터, 편집을 포함합니다.
-   **레이어 목록(객체)**: 템플릿 위의 작도 요소 목록입니다. 요소를 클릭하면 속성을 수정할 수 있습니다.
-   **작도 캔버스**: 도표를 보고, 데이터를 가져오고, 시각 설정을 하고, 템플릿 설명을 보는 중심 영역입니다.
-   **상태 표시줄**: 현재 도해 언어와 좌표 정보를 포함한 기본 작도 정보를 표시합니다.
-   **속성 패널**: 선택한 작도 요소의 속성(색, 크기 등)을 표시하여, 원하는 시각 효과를 냅니다.

![graphical_operation_interface](/img/v0.9.0/en-US/graphical_operation_interface.webp)

#### 도해 도구 모음

도구 모음은 일련의 **빠른 단추**로 이루어집니다. 주요 항목은 다음과 같습니다.

1. 도해 템플릿 라이브러리로 돌아가기
2. 조작 상태 전환(도해 모드, 데이터 모드, 편집 모드)
3. 도해의 여러 속성 패널과 조작 도구 등

자세한 기능은 아래 그림을 참고해 주십시오.

![graphical_toolbar](/img/v0.9.0/en-US/graphical_toolbar.webp)

### 레이어 목록

작도 요소는 7가지로 나뉩니다.

-   **Line(선)**: 기본 도해 경계 또는 선분을 정의합니다.
-   **Text(텍스트)**: 레이블과 주석입니다.
-   **Polygon(다각형)**: 도표 안의 닫힌 도형입니다.
-   **Arrow(화살표)**: 방향이 있는 작도 객체입니다.
-   **Function(함수)**: 사용자가 사용자 지정 수학 함수와 정의역을 입력할 수 있습니다.
-   **Axes(좌표축)**: 도표의 좌표축입니다.
-   **Data Point(데이터 점)**: 가져온 데이터를 나타내는 요소입니다.

**기본 렌더링 순서(위에서 아래): `데이터 점 > 텍스트 > 화살표 > 함수 > 선 > 다각형 > 좌표축`**.

![tutorial_plot5](/img/v0.9.0/en-US/diagrammatic_object_selection_example.webp)

레이어 패널에서 요소를 선택하면 캔버스에서 강조 표시되고, 다른 요소는 반투명해져 방해를 줄입니다. 이어서 속성 패널에 그 요소의 관련 속성이 표시됩니다. 🔍

이 속성을 수정하여 원하는 시각 스타일을 얻을 수 있습니다.

:::tip

모든 요소의 선택을 해제하려면 **캔버스의 임의 위치를 마우스 오른쪽 단추로 클릭**하거나, 도구 모음의 **선택 해제** 단추를 사용합니다.

:::

## 사용 예시

### 예시

1. **도해 템플릿 라이브러리**에서 도해 템플릿을 선택하여 도해 작업 화면으로 들어갑니다. 예: TAS 도해를 선택합니다.
2. 데이터를 입력해야 할 때는 도해 모드에서 데이터 모드로 전환합니다.
   
   ![tutorial_plot6](/img/v0.9.0/en-US/diagram_data_input.webp)


TAS 도해에서 반드시 입력해야 하는 데이터는 네 열입니다. `Category`, `SiO2`, `K2O`, `Na2O`입니다. `Category` 제목 열은 데이터를 그룹으로 나누고 범례를 생성하는 데 씁니다. `Sample` 열은 데이터 시료 레이블을 식별하며, 어떤 계산에도 참여하지 않습니다(비워 둘 수 있습니다). 다른 원소의 단위는 `wt.%`입니다. 이 도해에 어떤 데이터를, 어떤 단위로 입력하는지, 도해를 어떻게 쓰는지 분명하지 않으면, 도해 영역 오른쪽 위의 도해 도움말 단추를 클릭하여 해당 도해의 설명 문서를 볼 수 있습니다.

3. 요구를 파악한 뒤 데이터를 입력하고, 데이터 패널 오른쪽 위의 투점 단추를 클릭하여 데이터 점을 그립니다. 데이터 입력에 문제가 있으면 데이터를 수정한 뒤 투점을 다시 클릭하면 됩니다.![tutorial_plot8](/img/v0.9.0/en-US/data_plotting.webp)
4. **도해 내보내기**. **도해 투점 결과를 클립보드에 빠르게 복사하는 기능 단추**를 제공합니다. **정식 내보내기 기능**도 있습니다. 정식 내보내기 패널에서는 이미지 형식으로 `jpg`, `png`, `bmp`, `svg`를 내보낼 수 있습니다. 연구 작도에 벡터 그림이 필요하면 `svg` 형식을 권합니다. 동시에 **결과를 타사 작도 소프트웨어로 직접 연동**할 수도 있어, 내보낸 뒤 다시 가져오는 중간 단계가 필요하지 않습니다. 기본으로 권장하는 타사 소프트웨어는 **CorelDRAW, Inkscape, Adobe Illustrator**입니다. 후반의 연구용 2차 수정을 하려면 Inkscape 연동을 권합니다. `svg` 벡터 형식을 지원하는 다른 타사 작도 소프트웨어를 직접 지정할 수도 있습니다. 연구자는 설정에서 작도 소프트웨어 프로그램 경로만 지정하면 됩니다.
   ![tutorial_plot8](/img/v0.9.0/en-US/export_diagram.webp)

### 보충 설명

도해 템플릿 자체는 다국어 전환을 지원합니다. 즉, 하나의 도해를 여러 언어 버전으로 전환하여 국제화 필요를 충족합니다.

예를 들어 중국 학술지에 발표하는 논문의 도해에는 중국어 버전이 필요하고, 영어 SCI/IE 등의 학술지에 발표할 때는 영어 버전의 도해가 필요합니다. 도해 도구 모음 오른쪽 위의 도해 언어 전환을 클릭하면 해당하는 언어 버전의 도해로 한 번에 전환할 수 있습니다.

# CIPW 표준 광물 계산

**CIPW 표준 광물 계산**은 전암 주원소 산화물(wt%)을 이상화된 표준 광물 한 세트로 환산합니다. 결과는 화성암 비교, 규소 포화도와 알루미늄 포화도 판별에 씁니다. CIPW Norm은 Cross, Iddings, Pirsson, Washington이 1902년에 제안했습니다. 이 모듈은 Excel형 표에서 일괄 계산하고, 각 행의 진단과 질량 수지를 제시합니다.

## 화면

페이지는 위쪽 막대와 데이터 워크시트로 이루어집니다. 위쪽 막대 왼쪽은 **Fe³⁺/ΣFe**이고, 오른쪽은 **설명**, **예제**, **내보내기**, **지우기**, **계산 실행**입니다.

워크시트는 왼쪽에서 오른쪽으로 네 구간으로 나뉘며, 열 머리 위에 그룹 이름이 있습니다.

| 영역 | 그룹 | 단위 | 역할 |
| --- | --- | --- | --- |
| 시료 | — | — | 시료 이름. 식별용일 뿐 계산에 참여하지 않습니다. 이 열은 고정되어, 가로로 스크롤해도 보입니다 |
| 산화물 | 주원소, 기타 산화물 / 휘발분 | wt% | 흰색 입력 영역 |
| 진단 | 진단 | — | `SiO2 포화도`, `Al2O3 상태`, `질량 균형 오차(%)` |
| 표준 광물 | CIPW 표준 광물 | wt% | 옅은색 결과 영역. 표 머리는 약어에 한국어 이름을 붙입니다. 예: `Q(석영)` |

입력 영역과 결과 영역 사이에는 좁은 구분 열이 있습니다. 결과 열은 계산 전에는 비어 있습니다. 표는 처음에 500행을 제공합니다. 채우기 핸들을 두 번 클릭하면 Excel처럼 아래로 채울 수 있습니다.

### 위쪽 막대

| 컨트롤 | 역할 |
| --- | --- |
| **Fe³⁺/ΣFe** | 전철 `FeOT`를 사용할 때만, 이 비율로 FeO와 Fe₂O₃를 나눕니다. 범위는 `0`–`1`이고, 기본값은 `0.15`(Le Maitre, 2002)이며, 소수점 두 자리로 표시합니다 |
| **설명** | 소프트웨어 안의 알고리즘 설명을 엽니다 |
| **예제** | 화강암, 현무암, 안산암의 세 행 예제를 채우며, 실측 Fe₂O₃, FeO, MnO를 포함합니다 |
| **내보내기** | 현재 표를 UTF-8 CSV로 저장합니다. 기본 파일 이름은 `CIPW_Results.csv`입니다 |
| **지우기** | 확인 후 모든 입력, 결과, 계산 세부 내용을 지웁니다 |
| **계산 실행** | 유효한 산화물이 있는 모든 행을 계산합니다 |

### 행 머리 상태

행 번호 옆의 원형 표시는 그 행의 상태를 나타냅니다.

| 원형 표시 | 의미 |
| --- | --- |
| 회색 빈 원 | 입력은 있으나 아직 계산하지 않았습니다 |
| 청록색 채운 원 | 계산에 성공했고, 경고가 없으며 질량 수지도 통과했습니다 |
| 주황색 채운 원 | 계산에는 성공했으나 경고가 있거나, 질량 균형 오차가 `1×10⁻⁶`보다 큽니다 |
| 빨간색 채운 원 | 그 행의 계산에 실패했습니다. 진단 열에 "오류"와 이유가 적힙니다 |
| 주황색 빈 원 | 계산 뒤에 산화물을 다시 고쳐, 현재 결과가 만료되었습니다 |

예제 데이터에는 모두 MnO가 있습니다. MnO는 FeO에 합쳐지며 경고를 만들므로, 예제 행은 계산 뒤 주황색이 됩니다. 이것은 예상된 결과입니다. 시료 이름을 수정해도 결과는 만료되지 않습니다. 산화물 입력 중 하나라도 수정하면 만료됩니다.

## 입력

각 행은 전암 시료 하나이며, 산화물의 질량 백분율(wt%)을 입력합니다. 소프트웨어는 **0보다 큰** 셀만 읽습니다. 빈 칸과 0은 모두 제공되지 않은 것으로 봅니다. 빈 행은 자동으로 건너뜁니다.

스프레드시트에서 바로 붙여 넣을 수 있습니다. 열 순서는 고정되어 있으므로, 붙여 넣을 때 아래 표 머리에 맞춥니다.

### 산화물 열

주원소:

`SiO2`, `TiO2`, `Al2O3`, `Fe2O3`, `FeO`, `FeOT`, `MnO`, `MgO`, `CaO`, `Na2O`, `K2O`, `P2O5`

기타 산화물 / 휘발분:

`ZrO2`, `Cr2O3`, `CO2`, `S`, `F`, `Cl`, `SO3`

`FeOT`는 FeO 당량으로 나타낸 전철입니다. `S`, `F`, `Cl`은 원소 질량 백분율로 입력합니다.

### 철의 처리

| 입력 상황 | 처리 |
| --- | --- |
| `FeO`와 `Fe2O3`가 함께 있고 `FeOT`는 없음 | 실측 배분을 사용합니다. 철 처리 모드는 "실측값"입니다 |
| `FeO`만 있거나 `Fe2O3`만 있음 | 없는 항목은 0으로 두고, 모드는 "부분 가정"이며, 경고를 냅니다 |
| `FeOT`만 있음 | Fe³⁺/ΣFe로 나눕니다. 모드는 "FeOT에서 추정"입니다 |
| `FeOT`가 `FeO` 또는 `Fe2O3`와 함께 있음 | `FeOT`를 무시합니다. 모드는 "입력 불일치"이며, 경고를 냅니다 |
| 철 데이터가 전혀 없음 | FeO와 Fe₂O₃를 모두 0으로 둡니다. 모드는 "누락"이며, 경고를 냅니다 |

`FeOT`만 있을 때의 분리는 다음과 같습니다.

```text
Fe2O3 = FeOT × (Fe³⁺/ΣFe) × 1.11134
FeO   = FeOT × (1 − Fe³⁺/ΣFe)
```

계수 `1.11134`는 Fe₂O₃ 대 FeO 두 배의 몰 질량 비에 해당하며, 3가 철을 FeO 당량에서 Fe₂O₃ 질량 백분율로 되돌리는 데 씁니다.

`MnO`는 계산 전에 몰 질량 비로 FeO 당량으로 바꾸어 FeO에 더합니다.

```text
FeO 당량 = MnO × 71.844 / 70.937
```

MnO를 입력하기만 하면, 계산 세부 내용에 "MnO가 몰비에 따라 FeO 당량으로 변환되었습니다"가 나타납니다.

## 출력

### 진단 열

| 열 | 값 |
| --- | --- |
| **SiO2 포화도** | 과포화, 포화, 불포화 |
| **Al2O3 상태** | 과알칼리질, 준알루미나질, 과알루미나질 |
| **질량 균형 오차(%)** | 광물 질량과 입력 산화물의 닫힘 편차입니다. `0.01`보다 작으면 과학적 기수법을 쓰고, 그렇지 않으면 소수점 4자리를 유지합니다 |

세 포화도의 의미는 다음과 같습니다.

- **과포화**: 배분이 끝난 뒤에도 SiO₂가 남아, 석영 `Q`로 기록됩니다.
- **포화**: SiO₂가 딱 맞게 소진되어, 석영도 없고 탈규산도 필요하지 않습니다.
- **불포화**: SiO₂가 부족하여 아래의 탈규산 반응으로 들어갑니다. 반응 사슬 전체를 거쳐도 규소 결손을 없애지 못하면 경고를 추가하고, 잔여 결손(mol/100 g)을 설명합니다. 이때의 표준 광물은 신뢰할 수 없습니다.

알루미늄 포화 상태는 장석 배분 전에, 그때 남은 산화물의 몰수로 판단합니다.

- **과알칼리질**: Na₂O + K₂O > Al₂O₃
- **과알루미나질**: Al₂O₃ / (CaO + Na₂O + K₂O) > 1
- **준알루미나질**: 그 밖의 경우

인회석, 방해석, 형석, 암염, 망초가 이미 해당하는 CaO 또는 Na₂O를 먼저 소모했으므로, 여기서 쓰는 것은 남은 양입니다.

### 표준 광물

결과는 아래 순서로 나열합니다. 이름은 다음과 같습니다.

| 약어 | 광물 | 약어 | 광물 |
| --- | --- | --- | --- |
| `Q` | 석영 | `Fo` | 고토감람석 |
| `Or` | 정장석 | `Fa` | 철감람석 |
| `Ab` | 조장석 | `Mt` | 자철석 |
| `An` | 회장석 | `Hm` | 적철석 |
| `Le` | 백류석 | `Ilm` | 티탄철석 |
| `Ne` | 하석 | `Cm` | 크롬철석 |
| `Kp` | 의사류장석 | `Ru` | 금홍석 |
| `Cor` | 강옥 | `Tn` | 티타나이트 |
| `Ac` | 에기린 | `Pf` | 페로브스카이트 |
| `Di` | 투휘석 | `Z` | 지르콘 |
| `Hd` | 헤덴버자이트 | `Ap` | 인회석 |
| `Wo` | 규회석 | `Cc` | 방해석 |
| `Cs` | 란스트 | `Py` | 황철석 |
| `En` | 완화휘석 | `Fl` | 형석 |
| `Fs` | 철휘석 | `Hl` | 암염 |
| `ns` | 메타규산나트륨 | `Th` | 망초 |
| `ks` | 메타규산칼륨 | | |

정장석, 조장석, 에기린은 내부에서 화학식 단위로 셉니다. 1 mol K₂O는 2 mol `Or`를 만들고, 1 mol Na₂O는 2 mol `Ab` 또는 `Ac`를 만듭니다. 적어 내는 것은 항상 질량 백분율입니다.

## 계산 세부 내용

계산에 성공한 행을 선택하면 오른쪽 검사기에 다음이 표시됩니다.

- 시료 이름. 시료 열이 비어 있으면 "N행"으로 표시합니다.
- 규소 포화도와 알루미늄 포화도. 불포화이면 규소 포화도를 강조합니다.
- **철 처리 모드**. "실측값"이 아니면 강조합니다.
- **질량 균형 오차**. 소수점 6자리를 유지합니다. `1×10⁻⁶`을 넘으면 강조합니다.
- **광물 총량**. 각 표준 광물 wt%의 합이며, 소수점 4자리를 유지합니다. 황철석, 형석, 암염이 형성될 때 방출된 산소는 이 총량에 넣지 않으나, 질량 수지에는 넣습니다.
- **주요 광물**: 함량이 `0.01 wt%`보다 큰 광물을 높은 쪽부터 배열합니다. `10 wt%`보다 큰 항목은 강조합니다.
- **경고**: 철 데이터 누락 또는 불일치, FeOT에 의한 추정, MnO 환산, 잔여 규소 결손 등.

검사기 오른쪽 위에서는 이 세부 내용을 CSV로 내보내거나 클립보드에 복사할 수 있습니다.

## 계산 과정

아래는 현재 계산 코드의 실제 순서입니다. 인회석이 칼슘을 가장 먼저 차지하고, 그다음에 휘발분 광물이 형성됩니다. 티타나이트와 금홍석은 회장석 뒤에 둡니다.

광물 몰 질량은 모두 산화물 몰 질량에서 화학식으로 유도하여, 수동 반올림으로 질량이 맞지 않는 일을 피합니다. 계산에 쓰는 수치 허용 오차는 `1×10⁻¹²`입니다. 어느 단계에서든 SiO₂ 이외의 산화물이 뚜렷한 음수가 되면 그 행은 실패합니다.

### 1. 무수 정규화와 철, 망가니즈

제공되었고 음수가 아닌 모든 산화물을 100%로 정규화합니다. 이전 절에 따라 철을 처리한 뒤 MnO를 FeO 당량으로 바꾸고, **다시 한 번 정규화합니다**. 총량이 0보다 크지 않으면 그 행은 실패합니다.

### 2. 몰수로 환산

각 산화물의 몰수 = 정규화 뒤의 wt% / 몰 질량입니다. 이후의 배분은 모두 mol/100 g 척도에서 진행합니다.

### 3. 인회석

인회석이 칼슘을 가장 먼저 차지합니다. 1 mol `P2O5`는 `10/3` mol `CaO`와 결합합니다(OH 또는 F는 포함하지 않습니다).

```text
Ap = min(P2O5, CaO / (10/3))
```

### 4. 휘발분 광물

아래 순서대로, 결합할 수 있는 만큼 생성합니다.

| 광물 | 화학량 |
| --- | --- |
| 방해석 `Cc` | `min(CO2, CaO)` |
| 형석 `Fl` | `min(F/2, CaO)`. 즉 1 mol CaO가 2 mol F와 결합합니다 |
| 황철석 `Py` | `min(S/2, FeO)`. 즉 1 mol FeO가 2 mol S와 결합합니다 |
| 암염 `Hl` | `min(Cl, 2×Na2O)` |
| 망초 `Th` | `min(SO3, Na2O)` |

### 5. 지르콘, 크롬철석, 티탄철석

- 지르콘 `Z`: `ZrO2` 전부와 같은 양의 `SiO2`.
- 크롬철석 `Cm`: `min(Cr2O3, FeO)`.
- 티탄철석 `Ilm`: `min(TiO2, FeO)`.

이 단계에서는 FeO와 결합할 수 있는 타이타늄만 씁니다. 남은 TiO₂는 회장석 뒤로 남깁니다.

### 6. 장석, 강옥, 남은 알칼리

먼저 알루미늄 포화 상태를 기록한 뒤 배분합니다.

| 광물 | 조건과 생성물 |
| --- | --- |
| 정장석 `Or` | `min(K2O, Al2O3)`. SiO₂를 6배 소모하고, 생성물 몰수는 그 값의 2배입니다 |
| 조장석 `Ab` | `min(Na2O, Al2O3)`. 마찬가지로 SiO₂를 6배 소모하고, 생성물은 2배입니다 |
| 회장석 `An` | `min(CaO, Al2O3)`. SiO₂를 2배 소모합니다 |
| 강옥 `Cor` | 남은 Al₂O₃ |
| 에기린 `Ac` | `min(남은 Na2O, Fe2O3)`. SiO₂를 4배 소모하고, 생성물은 2배입니다 |
| 메타규산나트륨 `ns` | 남은 Na₂O와 같은 양의 SiO₂ |
| 메타규산칼륨 `ks` | 남은 K₂O와 같은 양의 SiO₂ |

장석 단계에서는 SiO₂를 일단 음수로 적어 두고, 뒤의 탈규산에서 한꺼번에 처리합니다.

### 7. 티타나이트와 금홍석

티타나이트는 회장석 뒤에 남은 CaO만 쓰며, **그때의 SiO₂ 잔량으로 티타나이트를 제한하지 않습니다**.

```text
Tn = min(남은 TiO2, 남은 CaO)
```

`Tn`은 동시에 같은 양의 SiO₂를 소모합니다. 마지막까지 남은 TiO₂는 금홍석 `Ru`로 기록합니다.

### 8. 철 산화물

```text
Mt = min(Fe2O3, FeO)
Hm = 남은 Fe2O3
```

### 9. 휘석과 규회석

`MgFe = MgO + FeO`로 둡니다. 단사휘석 총량은 `min(CaO, MgFe)`이며, 다시 마그네슘·철 비에 따라 투휘석 `Di`와 헤덴버자이트 `Hd`로 나눕니다. 휘석 1몫은 SiO₂ 2몫을 소모합니다.

남은 MgO와 FeO는 모두 완화휘석 `En`과 철휘석 `Fs`가 되며, 각각 SiO₂ 1몫을 소모합니다. 마그네슘과 철이 모두 소진된 뒤에도 CaO가 남아 있으면, 전부 규회석 `Wo`가 됩니다.

### 10. 규소 포화도와 탈규산

탈규산 순서는 자소휘석 → 티타나이트 → 조장석 → 정장석 → 규회석 → 투휘석/헤덴버자이트 → 백류석입니다. 각 단계는 그때 아직 부족한 SiO₂만 소모합니다.

| 순서 | 반응 | 방출되는 SiO₂ |
| --- | --- | --- |
| 1 | 완화휘석/철휘석 2 → 고토감람석/철감람석 1 | 휘석 2 mol마다 1 mol 방출 |
| 2 | 티타나이트 `Tn` → 페로브스카이트 `Pf` | 1 mol `Tn`이 1 mol 방출 |
| 3 | 조장석 `Ab` → 하석 `Ne` | 1 mol `Ab`가 2 mol 방출 |
| 4 | 정장석 `Or` → 백류석 `Le` | 1 mol `Or`가 1 mol 방출 |
| 5 | 규회석 `Wo` 2 → 란스트 `Cs` 1 | `Wo` 2 mol마다 1 mol 방출 |
| 6 | 투휘석/헤덴버자이트 → 란스트 + 감람석 | 휘석 1 mol이 1 mol 방출. 마그네슘은 `Fo`로, 철은 `Fa`로 들어갑니다 |
| 7 | 백류석 `Le` → 의사류장석 `Kp` | 1 mol `Le`가 1 mol 방출 |

SiO₂가 남으면 석영이 생성되고, 상태는 과포화입니다. SiO₂가 정확히 0이면 포화입니다. 위 표로 들어가면 불포화입니다.

### 11. 질량 백분율과 질량 수지

표준 광물 질량 = 몰수 × 화학식에서 유도한 몰 질량이며, 다시 정규화 뒤의 산화물 총량에 대한 wt%로 바꿉니다.

황철석, 형석, 암염 안의 S, F, Cl은 산화물 안의 산소를 치환했습니다. 방출된 산소는 어떤 광물에도 들어가지 않으므로, 질량 수지에서 다시 더합니다.

```text
방출 산소의 몰수 = Fl + Py + Hl / 2
질량 균형 오차 = |100 − (광물 wt%의 합 + 방출 산소의 wt%)|
```

오차가 `1×10⁻⁶`보다 크면 그 행을 경고로 기록합니다.

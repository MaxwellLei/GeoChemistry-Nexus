# 설정

소프트웨어의 설정은 매우 다양하며, 기능이 확장됨에 따라 더 많은 개인화 옵션이 계속 추가됩니다.

## 일반 프로그램 설정

설정은 크게 네 부분으로 나뉩니다. 파일 경로, 국제화와 개인화, 메시지 알림, 기타입니다. 아래는 주요 설정에 대한 간단한 설명입니다.

### 🌍 언어와 모양

-   **언어**: 현재 중국어(간체), 중국어(번체), 영어, 독일어, 스페인어, 일본어, 한국어, 러시아어, 프랑스어, 포르투갈어를 지원합니다.
-   **UI 배율**: 해상도가 다른 화면을 위한 배율 설정입니다. 일반적으로 기본값으로 충분합니다.

:::info

언어 지원에 관하여, 해당 국가의 현지화를 돕고 싶다면 번역 작업에 참여해 주시기를 열렬히 바랍니다. 현재 번역의 대부분은 AI의 도움을 받았으므로 일부는 정확하지 않을 수 있습니다. 도움이 절실히 필요하며, 감사드립니다.

:::

### 🗨️ 메시지 알림

-   **자동 닫기 시간**: 소프트웨어가 실행되는 동안 메시지 알림 팝업이 자동으로 닫히는 시간입니다. 오류와 경고 메시지는 직접 닫아야 합니다.

### ⚙️ 기타

-   **시스템과 함께 시작**: 시스템이 시작될 때 소프트웨어가 자동으로 시작됩니다.
-   **업데이트 자동 확인**: 소프트웨어가 시작될 때 업데이트를 자동으로 확인합니다.
-   **종료 방식**: 소프트웨어는 두 가지 방식으로 종료할 수 있습니다. 바로 종료하거나, 시스템 트레이로 최소화합니다. 트레이로 최소화를 선택하면, 트레이 아이콘을 마우스 오른쪽 단추로 클릭하고 종료를 선택하여 소프트웨어를 닫습니다.

## 작도 모듈 설정

작도 모듈 설정은 작도 모듈 안의 기능을 대상으로 하며, 다음을 포함하되 이에 국한되지 않습니다.

*   타사 프로그램 경로 구성
*   기본 타사 프로그램
*   도해 기본 로드 언어
*   도해 템플릿과 분류 구조의 자동 업데이트

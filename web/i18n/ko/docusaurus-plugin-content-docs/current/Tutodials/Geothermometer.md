# 지질 온압계

초기 버전에서 이 모듈의 약칭은 **GTM**이었습니다. 이후 지질 온도계로 바뀌었고, 지금은 정식 명칭이 지질 온압계입니다.

이전 버전에는 지르콘, 섬아연석, 석영, 제노타임, 녹니석, 흑운모 등의 지질 온도계 계산이 포함되어 있었습니다. 새 버전의 지질 온압계는 아직 업데이트와 적응을 진행 중이며, 곧 맞춰 제공할 예정입니다.

## 화면

지질 온압계 모듈은 전체적으로 두 부분으로 나뉩니다.

1. 왼쪽은 **온압계 템플릿 목록**입니다. 여기서 적합한 온압계 템플릿을 찾거나, 온압계 계산 템플릿을 직접 만들 수 있습니다.
2. 오른쪽은 **현재 선택한 온압계 템플릿의 도움말 설명 문서**입니다.

## 기능

지질 온압계 모듈은 처음부터 **Excel 형식을 본떠**, 사용자가 처음 익히는 부담을 낮추도록 설계했습니다. **온압계를 쓰는 방식은 주로 두 가지입니다**.

1. **온라인 온압계 템플릿**: 기본 **온라인 온압계 템플릿**은 사용자가 수정할 수 없으나, 알고리즘 구현 논리는 볼 수 있습니다. 소프트웨어를 업데이트하지 않아도 네트워크에 연결하여 더 새로운 지질 온압계 템플릿을 받을 수 있습니다. 연구자는 검색하고, 거르고, 자신에게 맞는 템플릿을 선택한 뒤, 안내 내용에 따라 데이터를 입력하고 계산합니다. **이 방식은 더 직접적이고 빠르며, 프로그래밍 지식이 필요하지 않습니다**.
2. **독립 계산 창**: 연구자는 위쪽 메뉴 막대에서 **파일 -> 독립 표 열기**를 선택하여 독립 계산 창을 열 수 있습니다. 독립 창에서는 서로 다른 지질 온압계를 조합하여 계산하도록 직접 프로그래밍할 수 있습니다. 온압계별 함수는 고급 자습서 부분을 참고해 주십시오. **이 방식은 더 복잡하고, 상대적으로 유연합니다**.

물론 지질 온압계 모듈에서는 연구자가 사용자 지정 지질 온압계를 직접 만들 수도 있습니다. 만든 지질 온압계 템플릿을 내보내 다른 연구자가 바로 쓰도록 배포할 수 있습니다.

## 사용 예시

### 온라인 온압계 템플릿 사용

먼저 지질 온도계 모듈 안에서 왼쪽 옆 막대로 걸러 해당 계산 템플릿을 선택합니다.

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/select_and_apply_thermobarometer_template.webp')}
    alt="지질 온압계 선택"
    style={{width: '100%'}}
  />
</div>

오른쪽 패널에서 해당 템플릿의 설명 문서를 볼 수 있으며, 위쪽 막대에는 현재 선택한 지질 온압계 템플릿의 제목과 태그가 표시됩니다. 해당하는 온압계 템플릿을 선택한 뒤, 위쪽 막대의 **적용** 단추를 클릭하여 온압계 계산 화면으로 들어갑니다.

온압계 화면에는 해당하는 입력 열이 있습니다. 위쪽 막대의 **예제** 단추를 클릭하여 예제 데이터를 불러올 수도 있습니다. 열 제목의 요구에 따라 해당 데이터를 입력한 뒤, **계산식을 복사**하거나 **"클릭하여 끌기" 채우기 핸들**(Excel과 유사)로 계산을 자동으로 마칩니다(아래 애니메이션 예시와 같습니다).

### 독립 창의 사용자 지정 함수

앞에서 설명한 대로, 메뉴 막대에서 **파일 -> 자유 표 열기**를 선택하여 독립 자유 창을 열 수 있습니다.

독립 창의 표는 빈 표이며, 몇 가지 간단한 도구 막대 단추를 포함합니다.

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/thermobarometer_free_form.webp')}
    alt="온압계 자유 계산 표"
    style={{width: '100%'}}
  />
</div>

독립 창 표는 일상에서 **Excel 표를 쓰는 것과 같습니다. 임의의 값을 입력하고, `=함수 이름(전달 인자)`를 입력하여 함수를 호출합니다**.

다른 점은, 지질 온압계 계산이 해당하는 계산 함수로 등록되어 있어, 연구자가 필요에 따라 계산 내용을 더 유연하게 직접 정의할 수 있다는 것입니다. **같은 표에서 여러 온압계 결과를 비교**할 수도 있습니다.

:::note

**독립 창 표에서는 해당 데이터 행의 중간 계산 과정을 볼 수 없습니다**.

:::

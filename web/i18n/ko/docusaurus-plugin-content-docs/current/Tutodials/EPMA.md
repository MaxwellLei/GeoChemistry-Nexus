# EPMA 광물 계산

**EPMA 광물 계산**은 전자현미분석으로 얻은 광물 성분을 처리합니다. 여러 분석점의 산화물 함량을 선택한 광물 계산 방법으로 광물 화학 결과로 환산하여, 광물 감정, 성분 비교, 이후 지질 해석에 사용합니다.

## 화면

EPMA 광물 계산은 **EPMA 광물 계산 템플릿 라이브러리**와 **EPMA 계산 화면**의 두 화면으로 나뉩니다.

템플릿 라이브러리에서 검색하고 걸러 알맞은 광물 EPMA 계산을 고를 수 있습니다. 맨 오른쪽 설명 패널에서 그 계산 템플릿의 기본 정보를 볼 수 있습니다. **계산으로 이동**을 누르면 계산을 시작합니다.

## 사용 예

예를 들어 감람석 EPMA 계산 템플릿을 고르고 계산 화면으로 들어갑니다. 화면은 위와 아래로 나뉘며, 위쪽 막대에서 그 템플릿의 자세한 설명 문서를 보거나 예제 데이터를 불러올 수 있습니다.

표에서 요구하는 데이터를 입력한 뒤 위쪽 막대의 **계산 실행**을 누릅니다.

흰색에 가까운 회색 영역이 입력 영역이고, 청자색 영역이 결과 출력 영역입니다. 출력을 자유롭게 보거나 **검사**를 눌러 중간 계산 과정을 볼 수 있습니다.

각 행 머리 앞의 색 점은 그 행의 계산 상태를 나타냅니다.

* **회색**: 그 행에 데이터는 있지만 아직 계산하지 않음
* **녹색**: 정상적으로 계산이 끝났고 경고와 오류가 없음
* **주황색**: 계산은 끝났지만 경고가 있음
* **빨간색**: 그 행의 계산이 실패함

# Niggli 표준 광물 계산

**Niggli 표준 광물 계산**은 같은 행의 전암 산화물에 대해 두 세트의 결과를 만듭니다.

1. **니글리 값**: `si`, `al`, `fm`, `c`, `alk`, `k`, `mg`, `qz`. 계산 세부 내용에만 표시되는 `ti`, `p`도 있습니다.
2. **Barth–Niggli 분자 표준 광물(Catanorm)**: 양이온 백분율(cat%)로 나타낸 표준 광물, 단성분 조성, 그리고 규소가 불포화일 때의 탈규산 과정입니다.

Catanorm은 Paul Niggli(1948)와 Tom F. W. Barth(1948)가 확립했습니다. 양이온 당량으로 배분하여 철 같은 무거운 원소가 질량 백분율에서 차지하는 비중을 줄이므로, CIPW의 wt%보다 박편에서 보는 광물 부피 관계에 더 가깝습니다. 질량 백분율 표준 광물은 [CIPW 표준 광물 계산](./CIPW)을 참고해 주십시오.

알고리즘은 GCDkit의 분자 표준 광물 절차를 참고하여 다시 구현했습니다. 그중 백류석을 더 탈규산한 생성물은 칼리오필라이트 `Kp`에 기록합니다.

## 화면

위쪽 막대는 CIPW와 같습니다. **Fe³⁺/ΣFe**, **설명**, **예제**, **내보내기**, **지우기**, **계산 실행**입니다. Fe³⁺/ΣFe의 범위는 `0`–`1`이고, 기본값은 `0.15`(Le Maitre, 2002)입니다.

**예제**는 세 행을 채웁니다. 화강암, 현무암, 포놀라이트(Phonolite)입니다. 앞의 두 행은 규소가 비교적 높은 흔한 화산암이고, 포놀라이트는 하석, 백류석 같은 불포화 결과를 보는 데 씁니다.

워크시트는 왼쪽에서 오른쪽으로 다섯 구간으로 나뉩니다.

| 영역 | 그룹 | 단위 | 내용 |
| --- | --- | --- | --- |
| 시료 | — | — | 시료 이름. 계산에 참여하지 않으며, 가로로 스크롤해도 보입니다 |
| 산화물 | 주원소, 기타 산화물 / 휘발분 | wt% | 입력 영역 |
| 니글리 값 | 니글리 값 | 무차원 | `si`, `al`, `fm`, `c`, `alk`, `k`, `mg`, `qz` |
| 진단 | 진단 | — | 규소 포화 상태, 알루미늄 포화 상태, 광물 총합 |
| 표준 광물 | 표준 광물 | cat% | 양이온 백분율. 마지막 열은 `Sum(합계)`입니다 |

시료 열은 고정됩니다. 표는 처음에 500행이며, 채우기 핸들을 두 번 클릭하여 아래로 채울 수 있습니다. 입력이 바뀌면 이미 계산한 행은 만료 상태가 되므로, **계산 실행**을 다시 클릭해야 합니다.

### 행 머리 상태

| 원형 표시 | 의미 |
| --- | --- |
| 회색 빈 원 | 입력은 있으나 아직 계산하지 않았습니다 |
| 청록색 채운 원 | 계산에 성공했고 경고가 없습니다 |
| 주황색 채운 원 | 계산에는 성공했으나 FeOT로 철의 원자가를 추정했습니다 |
| 빨간색 채운 원 | 계산에 실패했습니다. 진단 열에 "계산 오류"와 이유가 적힙니다 |
| 주황색 빈 원 | 계산 뒤에 산화물을 수정하여 결과가 만료되었습니다 |

FeO와 Fe₂O₃를 함께 입력한 시료는 계산에 성공하면 청록색 점입니다. FeOT만 있으면 철 원자가 경고가 나타나고, 행 머리는 주황색입니다.

## 입력

각 행은 시료 하나이며, 단위는 산화물 질량 백분율(wt%)입니다. 0보다 큰 셀만 읽습니다. 빈 칸과 0은 제공되지 않은 것으로 봅니다.

주원소는 `K2O`까지입니다.

`SiO2`, `TiO2`, `Al2O3`, `Fe2O3`, `FeO`, `FeOT`, `MnO`, `MgO`, `CaO`, `Na2O`, `K2O`

기타 산화물 / 휘발분:

`CO2`, `P2O5`, `F`, `S`

이 모듈은 `ZrO2`, `Cr2O3`, `Cl`, `SO3`를 읽지 않습니다. 이 네 항목을 표준 광물에 넣으려면 CIPW 모듈을 사용합니다.

### 철의 처리

철은 양이온으로 바꾸기 전에 처리합니다. 나눌 때는 철을 먼저 Fe 원자로 환원합니다. 전철 몰수 = 철의 질량 / FeO 몰 질량이며, 다시 Fe³⁺/ΣFe에 따라 3가와 2가로 나누고, 3가 철의 절반을 Fe₂O₃에 기록합니다.

| 입력 상황 | 처리 |
| --- | --- |
| `Fe2O3`와 `FeO`가 함께 있음 | 실측값을 사용합니다. 옆에 `FeOT`가 있어도 다시 나누지 않습니다 |
| `FeOT`가 있고, Fe₂O₃와 FeO를 동시에 갖추지 않음 | `FeOT`를 현재 비율로 나누고, 세부 내용에 경고를 남깁니다 |
| `Fe2O3`만 있고 `FeO`도 `FeOT`도 없음 | 이 Fe₂O₃를 전철로 보고, 다시 비율에 따라 Fe₂O₃와 FeO로 나눕니다 |
| `FeO`만 있고 `Fe2O3`도 `FeOT`도 없음 | 이 FeO를 전철로 보고, 다시 비율에 따라 Fe₂O₃와 FeO로 나눕니다 |

따라서 FeO만 분석했거나 Fe₂O₃만 분석했으면, 결과는 위쪽 막대의 비율에 따라 달라집니다. 두 항목이 모두 실측값이면 두 열을 모두 입력해 주십시오.

`MnO`는 양이온 환산까지 유지합니다. 니글리 값의 `fm`과 `mg`에 들어가고, Catanorm에서는 Fe²⁺에 합쳐집니다.

## 니글리 값

매개변수는 산화물의 **분자 수**로 계산합니다. 분자 수 = wt% / 몰 질량입니다. 여기서 `al`은 Al₂O₃의 분자 수이며, Al₂O₃ 1몫을 1로 셉니다. 뒤의 Catanorm에서 "Al₂O₃ 1몫을 Al 2개로 세는 것"과는 기준이 다릅니다.

```text
al  = n(Al2O3)
fm  = n(FeO) + 2 n(Fe2O3) + n(MnO) + n(MgO)
c   = n(CaO)
alk = n(Na2O) + n(K2O)
base = al + fm + c + alk

si  = 100 × n(SiO2) / base
al, fm, c, alk도 마찬가지로 base에 대한 100분율로 환산합니다
ti  = 100 × n(TiO2) / base
p   = 100 × n(P2O5) / base
k   = n(K2O) / (n(Na2O) + n(K2O))
mg  = n(MgO) / (n(MgO) + n(FeO) + 2 n(Fe2O3) + n(MnO))
```

석영 지수 `qz`:

```text
al > alk  일 때    qz = si − (100 + 4 al)
al ≤ alk  일 때    qz = si − (100 + 3 al + alk)
```

두 번째 식은 알루미늄이 알칼리를 넘지 않는 시료에 씁니다. 소프트웨어 안의 "설명" 창에는 첫 번째 식만 나열되어 있습니다.

`si`, `al`, `fm`, `c`, `alk`, `ti`, `p`, `qz`는 소수점 2자리를 유지하고, `k`와 `mg`는 소수점 3자리를 유지합니다. 표에는 앞 그룹의 여덟 열만 둡니다. `ti`와 `p`는 계산 세부 내용에 있습니다. `qz`가 양수이면 세부 내용에서 양수 기호를 붙입니다.

`al + fm + c + alk`는 표에서 100이어야 합니다. `si`는 100보다 훨씬 클 수 있습니다. 규소는 이 100분율 안에 있지 않기 때문입니다. `k`와 `mg`는 0에서 1 사이의 비입니다.

## 진단 열

| 열 | 의미 |
| --- | --- |
| **규소 포화 상태** | 규소 과포화, 규소 포화, 규소 불포화 |
| **알루미늄 포화 상태** | 과알루미나질, 준알루미나질, 과알칼리질 |
| **광물 총합** | Catanorm 양이온 백분율의 합. 소수점 2자리를 유지합니다 |

규소 포화 상태는 최종 광물로 판정하며, 문턱값은 `0.001 cat%`입니다.

- 석영 `Q`가 있음: 규소 과포화.
- 석영은 없으나 하석 `Ne`, 백류석 `Lc`, 칼리오필라이트 `Kp` 또는 감람석 `Ol`이 있음: 규소 불포화.
- 그 밖: 규소 포화.

`qz`의 양과 음은 규소가 니글리 기준에 비해 남는지 부족한지를 보는 데 씁니다. 표의 "규소 포화 상태"는 표준 광물을 봅니다. 두 열은 서로 대조할 수 있으며, 판정 기준은 다릅니다.

알루미늄 포화 상태는 정규화 뒤의 양이온으로 판단하며, 광물 배분 전에 일어납니다.

- **과알루미나질**: Al > Na + K + Ca
- **준알루미나질**: Na + K < Al ≤ Na + K + Ca
- **과알칼리질**: Al ≤ Na + K

## 표준 광물

광물 열의 단위는 양이온 백분율입니다. `Plag`는 `Ab + An`과 같고, 합계 `Sum`은 `Plag`를 넣으며 `Ab`와 `An`을 다시 더하지 않습니다. 닫힘 정도를 확인할 때는 `Sum` 또는 진단 열의 광물 총합을 봅니다.

| 약어 | 광물 | 약어 | 광물 |
| --- | --- | --- | --- |
| `Q` | 석영 | `Hy` | 사방휘석 |
| `C` | 강옥 | `Ol` | 감람석 |
| `Or` | 정장석 | `Cs` | 랑키나이트 |
| `Plag` | 사장석 | `Wo` | 규회석 |
| `Ab` | 조장석 | `Mt` | 자철석 |
| `An` | 회장석 | `Hm` | 적철석 |
| `Lc` | 백류석 | `Il` | 티탄철석 |
| `Ne` | 하석 | `Tn` | 티타나이트 |
| `Kp` | 칼리오필라이트 | `Pf` | 페로브스카이트 |
| `Ac` | 에기린 | `Ru` | 금홍석 |
| `Ns` | 메타규산나트륨 | `Ap` | 인회석 |
| `Ks` | 메타규산칼륨 | `Fr` | 형석 |
| `Di` | 투휘석 | `Py` | 황철석 |
| | | `Cc` | 방해석 |

단성분 비율은 결과 열을 따로 차지하지 않으며, 모두 계산 세부 내용에 적습니다.

## 계산 세부 내용

성공한 행을 선택하면 오른쪽 검사기가 여섯 구간으로 표시합니다.

1. **암석 분류와 포화 상태**: 규소 포화 상태, 알루미늄 포화 상태, 표준 광물 총합. 불포화이면 규소 포화도를 강조하고, 과알칼리질이면 알루미늄 포화도를 강조합니다.
2. **니글리 값**: `si`, `al`, `fm`, `c`, `alk`, `ti`, `p`, `k`, `mg`, `qz`.
3. **광물 단성분**. 해당하는 광물이 있을 때만 나타납니다.
   - 사장석 `An% = 100 × An / (Ab + An)`
   - 투휘석은 Wo 50%로 고정되고, 나머지 50%는 마그네슘·철 비에 따라 En과 Fs로 나뉩니다
   - 감람석 Fo, Fa. Fo는 아래의 마그네슘 지수와 같습니다
   - 마그네슘 지수 `Mgr = 100 × En / (En + Fs)`. 사방휘석이 투휘석에 합쳐지기 전에 계산합니다
4. **탈규산 반응 과정**: 규소가 남으면 석영의 cat%를 밝힙니다. 규소가 결손이면, 어떤 광물을 소모했는지, 결손이 이미 해소되었는지를 단계적으로 적습니다.
5. **주요 표준 광물**: `1 cat%`보다 큰 광물을 높은 쪽부터 나열하며, 중복되는 `Plag`는 넣지 않습니다. `10 cat%`보다 큰 항목은 강조합니다.
6. **경고**: 현재 구현은 FeOT로 철의 원자가를 추정할 때 경고를 기록합니다.

## 계산 과정

### 1. 양이온 기준

각 산화물은 먼저 양이온량으로 바뀝니다. `(wt% / 몰 질량) × 화학식 안의 양이온 수`입니다. SiO₂, TiO₂, FeO, MnO, MgO, CaO, CO₂, F, S의 양이온 수는 1이고, Al₂O₃, Fe₂O₃, Na₂O, K₂O, P₂O₅는 2입니다.

모든 양이온을 더한 뒤 그 합을 100으로 맞추어 Catanorm의 배분 풀로 삼습니다. 총합이 0에 가까우면 그 행은 실패하며, 양이온 총합이 부족하다고 알립니다. 이 단계에서는 산화물 wt%를 100으로 **정규화하지 않습니다**. 입력하지 않은 H₂O와 강열감량은 이 100에 들어가지 않습니다.

### 2. 부성분 광물과 염류

Mn을 먼저 Fe²⁺에 합칩니다. 이어서 양이온 화학량에 따릅니다.

| 순서 | 광물 | 화학량 요점 |
| --- | --- | --- |
| 1 | 방해석 `Cc` | 광물량 = `2 × CO2`. 같은 양의 Ca를 소모합니다 |
| 2 | 인회석 `Ap` | P가 F에 비해 적을 때 `Ap = 3P`이며, F의 일부를 소모합니다. 그렇지 않으면 남은 F를 모두 인회석에 넣습니다 |
| 3 | 형석 `Fr` | 남은 F: `Fr = 1.5 × F`. Ca를 `0.5 × F`만큼 소모합니다 |
| 4 | 황철석 `Py` | `Py = 1.5 × S`. Fe²⁺를 `0.5 × S`만큼 소모합니다 |
| 5 | 티탄철석 `Il` | Ti와 Fe²⁺ 중 적은 쪽이 생산량을 결정하며, 광물량은 그 양의 2배입니다 |

CO₂, P, F, S는 Ca 또는 Fe²⁺를 우선 차지합니다. 이 휘발분이 결합할 수 있는 양이온보다 뚜렷이 많으면, 뒤의 칼슘·마그네슘 광물이 왜곡되므로 광물 총합과 탈규산 기록으로 확인해 주십시오.

### 3. 장석, 준장석 전구체, 타이타늄 광물

배분 단위는 양이온입니다. 정장석, 조장석, 회장석은 단성분이 충분할 때 모두 양이온 5개씩 한 조입니다.

1. K가 Al, Si와 정장석 `Or`를 만듭니다(K 하나마다 Al 1개와 Si 3개를 짝짓습니다). 남은 K는 메타규산칼륨 `Ks`를 만듭니다.
2. Na가 Al, Si와 조장석 `Ab`를 만듭니다. 남은 Na는 다시 Fe³⁺와 에기린 `Ac`를 만듭니다(Na 하나마다 Fe³⁺ 1개와 Si 2개를 짝짓습니다). 그래도 남은 Na는 메타규산나트륨 `Ns`를 만듭니다.
3. 남은 Al이 Ca와 회장석 `An`을 만듭니다. Ca가 부족하면 알루미늄으로 제한하며, 제한이 되는 Al 하나마다 Ca 0.5개와 Si 1개가 대응합니다.
4. 남은 Ti가 Ca, Si와 티타나이트 `Tn`을 만듭니다(양이온 3개). 그래도 남은 Ti는 금홍석 `Ru`입니다.
5. 마지막까지 남은 Al은 강옥 `C`입니다.

### 4. 철 산화물과 휘석

Fe³⁺와 Fe²⁺가 자철석 `Mt`를 만듭니다. Fe³⁺가 Fe²⁺의 두 배를 넘지 않을 때 `Mt = 1.5 × Fe³⁺`입니다. 남은 Fe³⁺는 적철석 `Hm`입니다.

남은 Ca, Mg, Fe²⁺는 각각 규회석 `Wo`, 완화휘석 분자, 철휘석 분자가 됩니다. 각각 양이온 수의 2배이며, 같은 양의 Si 1몫을 소모합니다. 완화휘석 분자와 철휘석 분자를 더하면 사방휘석 `Hy`입니다. 이때 마그네슘 지수를 계산합니다.

`Wo`와 `Hy`는 다시 같은 양이온으로 결합하여 투휘석 `Di`가 됩니다. 적은 쪽은 모두 `Di`로 들어가고, `Di`의 양이온 수는 그것의 2배입니다. 많은 쪽은 `Wo` 또는 `Hy`로 남습니다.

### 5. 석영 또는 일곱 단계 탈규산

남은 Si ≥ 0이면 모두 석영 `Q`가 되고, 계산은 여기서 끝납니다.

Si < 0이면 결손 `D = −Si`입니다. 아래의 각 단계는 결손을 0까지 줄이고 끝나거나, 그 광물을 모두 쓴 뒤 다음 단계로 들어갑니다. 계수는 양이온 백분율입니다.

| 단계 | 반응 | Si 결손 1몫을 없앨 때 |
| --- | --- | --- |
| 1 | 사방휘석 → 감람석 | `Hy` 4를 소모하고 `Ol` 3을 생성합니다 |
| 2 | 티타나이트 → 페로브스카이트 | `Tn` 3을 소모하고 `Pf` 2를 생성합니다 |
| 3 | 조장석 → 하석 | `Ab` 2.5를 소모하고 `Ne` 1.5를 생성합니다 |
| 4 | 정장석 → 백류석 | `Or` 5를 소모하고 `Lc` 4를 생성합니다 |
| 5 | 백류석 → 칼리오필라이트 | `Lc` 4를 소모하고 `Kp` 3을 생성합니다 |
| 6 | 규회석 → 랑키나이트 | `Wo` 4를 소모하고 `Cs` 3을 생성합니다 |
| 7 | 투휘석 → 랑키나이트 + 감람석 | `Di` 4를 소모하고 `Cs` 1.5와 `Ol` 1.5를 각각 생성합니다 |

5단계의 생성물은 `Kp`입니다. 탈규산이 끝나면 사장석 `Plag = Ab + An`으로 두고, 앞의 규칙에 따라 규소 포화 상태를 판단합니다.

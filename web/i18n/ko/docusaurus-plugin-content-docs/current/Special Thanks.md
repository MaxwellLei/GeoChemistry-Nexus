# 🙏 특별 감사

GeoChemistry Nexus는 커뮤니티의 지원 덕분에 존재합니다.

## 기여자

GitHub Issue, 토론, 또는 이메일로 이 프로젝트에 참여한 모든 분께 감사드립니다. 다음을 포함하되 이에 국한되지 않습니다.

* 버그 보고, 기능 제안
* 코드, 시험, 문서 기여
* 판별 도해, 온압계 등 템플릿의 공유와 공동 구축

* 다국어 현지화 참여 등

공개가 허락된 모든 기여자는 프로젝트 기여자 명단에 수록합니다. 개인 홈페이지나 관련 링크가 있으면 알려 주시면 함께 표시합니다.

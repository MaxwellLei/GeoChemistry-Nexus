# 🌍 はじめに

**GeoChemistry Nexus は、地球化学、岩石学、鉱物学、鉱床学などの研究者向けの統合研究プラットフォームです。**

判別図の作成、地質温度圧力計、EPMA による鉱物化学計算、CIPW ノルム計算、Niggli ノルム計算など、研究でよく使う計算を一つの作業環境にまとめます。別々のソフトウェアを行き来する手間を減らし、地質データの処理、計算、可視化をよりスムーズに進められます。

さらに GeoChemistry Nexus はクラウドのテンプレート基盤により、図解テンプレートと計算アルゴリズムの継続的な更新、共有、再利用に対応します。研究ツールを広げながら、開かれて柔軟で、長く使い続けられる地球科学の作業環境を築いていきます。

**3 分で GeoChemistry Nexus を始める** ⏱️。

## 前提条件 🛠️

現在、**GeoChemistry Nexus が対応しているのは Windows のみ**です。macOS と Linux のネイティブ版はまだありません。

- **Windows**：Windows 7 以降を使用してください
- **macOS / Linux**：ネイティブで動かす方法はまだありません。仮想マシンに Windows を入れて GeoChemistry Nexus を実行することはできますが、互換性と性能はその仮想マシン環境によります。

### 🚀 クロスプラットフォームの計画

複数の OS への対応を計画しており、今後は `Avalonia UI` への移行を検討して、macOS や Linux などを段階的にサポートします。

## ここから始める 🚀

[ここをクリック](https://github.com/MaxwellLei/GeoChemistry-Nexus/releases)してダウンロードページを開きます。適切なバージョンを選び、対応するインストーラーをダウンロードしてください。

ダウンロード後は、インストールウィザードに従ってインストールします。完了したら `GeoChemistry Nexus.exe` をダブルクリックすると起動します。 🖱️

### ソフトウェアの不具合とフィードバック 💬

GeoChemistry Nexus は今も開発と改善を続けています。開発者である私にも、考慮漏れや実装上の見落としはあります。機能設計、計算ロジック、データ処理、画面操作のどこかに、まだ見つかっていない問題が残っている可能性があります。信頼性や計算の正確さには努めますが、あらゆる状況で誤りがまったくないとは約束できません。

使用中にバグ、計算の異常、不自然な結果、より良い機能の提案を見つけたら、GitHub Issues から知らせてください。一つひとつの報告と提案が、GeoChemistry Nexus を良くしていく力になります。

**ソフトウェアの改善は、使ってくださる一人ひとりの助けがあってこそです。ご理解、ご支援、ご参加に感謝します。**

# 🙏 特別な謝辞

GeoChemistry Nexus が存在するのは、コミュニティの支えがあるからです。

## 貢献者

GitHub Issue、ディスカッション、メールを通じてこのプロジェクトに加わってくださったすべての方に感謝します。次のような参加を含み、これらに限りません。

* バグの報告、機能の提案
* コード、テスト、文書への貢献
* 判別図や温圧計などのテンプレートの共有と共同作成

* 多言語ローカライズへの参加など

公開の許可を得た貢献者は、プロジェクトの貢献者一覧に掲載します。個人のホームページや関連するリンクがある場合は、併せて表示できるようお知らせください。

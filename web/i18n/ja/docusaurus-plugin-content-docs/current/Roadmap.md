# 🛣️ ロードマップ

GeoChemistry Nexus の目標は、**データ · 図解 · 計算 · 協力** を一つにまとめた、地球化学と岩石学の研究ツールチェーンを段階的に築くことです。

## ✅ 完了済み


### 中核となる作業の流れ
- [x] **ホーム**：ショートカットと実用的な小ツール
- [x] **判別図**：テンプレートライブラリに多数の判別図を内蔵しています。テクトニック環境の判別図、岩石分類図などを含み、これらに限りません。これに加えて、微量元素と希土類元素のスパイダー図に対応し、多数の規格化スキームを内蔵しています。ハーカー図の多連図へのプロットにも対応しています。
- [x] **地質温圧計**：オンラインの多鉱物地質温圧計算テンプレートと、Excel 風のカスタム関数を内蔵しています。
- [x] **EPMA 鉱物計算**：鉱物ごとの EPMA 計算テンプレートをオンラインで随時更新し、ダウンロードしてすぐ使えます。
- [x] **CIPW ノルム計算**：全岩主要成分データの規格化計算と結果のエクスポート
- [x] **Niggli ノルム計算**：全岩主要成分データの規格化計算と結果のエクスポート
### プラットフォームの能力
- [x] **性能**：メモリ使用量は極めて小さく、必要なインストール容量も最小限です。`.NET` ランタイムを含まない場合、ソフトウェア本体は 9 MB のみです。
- [x] **テンプレート生態系**：オンラインテンプレートをクラウドから動的に更新します。カスタムテンプレートの作成、インポート、パッケージ化しての共有に対応します。検証しやすいよう、計算過程の詳細を確認できます。
- [x] **多言語**：インターフェースのローカライズ（中国語 / 英語 / ドイツ語 / ロシア語 / 日本語 / 韓国語など）。図解テンプレートの言語をワンクリックで切り替えられます。
- [x] **エクスポートと連携**：PNG / JPG / BMP / SVG のエクスポート。CorelDRAW、Inkscape、Adobe Illustrator などのサードパーティソフトとの連携に対応します。

## 🔭 中長期の展望
### 機械学習による解析の補助
よく使われる機械学習の手順を取り入れ、地球化学データの判別と分類を補助します。モデル評価、変数重要度、ROC 曲線、混同行列などの可視化結果を出力します。**ユーザーが自分で Python 環境を用意する必要はありません。**
### 「新しい図解」型の判別モデル
拡張可能な機械学習の判別モデル（大規模データで訓練した新しい判別図など）を読み込めるようにします。研究者が ML 開発一式を習得しなくても、「新しい図解」を直接適用して解析できるようにします。
### AI 研究アシスタント（段階的に）
1. **第 1 段階**：内蔵のヘルプ文書と知識ベースに基づく RAG による質疑応答。キーワードと場面に応じて操作の提案を示します。
2. **第 2 段階**：データ処理と解析の手順をさらに補助し、繰り返しの操作を簡略化します。

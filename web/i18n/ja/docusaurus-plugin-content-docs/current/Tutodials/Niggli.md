# Niggli ノルム計算

**Niggli ノルム計算**は、同じ行の全岩酸化物に対して、二組の結果を出します。

1. **ニグリ値**：`si`、`al`、`fm`、`c`、`alk`、`k`、`mg`、`qz`。計算詳細にだけ表示する `ti`、`p` もあります。
2. **Barth–Niggli 分子ノルム（Catanorm）**：陽イオン百分率（cat%）で表したノルム鉱物、端成分組成、およびシリカが不飽和のときの脱珪の経過です。

Catanorm は Paul Niggli（1948）と Tom F. W. Barth（1948）が確立しました。陽イオン当量で配分し、鉄などの重い元素が質量百分率の中で占める比重を小さくするため、CIPW の wt% よりも薄片中の鉱物体積の関係に近くなります。質量百分率のノルム鉱物は [CIPW ノルム計算](./CIPW) を参照してください。

アルゴリズムは GCDkit の分子ノルムの手順を参考に再実装しています。白榴石をさらに脱珪した生成物は、カリオフィライト `Kp` として記録します。

## 画面

上部バーは CIPW と同じです。**Fe³⁺/ΣFe**、**説明**、**例**、**エクスポート**、**クリア**、**計算実行** です。Fe³⁺/ΣFe の範囲は `0`–`1`、既定は `0.15`（Le Maitre, 2002）です。

**例** は 3 行を入力します。花崗岩、玄武岩、響岩（Phonolite）です。最初の 2 行はシリカが比較的高い一般的な火山岩で、響岩は霞石や白榴石のような不飽和の結果を確認するために使います。

ワークシートは左から右へ五つの区間に分かれます。

| 領域 | グループ | 単位 | 内容 |
| --- | --- | --- | --- |
| 試料 | — | — | 試料名です。計算には参加せず、横にスクロールしても表示されたままです |
| 酸化物 | 主要元素；その他の酸化物 / 揮発分 | wt% | 入力領域 |
| ニグリ値 | ニグリ値 | 無次元 | `si`、`al`、`fm`、`c`、`alk`、`k`、`mg`、`qz` |
| 診断 | 診断 | — | シリカ飽和状態、アルミナ飽和状態、鉱物合計 |
| ノルム鉱物 | ノルム鉱物 | cat% | 陽イオン百分率です。最後の列は `Sum(合計)` です |

試料列は固定されます。表は最初 500 行で、フィルハンドルのダブルクリックによる下方向へのフィルに対応しています。入力を変更すると、計算済みの行は期限切れの状態になり、**計算実行** を再度クリックする必要があります。

### 行ヘッダーの状態

| 丸 | 意味 |
| --- | --- |
| 灰色の中抜き | 入力はあるが、まだ計算していない |
| 青緑の塗りつぶし | 計算に成功し、警告がない |
| 橙色の塗りつぶし | 計算には成功したが、FeOT による鉄の価数の推定を使った |
| 赤色の塗りつぶし | 計算に失敗した。診断列に「計算エラー」と原因が書かれる |
| 橙色の中抜き | 計算したあと酸化物を変更したため、結果が古くなっている |

FeO と Fe₂O₃ を両方入力した試料は、計算に成功すると青緑の点になります。FeOT だけのときは鉄の価数の警告が出て、行ヘッダーは橙色になります。

## 入力

各行が一つの試料で、単位は酸化物の質量百分率（wt%）です。0 より大きいセルだけを読み取ります。空白と 0 は未入力とみなします。

主要元素は `K2O` までです。

`SiO2`、`TiO2`、`Al2O3`、`Fe2O3`、`FeO`、`FeOT`、`MnO`、`MgO`、`CaO`、`Na2O`、`K2O`

その他の酸化物 / 揮発分：

`CO2`、`P2O5`、`F`、`S`

このモジュールは `ZrO2`、`Cr2O3`、`Cl`、`SO3` を読み取りません。これら四つをノルム鉱物へ入れる必要がある場合は、CIPW モジュールを使ってください。

### 鉄の処理

鉄は、陽イオンへ換算する前に処理します。分割するときは、鉄をいったん Fe 原子へ還元します。全鉄のモル数 = 鉄の質量 / FeO のモル質量です。そのあと Fe³⁺/ΣFe に従って三価と二価に分け、三価鉄の半分を Fe₂O₃ へ書き込みます。

| 入力の状況 | 処理 |
| --- | --- |
| `Fe2O3` と `FeO` が両方ある | 実測値を使います。隣に `FeOT` があっても、それ以上は分割しません |
| `FeOT` があり、Fe₂O₃ と FeO が同時にはそろっていない | `FeOT` を現在の比で分割し、詳細に警告を出します |
| `Fe2O3` だけで、`FeO` も `FeOT` もない | この Fe₂O₃ を全鉄とみなし、比に従って Fe₂O₃ と FeO に分割します |
| `FeO` だけで、`Fe2O3` も `FeOT` もない | この FeO を全鉄とみなし、比に従って Fe₂O₃ と FeO に分割します |

したがって、FeO だけ、または Fe₂O₃ だけを分析した場合、結果は上部バーの比に従って変わります。この二つがどちらも実測値であれば、両方の列に入力してください。

`MnO` は陽イオン換算まで保持します。ニグリ値の `fm` と `mg` に入り、Catanorm では Fe²⁺ に合算します。

## ニグリ値

パラメータは酸化物の **分子数** で計算します。分子数 = wt% / モル質量です。ここでの `al` は Al₂O₃ の分子数で、Al₂O₃ 1 を 1 と数えます。あとの Catanorm で「Al₂O₃ 1 を Al 2 個と数える」のとは、基数は同じではありません。

```text
al  = n(Al2O3)
fm  = n(FeO) + 2 n(Fe2O3) + n(MnO) + n(MgO)
c   = n(CaO)
alk = n(Na2O) + n(K2O)
base = al + fm + c + alk

si  = 100 × n(SiO2) / base
al、fm、c、alk も同様に、base を 100 とした割合に換算します
ti  = 100 × n(TiO2) / base
p   = 100 × n(P2O5) / base
k   = n(K2O) / (n(Na2O) + n(K2O))
mg  = n(MgO) / (n(MgO) + n(FeO) + 2 n(Fe2O3) + n(MnO))
```

石英指数 `qz`：

```text
al > alk  のとき    qz = si − (100 + 4 al)
al ≤ alk  のとき    qz = si − (100 + 3 al + alk)
```

二つ目は、アルミニウムがアルカリを超えない試料に使います。ソフトウェア内の「説明」ウィンドウに列挙されているのは、一つ目だけです。

`si`、`al`、`fm`、`c`、`alk`、`ti`、`p`、`qz` は小数第 2 位まで、`k` と `mg` は小数第 3 位まで保持します。表に置くのは前の組の 8 列だけです。`ti` と `p` は計算詳細にあります。`qz` が正のとき、詳細では正の符号を付けます。

表の中では、`al + fm + c + alk` は 100 になるはずです。`si` は 100 を大きく超えることがあります。シリカはこの 100 分の配分の中に入らないからです。`k` と `mg` は 0 から 1 の比です。

## 診断列

| 列 | 意味 |
| --- | --- |
| **シリカ飽和状態** | シリカ過飽和、シリカ飽和、シリカ不飽和 |
| **アルミナ飽和状態** | ペラルミナス、準アルミニウム質、過アルカリ質 |
| **鉱物合計** | Catanorm の陽イオン百分率の和。小数第 2 位まで保持します |

シリカ飽和状態は最終的な鉱物から判定します。しきい値は `0.001 cat%` です。

- 石英 `Q` がある：シリカ過飽和。
- 石英はないが、霞石 `Ne`、白榴石 `Lc`、カリオフィライト `Kp`、またはかんらん石 `Ol` がある：シリカ不飽和。
- それ以外：シリカ飽和。

`qz` の正負は、ニグリの基数に対してシリカが過剰か不足かを見るためのものです。表の「シリカ飽和状態」が見ているのはノルム鉱物です。二つの列は対照できますが、判定の基数は異なります。

アルミナ飽和状態は、正規化後の陽イオンで判断し、鉱物の配分より前に行われます。

- **ペラルミナス**：Al > Na + K + Ca
- **準アルミニウム質**：Na + K < Al ≤ Na + K + Ca
- **過アルカリ質**：Al ≤ Na + K

## ノルム鉱物

鉱物列の単位は陽イオン百分率です。`Plag` は `Ab + An` に等しく、合計 `Sum` には `Plag` を計上し、`Ab` と `An` を二度目に加えることはありません。閉合の程度を確かめるときは、`Sum` または診断列の鉱物合計を見てください。

| 略号 | 鉱物 | 略号 | 鉱物 |
| --- | --- | --- | --- |
| `Q` | 石英 | `Hy` | 斜方輝石 |
| `C` | コランダム | `Ol` | かんらん石 |
| `Or` | 正長石 | `Cs` | ランキナイト |
| `Plag` | 斜長石 | `Wo` | 珪灰石 |
| `Ab` | 曹長石 | `Mt` | 磁鉄鉱 |
| `An` | 灰長石 | `Hm` | 赤鉄鉱 |
| `Lc` | 白榴石 | `Il` | チタン鉄鉱 |
| `Ne` | 霞石 | `Tn` | チタナイト |
| `Kp` | カリオフィライト | `Pf` | ペロブスカイト |
| `Ac` | エジリン | `Ru` | ルチル |
| `Ns` | メタケイ酸ナトリウム | `Ap` | 燐灰石 |
| `Ks` | メタケイ酸カリウム | `Fr` | 蛍石 |
| `Di` | 透輝石 | `Py` | 黄鉄鉱 |
| | | `Cc` | 方解石 |

端成分の比は結果列を別に占めず、すべて計算詳細に書きます。

## 計算詳細

成功した行を選択すると、右側のインスペクターが六つの区間で表示します。

1. **岩石分類と飽和状態**：シリカ飽和状態、アルミナ飽和状態、ノルム鉱物の合計。不飽和のときシリカ飽和度を強調表示し、過アルカリ質のときアルミナ飽和度を強調表示します。
2. **ニグリ値**：`si`、`al`、`fm`、`c`、`alk`、`ti`、`p`、`k`、`mg`、`qz`。
3. **鉱物端成分**。対応する鉱物があるときだけ現れます。
   - 斜長石 `An% = 100 × An / (Ab + An)`
   - 透輝石は Wo 50% に固定し、残りの 50% をマグネシウムと鉄の比で En と Fs に分けます
   - かんらん石の Fo、Fa。Fo は次のマグネシウム指数に等しいです
   - マグネシウム指数 `Mgr = 100 × En / (En + Fs)`。斜方輝石を透輝石へ合算する前に計算します
4. **脱珪反応の経過**：シリカが余るときは石英の cat% を明記します。シリカが不足するときは、どの鉱物を消費したか、不足がすでに解消したかを段階的に書き出します。
5. **主要なノルム鉱物**：`1 cat%` より大きい鉱物を高い方から並べます。重複する `Plag` は含みません。`10 cat%` より大きい項目は強調表示します。
6. **警告**：現在の実装では、FeOT から鉄の価数を推定したときに警告を書き込みます。

## 計算過程

### 1. 陽イオンの基数

各酸化物をまず陽イオン量にします。`(wt% / モル質量) × 化学式中の陽イオン数` です。SiO₂、TiO₂、FeO、MnO、MgO、CaO、CO₂、F、S の陽イオン数は 1、Al₂O₃、Fe₂O₃、Na₂O、K₂O、P₂O₅ は 2 です。

すべての陽イオンを合計したあと 100 に縮尺し、Catanorm の配分プールとします。合計が 0 に近いとき、その行は失敗し、陽イオンの合計が不足していることを示します。この段階では、酸化物の wt% を 100 に正規化することは **もう行いません**。未入力の H₂O や強熱減量は、この 100 には入りません。

### 2. 副成分鉱物と塩類

Mn をまず Fe²⁺ に合算します。そのあと陽イオンの量関係に従います。

| 順序 | 鉱物 | 量関係の要点 |
| --- | --- | --- |
| 1 | 方解石 `Cc` | 鉱物量 = `2 × CO2`。等量の Ca を消費します |
| 2 | 燐灰石 `Ap` | P が F に対して少ないとき、`Ap = 3P` とし、F の一部を消費します。そうでない場合は、残りの F をすべて燐灰石に合算します |
| 3 | 蛍石 `Fr` | 残りの F：`Fr = 1.5 × F`。Ca を `0.5 × F` 消費します |
| 4 | 黄鉄鉱 `Py` | `Py = 1.5 × S`。Fe²⁺ を `0.5 × S` 消費します |
| 5 | チタン鉄鉱 `Il` | Ti と Fe²⁺ のうち少ない方が生成量を決め、鉱物量はその量の 2 倍です |

CO₂、P、F、S は、Ca または Fe²⁺ を優先して占めます。これらの揮発分が、結合できる陽イオンより明らかに多いとき、あとのカルシウム・マグネシウム鉱物は実態から外れます。鉱物合計と脱珪の記録で確かめてください。

### 3. 長石、準長石の前身、チタン鉱物

配分の単位は陽イオンです。正長石、曹長石、灰長石は、端成分が足りているとき、いずれも陽イオン 5 個で一組です。

1. K が Al、Si と正長石 `Or` を生成します（K 1 個につき Al 1 個と Si 3 個）。残った K はメタケイ酸カリウム `Ks` を生成します。
2. Na が Al、Si と曹長石 `Ab` を生成します。残った Na はさらに Fe³⁺ とエジリン `Ac` を生成します（Na 1 個につき Fe³⁺ 1 個と Si 2 個）。なお残る Na はメタケイ酸ナトリウム `Ns` を生成します。
3. 残った Al が Ca と灰長石 `An` を生成します。Ca が不足するときはアルミニウムで制限し、制限となる Al 1 個につき Ca 0.5 個と Si 1 個が対応します。
4. 残った Ti が Ca、Si とチタナイト `Tn` を生成します（陽イオン 3 個）。なお残る Ti はルチル `Ru` です。
5. 最後に残った Al はコランダム `C` です。

### 4. 鉄酸化物と輝石

Fe³⁺ と Fe²⁺ が磁鉄鉱 `Mt` を生成します。Fe³⁺ が Fe²⁺ の 2 倍を超えないとき、`Mt = 1.5 × Fe³⁺` です。残った Fe³⁺ は赤鉄鉱 `Hm` です。

残った Ca、Mg、Fe²⁺ はそれぞれ珪灰石 `Wo`、頑火輝石分子、鉄輝石分子になります。いずれも陽イオン数の 2 倍で、等量の Si を 1 消費します。頑火輝石分子と鉄輝石分子を足したものが斜方輝石 `Hy` です。この時点でマグネシウム指数を計算します。

`Wo` と `Hy` は、さらに等しい陽イオン数で結合して透輝石 `Di` になります。少ない方がすべて `Di` に入り、`Di` の陽イオン数はその 2 倍です。多い方は `Wo` または `Hy` として残します。

### 5. 石英、または 7 段階の脱珪

残りの Si ≥ 0 のとき、すべてが石英 `Q` になり、計算はここで終わります。

Si < 0 のとき、不足は `D = −Si` です。次の各段階は、不足を 0 まで減らして終了するか、その鉱物を使い切って次の段階へ進むかのいずれかです。係数は陽イオン百分率です。

| 段階 | 反応 | Si の不足を 1 解消するごと |
| --- | --- | --- |
| 1 | 斜方輝石 → かんらん石 | `Hy` を 4 消費し、`Ol` を 3 生成 |
| 2 | チタナイト → ペロブスカイト | `Tn` を 3 消費し、`Pf` を 2 生成 |
| 3 | 曹長石 → 霞石 | `Ab` を 2.5 消費し、`Ne` を 1.5 生成 |
| 4 | 正長石 → 白榴石 | `Or` を 5 消費し、`Lc` を 4 生成 |
| 5 | 白榴石 → カリオフィライト | `Lc` を 4 消費し、`Kp` を 3 生成 |
| 6 | 珪灰石 → ランキナイト | `Wo` を 4 消費し、`Cs` を 3 生成 |
| 7 | 透輝石 → ランキナイト + かんらん石 | `Di` を 4 消費し、`Cs` と `Ol` をそれぞれ 1.5 生成 |

第 5 段階の生成物は `Kp` です。脱珪が終わったあと、斜長石 `Plag = Ab + An` とし、前述の規則に従ってシリカ飽和状態を判断します。

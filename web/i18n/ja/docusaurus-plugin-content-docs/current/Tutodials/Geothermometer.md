# 地質温圧計

初期のバージョンでは、このモジュールを **GTM** と略していました。その後、地質温度計という名称になり、現在の正式名称は地質温圧計です。

初期バージョンには、ジルコン、閃亜鉛鉱、石英、ゼノタイム、緑泥石、黒雲母などの鉱物の地質温度計計算が含まれていました。新しいバージョンの地質温圧計は、対応の更新を続けており、まもなく同期される予定です。

## 画面

地質温圧計モジュールは、全体として二つの部分に分かれます。

1. 左側は **温圧計テンプレートの一覧** です。ここで目的の温圧計テンプレートを探すか、自分用の温圧計計算テンプレートを作成できます。
2. 右側は **現在選択している温圧計テンプレートのヘルプ説明文書** です。

## 機能

地質温圧計モジュールは、最初から **Excel の形式に倣って** 設計し、ユーザーが使い始める負担を下げています。**温圧計の使い方は、主に二つの形式に分かれます。**

1. **オンライン温圧計テンプレート**：既定の **オンライン温圧計テンプレート** は、ユーザーが変更することはできませんが、アルゴリズムの実装ロジックは確認できます。ソフトウェアを更新しなくても、ネットワークに接続して、より新しい地質温圧計テンプレートを取得できます。研究者は検索と絞り込みを行い、自分に合うテンプレートを選び、ガイドに従ってデータを入力して計算します。**この方法はより直接的で速く、プログラミングの知識は不要です。**
2. **独立した計算ウィンドウ**：上部メニューバーの **ファイル → 自由スプレッドシートを開く** から、独立した計算ウィンドウを開けます。独立したウィンドウでは、異なる地質温圧計を組み合わせて計算するよう、自分でプログラムできます。温圧計ごとの関数は、上級チュートリアルを参照してください。**この方法はより複雑ですが、相対的に柔軟です。**

もちろん、地質温圧計モジュールでは、研究者が自分のカスタム地質温圧計を作成することもできます。作成した地質温圧計テンプレートをエクスポートし、ほかの研究者へ配布して、すばやく使ってもらえます。

## 使用例

### オンライン温圧計テンプレートを使う

まず、地質温度計モジュールの中で、左のサイドバーから絞り込み、対応する計算テンプレートを選びます。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/select_and_apply_thermobarometer_template.webp')}
    alt="地質温圧計の選択"
    style={{width: '100%'}}
  />
</div>

右側のパネルで、そのテンプレートの説明文書を確認できます。上部バーには、現在選択している地質温圧計テンプレートのタイトルとタグも表示されます。対応する温圧計テンプレートを選んだら、上部バーの **適用** ボタンをクリックし、温圧計の計算画面へ進みます。

温圧計の画面では、対応する入力列を確認できます。上部バーの **サンプル** ボタンをクリックして、サンプルデータを読み込むこともできます。列見出しの要件に従ってデータを入力し、**計算式をコピー** するか、**「クリックしてドラッグ」するフィルハンドル**（Excel と同様）を使って計算を自動で完成させます（次のアニメーション例のとおりです）。

> 補足です。`Sample` 列は計算には参加せず、データを識別するための注釈にのみ使います。

マウスで対応するデータ行を選択し、上部の **検査** ボタンをクリックすると、ポップアップしたサイドバーで途中結果の詳細を確認できます。

### 独立ウィンドウでのカスタム関数

前述のとおり、メニューバーの **ファイル → 自由スプレッドシートを開く** から、独立した自由形式のウィンドウを開けます。

独立したウィンドウの表は空の表で、簡単なツールバーボタンがいくつか付いています。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/thermobarometer_free_form.webp')}
    alt="温圧計の自由計算表"
    style={{width: '100%'}}
  />
</div>

独立ウィンドウの表は、日常的に **Excel の表を使うときと同じように、任意の数値を入力し、`=関数名(引数)` と入力して関数を呼び出せます。**

異なる点は、地質温圧計の計算が対応する計算関数として登録されていることです。研究者は必要に応じて、より柔軟に計算内容をカスタマイズできます。**同じ表の中で、複数の温圧計の結果を比較すること** もできます。

:::note

注意してください。**独立ウィンドウの表では、対応するデータ行の途中の計算過程を確認することはできません。**

:::

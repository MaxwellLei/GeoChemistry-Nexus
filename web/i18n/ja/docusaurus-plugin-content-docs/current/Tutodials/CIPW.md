# CIPW ノルム計算

**CIPW ノルム計算**は、全岩の主要元素酸化物（wt%）を、一組の理想化されたノルム鉱物へ換算します。結果は、火成岩の対比、シリカ飽和度とアルミナ飽和度の判別に使います。CIPW Norm は、Cross、Iddings、Pirsson、Washington が 1902 年に提案しました。このモジュールは Excel 風の表で一括計算し、各行の診断と質量バランスを示します。

## 画面

ページは上部バーとデータワークシートで構成されます。上部バーの左側は **Fe³⁺/ΣFe**、右側は **説明**、**サンプル**、**エクスポート**、**クリア**、**計算実行** です。

ワークシートは左から右へ四つの区間に分かれ、列見出しの上にグループ名があります。

| 領域 | グループ | 単位 | 役割 |
| --- | --- | --- | --- |
| 試料 | — | — | 試料名です。識別にのみ使い、計算には参加しません。この列は固定され、横にスクロールしても表示されたままです |
| 酸化物 | 主要元素；その他の酸化物 / 揮発分 | wt% | 白色の入力領域 |
| 診断 | 診断 | — | `SiO2 飽和度`、`Al2O3 状態`、`質量バランス誤差(%)` |
| ノルム鉱物 | CIPW ノルム鉱物 | wt% | 淡色の結果領域。見出しは略号に日本語名を付けたもの、たとえば `Q(石英)` です |

入力領域と結果領域のあいだには、細い区切り列があります。結果列は計算前は空です。表は最初に 500 行を用意します。フィルハンドルをダブルクリックすると、Excel と同じように下方向へフィルできます。

### 上部バー

| コントロール | 役割 |
| --- | --- |
| **Fe³⁺/ΣFe** | 全鉄 `FeOT` を使うときだけ、この比に従って FeO と Fe₂O₃ を分割します。範囲は `0`–`1`、既定は `0.15`（Le Maitre, 2002）で、小数第 2 位まで表示します |
| **説明** | ソフトウェア内のアルゴリズム説明を開きます |
| **サンプル** | 花崗岩、玄武岩、安山岩の 3 行の例を入力します。実測の Fe₂O₃、FeO、MnO を含みます |
| **エクスポート** | 現在の表を UTF-8 の CSV として保存します。既定のファイル名は `CIPW_Results.csv` です |
| **クリア** | 確認したあと、すべての入力、結果、計算詳細を消去します |
| **計算実行** | 有効な酸化物を含むすべての行を計算します |

### 行ヘッダーの状態

行番号の横の丸は、その行の状態を表します。

| 丸 | 意味 |
| --- | --- |
| 灰色の中抜き | 入力はあるが、まだ計算していない |
| 青緑の塗りつぶし | 計算に成功し、警告がなく、質量バランスも通過している |
| 橙色の塗りつぶし | 計算には成功したが、警告があるか、質量バランス誤差が `1×10⁻⁶` より大きい |
| 赤色の塗りつぶし | その行の計算に失敗した。診断列に「エラー」と原因が書かれる |
| 橙色の中抜き | 計算したあと酸化物を変更したため、現在の結果は古くなっている |

サンプルデータには、いずれも MnO が含まれています。MnO は FeO に合算され、警告が出るため、サンプル行は計算後に橙色になります。これは想定どおりの結果です。試料名を変更しても結果は古くなりません。いずれかの酸化物入力を変更すると、古くなります。

## 入力

各行は一つの全岩試料です。酸化物の質量百分率（wt%）を入力します。ソフトウェアが読み取るのは **0 より大きい** セルだけで、空白と 0 はどちらも未入力とみなします。空行は自動的にスキップします。

表計算ソフトから直接貼り付けできます。列の順序は固定なので、貼り付けるときは次の見出しに合わせてください。

### 酸化物の列

主要元素：

`SiO2`、`TiO2`、`Al2O3`、`Fe2O3`、`FeO`、`FeOT`、`MnO`、`MgO`、`CaO`、`Na2O`、`K2O`、`P2O5`

その他の酸化物 / 揮発分：

`ZrO2`、`Cr2O3`、`CO2`、`S`、`F`、`Cl`、`SO3`

`FeOT` は、FeO 当量で表した全鉄です。`S`、`F`、`Cl` は元素の質量百分率で入力します。

### 鉄の処理

| 入力の状況 | 処理 |
| --- | --- |
| `FeO` と `Fe2O3` が両方あり、`FeOT` がない | 実測の配分を使います。鉄の処理モードは「実測値」です |
| `FeO` だけ、または `Fe2O3` だけがある | 欠けている方を 0 とします。モードは「部分仮定」で、警告を出します |
| `FeOT` だけがある | Fe³⁺/ΣFe に従って分割します。モードは「FeOT から推定」です |
| `FeOT` と、`FeO` または `Fe2O3` が同時にある | `FeOT` を無視します。モードは「入力不一致」で、警告を出します |
| 鉄のデータがまったくない | FeO と Fe₂O₃ をどちらも 0 とします。モードは「欠損」で、警告を出します |

`FeOT` だけのときの分割は、次のとおりです。

```text
Fe2O3 = FeOT × (Fe³⁺/ΣFe) × 1.11134
FeO   = FeOT × (1 − Fe³⁺/ΣFe)
```

係数 `1.11134` は、Fe₂O₃ と FeO の 2 倍とのモル質量比に対応し、三価鉄を FeO 当量から Fe₂O₃ の質量百分率へ戻すために使います。

`MnO` は計算の前に、モル質量比で FeO 当量へ換算し、FeO に加えます。

```text
FeO 当量 = MnO × 71.844 / 70.937
```

MnO を入力していると、計算詳細に「MnO はモル比に基づいて FeO 当量に換算されました」と表示されます。

## 出力

### 診断列

| 列 | 取り得る値 |
| --- | --- |
| **SiO2 飽和度** | 過飽和、飽和、不飽和 |
| **Al2O3 状態** | ペルアルカリ、メタアルミナス、ペラルミナス |
| **質量バランス誤差(%)** | 鉱物の質量と入力酸化物との閉合のずれです。`0.01` 未満のときは科学記数法、それ以外は小数第 4 位までです |

三つの飽和度の意味は次のとおりです。

- **過飽和**：配分が終わったあとも SiO₂ が残り、石英 `Q` として記録します。
- **飽和**：SiO₂ がちょうど使い切られ、石英もなく、脱珪も不要です。
- **不飽和**：SiO₂ が不足し、次の脱珪反応へ進みます。反応連鎖の全体でもシリカの不足を解消できない場合は、警告を追加し、残余の不足（mol/100 g）を示します。このときのノルム鉱物は信頼できません。

アルミナの飽和状態は、長石の配分の前に、その時点で残っている酸化物のモル数で判断します。

- **ペルアルカリ**：Na₂O + K₂O > Al₂O₃
- **ペラルミナス**：Al₂O₃ / (CaO + Na₂O + K₂O) > 1
- **メタアルミナス**：それ以外

燐灰石、方解石、蛍石、岩塩、芒硝が、対応する CaO または Na₂O をすでに消費しているため、ここで使うのは残量です。

### ノルム鉱物

結果は次の順序で並びます。

| 略号 | 鉱物 | 略号 | 鉱物 |
| --- | --- | --- | --- |
| `Q` | 石英 | `Fo` | 苦土橄欖石 |
| `Or` | 正長石 | `Fa` | 鉄橄欖石 |
| `Ab` | 曹長石 | `Mt` | 磁鉄鉱 |
| `An` | 灰長石 | `Hm` | 赤鉄鉱 |
| `Le` | 白榴石 | `Ilm` | チタン鉄鉱 |
| `Ne` | 霞石 | `Cm` | クロム鉄鉱 |
| `Kp` | 仮白榴石 | `Ru` | ルチル |
| `Cor` | コランダム | `Tn` | チタナイト |
| `Ac` | エジリン | `Pf` | ペロブスカイト |
| `Di` | 透輝石 | `Z` | ジルコン |
| `Hd` | ヘデンベルグ輝石 | `Ap` | 燐灰石 |
| `Wo` | 珪灰石 | `Cc` | 方解石 |
| `Cs` | ラーナイト | `Py` | 黄鉄鉱 |
| `En` | 頑火輝石 | `Fl` | 蛍石 |
| `Fs` | 鉄珪輝石 | `Hl` | 岩塩 |
| `ns` | メタケイ酸ナトリウム | `Th` | 芒硝 |
| `ks` | メタケイ酸カリウム | | |

正長石、曹長石、エジリンは、内部では化学式単位で数えます。K₂O 1 mol から `Or` 2 mol が生成し、Na₂O 1 mol から `Ab` または `Ac` が 2 mol 生成します。書き出される値は、常に質量百分率です。

## 計算詳細

計算に成功した行を選択すると、右側のインスペクターに次の内容が表示されます。

- 試料名。試料列が空のときは「第 N 行」と表示します。
- シリカ飽和度とアルミナ飽和度。不飽和のとき、シリカ飽和度を強調表示します。
- **鉄処理モード**。「実測値」以外のときは強調表示します。
- **質量バランス誤差**。小数第 6 位まで保持します。`1×10⁻⁶` を超えると強調表示します。
- **鉱物合計**。各ノルム鉱物の wt% の和で、小数第 4 位まで保持します。黄鉄鉱、蛍石、岩塩の形成時に放出された酸素は、この合計には入れませんが、質量バランスには入れます。
- **主要鉱物**：含有量が `0.01 wt%` より大きい鉱物を、高い方から並べます。`10 wt%` より大きい項目は強調表示します。
- **警告**：鉄データの欠損や不一致、FeOT からの推定、MnO の換算、残余のシリカ不足などです。

インスペクターの右上から、この詳細を CSV としてエクスポートするか、クリップボードへコピーできます。

## 計算過程

以下では、現在の計算コードの実際の順序に沿って説明します。燐灰石が最初にカルシウムを占め、そのあとで揮発分鉱物を形成します。チタナイトとルチルは、灰長石のあとに置きます。

鉱物のモル質量はすべて、酸化物のモル質量から化学式に従って導きます。手計算の丸めによる質量の不整合を避けるためです。計算に使う数値許容差は `1×10⁻¹²` です。いずれかの段階で、SiO₂ 以外の酸化物が明らかに負になると、その行は失敗します。

### 1. 無水での正規化と、鉄・マンガン

提供されていて負でない酸化物をすべて 100% に正規化します。前節に従って鉄を処理し、MnO を FeO 当量へ換えたあと、**もう一度正規化します。** 合計が 0 以下のとき、その行は失敗します。

### 2. モル数への換算

各酸化物のモル数 = 正規化後の wt% / モル質量です。その後の配分は、すべて mol/100 g の尺度で行います。

### 3. 燐灰石

燐灰石が最初にカルシウムを占めます。`P2O5` 1 mol は `CaO` `10/3` mol と結合します（OH も F も含みません）。

```text
Ap = min(P2O5, CaO / (10/3))
```

### 4. 揮発分鉱物

次の順序で、結合できる量だけ生成します。

| 鉱物 | 量関係 |
| --- | --- |
| 方解石 `Cc` | `min(CO2, CaO)` |
| 蛍石 `Fl` | `min(F/2, CaO)`。つまり CaO 1 mol が F 2 mol と結合します |
| 黄鉄鉱 `Py` | `min(S/2, FeO)`。つまり FeO 1 mol が S 2 mol と結合します |
| 岩塩 `Hl` | `min(Cl, 2×Na2O)` |
| 芒硝 `Th` | `min(SO3, Na2O)` |

### 5. ジルコン、クロム鉄鉱、チタン鉄鉱

- ジルコン `Z`：`ZrO2` のすべてと、等量の `SiO2`。
- クロム鉄鉱 `Cm`：`min(Cr2O3, FeO)`。
- チタン鉄鉱 `Ilm`：`min(TiO2, FeO)`。

この段階で使うのは、FeO と結合できるチタンだけです。残った TiO₂ は、灰長石のあとまで残します。

### 6. 長石、コランダム、残りのアルカリ

まずアルミナの飽和状態を記録し、それから配分します。

| 鉱物 | 条件と生成物 |
| --- | --- |
| 正長石 `Or` | `min(K2O, Al2O3)`。SiO₂ を 6 倍消費し、生成物のモル数はその値の 2 倍です |
| 曹長石 `Ab` | `min(Na2O, Al2O3)`。同様に SiO₂ を 6 倍消費し、生成物は 2 倍です |
| 灰長石 `An` | `min(CaO, Al2O3)`。SiO₂ を 2 倍消費します |
| コランダム `Cor` | 残りの Al₂O₃ |
| エジリン `Ac` | `min(残りの Na2O, Fe2O3)`。SiO₂ を 4 倍消費し、生成物は 2 倍です |
| メタケイ酸ナトリウム `ns` | 残りの Na₂O と等量の SiO₂ |
| メタケイ酸カリウム `ks` | 残りの K₂O と等量の SiO₂ |

長石の段階では、SiO₂ をいったん負の値として記録することを許し、あとの脱珪でまとめて処理します。

### 7. チタナイトとルチル

チタナイトが使うのは、灰長石のあとに残った CaO だけです。**その時点の SiO₂ の残量でチタナイトを制限することはしません。**

```text
Tn = min(残りの TiO2, 残りの CaO)
```

`Tn` は同時に、等量の SiO₂ を消費します。最後になお残る TiO₂ は、ルチル `Ru` とします。

### 8. 鉄酸化物

```text
Mt = min(Fe2O3, FeO)
Hm = 残りの Fe2O3
```

### 9. 輝石と珪灰石

`MgFe = MgO + FeO` とします。単斜輝石の合計は `min(CaO, MgFe)` で、これをマグネシウムと鉄の比に従って透輝石 `Di` とヘデンベルグ輝石 `Hd` に分けます。輝石 1 につき SiO₂ を 2 消費します。

残りの MgO と FeO はすべて頑火輝石 `En` と鉄珪輝石 `Fs` になり、それぞれ SiO₂ を 1 消費します。マグネシウムと鉄をどちらも使い切ったあと、まだ CaO があれば、すべて珪灰石 `Wo` になります。

### 10. シリカ飽和度と脱珪

脱珪の順序は、紫蘇輝石 → チタナイト → 曹長石 → 正長石 → 珪灰石 → 透輝石/ヘデンベルグ輝石 → 白榴石です。各段階では、その時点でまだ不足している SiO₂ だけを消費します。

| 順序 | 反応 | 放出される SiO₂ |
| --- | --- | --- |
| 1 | 頑火輝石/鉄珪輝石 2 → 苦土橄欖石/鉄橄欖石 1 | 輝石 2 mol ごとに 1 mol を放出 |
| 2 | チタナイト `Tn` → ペロブスカイト `Pf` | `Tn` 1 mol が 1 mol を放出 |
| 3 | 曹長石 `Ab` → 霞石 `Ne` | `Ab` 1 mol が 2 mol を放出 |
| 4 | 正長石 `Or` → 白榴石 `Le` | `Or` 1 mol が 1 mol を放出 |
| 5 | 珪灰石 `Wo` 2 → ラーナイト `Cs` 1 | `Wo` 2 mol ごとに 1 mol を放出 |
| 6 | 透輝石/ヘデンベルグ輝石 → ラーナイト + かんらん石 | 輝石 1 mol が 1 mol を放出。マグネシウムは `Fo` へ、鉄は `Fa` へ入る |
| 7 | 白榴石 `Le` → 仮白榴石 `Kp` | `Le` 1 mol が 1 mol を放出 |

SiO₂ が残るときは石英を生成し、状態は過飽和です。SiO₂ がちょうどゼロのときは飽和です。上の表に入った場合は不飽和です。

### 11. 質量百分率と質量バランス

ノルム鉱物の質量 = モル数 × 化学式から導いたモル質量です。これを、正規化後の酸化物合計に対する wt% へ換算します。

黄鉄鉱、蛍石、岩塩の中の S、F、Cl は、酸化物中の酸素を置換しています。放出された酸素はどの鉱物にも入らないため、質量バランスのときに加え戻します。

```text
放出酸素のモル数 = Fl + Py + Hl / 2
質量バランス誤差 = |100 − (鉱物 wt% の和 + 放出酸素の wt%)|
```

誤差が `1×10⁻⁶` より大きいとき、その行は警告として記録します。

# 設定

ソフトウェアの設定は多様で、機能が広がるにつれて、さらに多くの個人向けオプションが追加されていきます。

## プログラムの一般設定

設定は主に四つの部分に分かれます。ファイルパス、国際化と個人向け設定、メッセージ通知、その他です。主要な設定の概要は次のとおりです。

### 🌍 言語と外観

-   **言語**：現在は、簡体字中国語、繁体字中国語、英語、ドイツ語、スペイン語、日本語、韓国語、ロシア語、フランス語、ポルトガル語に対応しています。
-   **UI スケール**：解像度の異なる画面向けの拡大縮小です。通常は既定のままで問題ありません。

:::info

言語への対応についてです。お住まいの国や地域のローカライズを手伝っていただける場合は、翻訳への参加を熱烈に歓迎します。現在の翻訳の多くは AI の補助によるもので、一部が正確でないことがあります。助けていただけると大変ありがたいです。

:::

### 🗨️ メッセージ通知

-   **自動で閉じるまでの時間**：ソフトウェアの実行中に、メッセージ通知のポップアップが自動で閉じるまでの時間です。エラーと警告のメッセージは、手動で閉じる必要があります。

### ⚙️ その他

-   **システムと一緒に起動**：システム起動時に、ソフトウェアを自動で起動します。
-   **更新を自動で確認**：起動時に、ソフトウェアが更新を自動で確認します。
-   **終了の方法**：ソフトウェアの終了方法は二つあります。そのまま終了するか、システムトレイへ最小化するかです。トレイへ最小化する場合は、トレイアイコンを右クリックして終了を選ぶと、ソフトウェアを閉じられます。

## 作図モジュールの設定

作図モジュールの設定は、作図モジュール内の機能に特化しています。次のものを含み、これらに限りません。

*   サードパーティプログラムのパス設定
*   既定のサードパーティプログラム
*   図の既定の読み込み言語
*   図テンプレートと分類構造の自動更新

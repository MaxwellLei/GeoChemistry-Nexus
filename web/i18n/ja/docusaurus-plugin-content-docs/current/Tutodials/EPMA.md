# EPMA 鉱物計算

**EPMA 鉱物計算**は、電子プローブマイクロアナリシスで得た鉱物組成を処理します。複数の分析点の酸化物含有量を、選んだ鉱物の計算方法で鉱物化学の結果に換算し、鉱物同定、組成の比較、その後の地質学的解釈に使います。

## 画面

EPMA 鉱物計算は、**EPMA 鉱物計算テンプレートライブラリ**と**EPMA 計算画面**の二つに分かれています。

テンプレートライブラリでは、検索や絞り込みで目的の鉱物 EPMA 計算を選べます。一番右の説明パネルで、その計算テンプレートの基本情報を確認できます。**計算画面を開く**をクリックすると計算を始められます。

## 使用例

たとえばかんらん石の EPMA 計算テンプレートを選び、計算画面を開きます。画面は上下に分かれており、上部バーからそのテンプレートの詳しい説明を見るか、サンプルデータを読み込めます。

表が必要とするデータを入力したら、上部バーの**計算を実行**をクリックします。

白灰色の領域が入力欄、青紫色の領域が結果の出力欄です。出力を自由に確認できるほか、**検査**をクリックすると途中の計算過程を見られます。

各行の行頭の前にある色付きの丸は、その行の計算状態を表します。

* **灰色**：その行にデータはあるが、まだ計算していない
* **緑色**：正常に計算が終わり、警告もエラーもない
* **橙色**：計算は終わったが、警告がある
* **赤色**：その行の計算が失敗した

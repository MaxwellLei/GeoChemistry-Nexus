# 図解

図解モジュールでは、さらに多くの基礎的な地球科学の図解テンプレートをまとめていきます。テクトニック環境の判別図、岩石分類図などを含み、これらに限りません。**最終的な目標は、地球科学のための包括的な図枠・作図ツールキットを作り、研究者に最大の利便性を提供することです。** 🧪

:::info

地質図解などの分野を研究し、自分の図解の成果を広めたい研究者の方は、ぜひご連絡ください。図解の成果がより広い研究コミュニティへ届くよう支援し、学術成果の伝わり方と影響力をさらに高めます。

:::

## クイックスタート

ソフトウェアの図解モジュールは、主に二つの部分で構成されます。図解テンプレートライブラリと図解操作画面です。まず図解テンプレートライブラリで必要な図解の種類を選び、対応する操作画面へ進んで、データの入力、図解の処理、結果のエクスポートなどの操作を行います。

### テンプレートライブラリ

図解モジュールは三つの大きな種類に分けます。**オンラインクラウドテンプレート**、**マイテンプレート**、**ツール図解テンプレート** です。

**オンラインクラウドテンプレート**：こちらで継続的に更新し、保守します。ソフトウェアを更新しなくても、ネットワークに接続していれば更新された図解テンプレートを取得でき、常に最も包括的で信頼できるテンプレートを利用できます。

**マイテンプレート**：特定の研究上の必要に合わせてカスタムテンプレートを作成する場合に使います。自分でこれらのテンプレートを作成できるだけでなく、エクスポートしてほかの研究者と容易に共有し、学術的な交流と普及を促せます。

> *将来は、図解テンプレート専用のコミュニティを作る計画です。ユーザーが各種の **個人カスタムテンプレート** を容易に作成、アップロード、共有、ダウンロードできるようにし、システムの柔軟性と拡張性をさらに高めます。*

**ツール図解テンプレート**：決まった常用の図解を別に切り出したものです。現在は **希土類元素スパイダー図、微量元素スパイダー図、ハーカー多連図**、ならびに通常の二次元散布図と三元散布図を含みます。

#### 画面

既定では、作図モジュールを開くと内蔵の地球科学テンプレートライブラリが表示されます。画面は三つの主要な部分に分かれます。

*   **左側 - 図解の分類**：すべてのテンプレート階層と対応するテンプレートを表示します。カスタムテンプレートの一覧も含みます。
*   **右側 - 図解カード**：現在の階層にある図解カードを表示します。名称とプレビュー画像を含みます。
*   **上部 - ナビゲーションバー**：ソフトウェアは枠なしのデザインなので、上部のナビゲーションバーが各ページの機能の一部を担います。図解画面では、上部ナビゲーションバーに現在の図解テンプレートのパスや、図解テンプレートの検索などの機能が表示されます。

![図解インターフェース](/img/v0.9.0/en-US/graphical_interface.webp)

適切な図解テンプレートを選び、図解テンプレートカードをクリックすると、図解操作画面へ入れます。図解テンプレートカードは、右クリックでエクスポート、削除、お気に入りなどの操作もできます。

:::tip

右 <kbd>Alt</kbd> キーを押すと、図解テンプレートをすばやく削除したり、お気に入りに追加したりできます。

:::

#### 上部メニューバー

上部の **ファイル** メニューには、次のものが含まれます。

1.  **新規図解**：カスタムの図解テンプレートを作成します。
2.  **図解を開く**：図解テンプレートを一時的に開きます。対応しているのは `.diag.zip` ファイルだけです。
3.  **図解をインポート**：外部の図解テンプレートパッケージ（`.diag.zip`）を、ローカルのマイテンプレート一覧へ取り込みます。

### 図解操作画面

#### 画面

図解画面は五つの主要な部分に分かれます。

-   **ツールバー**：ショートカットボタンと、三つの機能タブ（作図、データ、編集）を含みます。
-   **レイヤー一覧（オブジェクト）**：テンプレート上の作図要素の一覧です。要素をクリックすると、そのプロパティを変更できます。
-   **作図キャンバス**：図の確認、データのインポート、表示の設定、テンプレート説明の確認を行う中心領域です。
-   **ステータスバー**：基本的な作図情報を表示します。現在の図の言語と座標情報を含みます。
-   **プロパティパネル**：選択した作図要素のプロパティ（色、大きさなど）を表示し、必要な見た目にします。

![図解操作画面](/img/v0.9.0/en-US/graphical_operation_interface.webp)

#### 図解ツールバー

ツールバーは一連の **ショートカットボタン** で構成されます。主なものは次のとおりです。

1. 図解テンプレートライブラリへ戻る
2. 操作状態を切り替える（図解モード、データモード、編集モード）
3. 図解の各種プロパティパネルや操作ツールなど

詳しい機能は次の図を参照してください。

![図解ツールバー](/img/v0.9.0/en-US/graphical_toolbar.webp)

### レイヤー一覧

作図要素は 7 種類に分かれます。

-   **Line（線）**：基本的な図解の境界や線分を定義します。
-   **Text（テキスト）**：ラベルと注釈です。
-   **Polygon（ポリゴン）**：図の中の閉じた形状です。
-   **Arrow（矢印）**：方向をもつ作図オブジェクトです。
-   **Function（関数）**：カスタムの数学関数と定義域を入力できます。
-   **Axes（座標軸）**：図の座標軸です。
-   **Data Point（データ点）**：インポートしたデータを表す要素です。

**既定の描画順序（上から下）：`データ点 > テキスト > 矢印 > 関数 > 線 > ポリゴン > 座標軸`**。

![図解オブジェクトの選択例](/img/v0.9.0/en-US/diagrammatic_object_selection_example.webp)

レイヤーパネルで要素を選択すると、キャンバス上でその要素が強調表示され、ほかの要素は半透明になって邪魔にならないようになります。そのあと、プロパティパネルにその要素の関連プロパティが表示されます。 🔍

これらのプロパティを変更し、望む見た目にできます。

:::tip

すべての要素の選択を解除するには、**キャンバス上の任意の位置を右クリック** するか、ツールバーの **選択解除** ボタンを使います。

:::

## 使用例

### 例

1. **図解テンプレートライブラリ** から図解テンプレートを選び、図解操作ページへ進みます。たとえば TAS 図を選びます。
2. データを入力するときは、図解モードからデータモードへ切り替えます。
   
   ![図解データ入力](/img/v0.9.0/en-US/diagram_data_input.webp)


TAS 図で必ず入力するのは、四つの列です。`Category`、`SiO2`、`K2O`、`Na2O` です。`Category` 見出しの列は、データをグループ化し、凡例を生成するために使います。`Sample` 列はデータ試料のラベルを示すもので、計算には参加しません（空でもかまいません）。その他の元素の単位は `wt.%` です。この図解がどのようなデータと単位を入力し、どのように使うのかが分からない場合は、図解領域の右上にある図解ヘルプボタンをクリックし、その図解の説明文書を確認できます。

3. 要件を理解したら、データを入力し、データパネル右上のプロットボタンをクリックしてデータ点を描きます。データ入力に問題がある場合は、データを修正したあと、もう一度プロットをクリックしてください。![データプロット](/img/v0.9.0/en-US/data_plotting.webp)
4. **図解をエクスポート** します。**図解のプロット結果をクリップボードへすばやくコピーする機能ボタン** を用意しています。**正式なエクスポート機能** もあります。正式なエクスポートパネルでは、画像形式として `jpg`、`png`、`bmp`、`svg` をエクスポートできます。研究用の作図でベクター図が必要な場合は、`svg` 形式をおすすめします。同時に、**結果をサードパーティの作図ソフトへ直接連携する** ことにも対応しており、エクスポートしてからインポートする中間手順は不要です。内蔵のおすすめサードパーティソフトは、**CorelDRAW、Inkscape、Adobe Illustrator** です。後段の研究用の修正には、Inkscape との連携をおすすめします。ほかのサードパーティ作図ソフトをカスタムで指定することもできます。そのソフトが `svg` ベクター形式に対応していることが前提です。研究者は設定で、作図ソフトのプログラムパスを指定するだけで済みます。
   ![図解のエクスポート](/img/v0.9.0/en-US/export_diagram.webp)

### 補足

図解テンプレート自体が多言語の切り替えに対応しています。つまり、一つの図解を複数の言語版へ切り替え、国際的な必要に応えられます。

たとえば、中国の学術誌に投稿する図解では中国語版が必要で、英語の SCI/IE などの学術誌に投稿するときは英語版の図解が必要です。図解ツールバー右上の言語切り替えをクリックすると、対応する言語版の図解へワンクリックで切り替えられます。

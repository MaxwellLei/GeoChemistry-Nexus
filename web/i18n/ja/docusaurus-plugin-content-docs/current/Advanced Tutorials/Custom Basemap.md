# 図解テンプレートを作る

オンラインの図解テンプレートライブラリにまだ収録されていない図解については、カスタムの図解テンプレートを作ることができます。カスタムテンプレートをテンプレートパッケージにまとめると、ほかの研究者とすばやく共有できます。

テンプレートを開発者へ提供し、オンラインの図解テンプレートライブラリへ収録してもらうこともできます。参加してくださる方の貢献に、心から感謝します。

## すばやく作成する

メニューバーから `ファイル` → `新規図解テンプレート` を選ぶと、新しい図解テンプレートを作成できます。次のとおりです。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/new_graphic_template.webp')}
    alt="図解設定"
    style={{width: '50%'}}
  />
</div>

【新規図解テンプレート】をクリックすると、新しい図解テンプレートを作成するためのポップアップが表示されます。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/new_graphic_template_interface.webp')}
    alt="新規図解の画面"
    style={{width: '100%'}}
  />
</div>

新しいカスタム図テンプレートでは、主に三つの部分を設定します。

1.  **既定で対応する言語**：右側の選択ボックスから、内蔵の言語ショートカットを選べます。簡体字中国語、繁体字中国語、アメリカ英語、日本語、ロシア語、韓国語、ドイツ語など、10 言語を用意しています。

    > 補足です。既定言語は、ほかの言語が未翻訳のときやエラーが起きたときに戻る言語です。また新しいバージョンでは、ユーザーが言語コードを独自に定義することは許可されません。お使いの言語への対応が必要な場合は、開発者へ連絡してください。

2.  **図解テンプレートの分類（階層）**：内蔵の分類構造をショートカットとして用意しています。この設定は、図テンプレート一覧の中でテンプレートがどの階層に置かれるかを決めます。

3.  **図テンプレートの種類**：現在は二つの種類に対応しています。**二次元座標系** と三元図です。

設定が終わったら【確認】をクリックし、カスタム作図の画面へ進みます。ここからは【編集】機能バーを中心に操作します。【編集】をクリックすると、図を編集するための再確認ダイアログが表示されます。確認すると編集モードに入り、編集機能バーの各種ツールを確認して使えます。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/empty_diagram_template.webp')}
    alt="空の図解"
    style={{width: '100%'}}
  />
</div>

## 図解を描く

編集モードでは、次の操作ができます。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/graphical_toolbar.webp')}
    alt="図解の描画"
    style={{width: '100%'}}
  />
</div>

* **保存**：図テンプレートを保存します。クリックすると、プログラムは現在の作図状態に応じたサムネイルを既定で生成します。
* **名前を付けて保存**：図テンプレートを別のファイル位置へ保存します。
* **線を追加**：有効にすると「線を追加」モードに入ります。作図領域の 1 点目をクリックして線を引き始め、2 点目をクリックすると線オブジェクトが完成します。
* **テキストを追加**：注釈とも呼びます。有効にすると「テキストを追加」モードに入ります。作図上の位置をクリックすると作成できます。既定のテキストは `Text` です。位置や内容は、レイヤーパネルのプロパティで変更できます。
* **ポリゴンを追加**：有効にすると「ポリゴンを追加」モードに入ります。左クリックを続けて頂点を作り、閉じたポリゴンを追加します。右クリックで図形を閉じます。
* **矢印を追加**：有効にすると「矢印を追加」モードに入ります。追加の手順は線の作成と似ています。
* **関数を追加**：クリックすると、既定の関数 `sin(x)` が追加されます。定義域は [-10, 10] です。数式はプロパティパネルでカスタマイズできます。
* **元に戻す／やり直し**：作図オブジェクトを作成または削除していない場合、これらの機能は無効です。既定では、履歴に保持されるのは直近 10 回の操作だけです。
* **削除**：作図オブジェクトを削除します。まずオブジェクト（たとえばテキスト）を選択し、削除をクリックして取り除きます。

### 関数を追加する

関数の追加は、これまでのオブジェクトとは異なります。**関数を追加するボタンをクリックすると、既定の関数オブジェクトがすぐに追加されます。** 既定の関数は `sin(x)` です。プロパティパネルで関数式を変更し、関数を定義できます。

関数オブジェクトのプロパティのうち、最も重要な二つのパラメータは **定義域** と **サンプル点** です。

* **定義域は、関数をキャンバス上に表示する範囲を決めます。**
* **サンプル点は、関数をキャンバス上に描く精度を制御し**、マウスで捕捉して選択するアルゴリズムの正確さにも影響します。既定値は `1000` です。精度を高くするほど関数の描画は精細になりますが、プログラムの描画負荷も増します。

## 図解テンプレートを仕上げる

基本的な図形を描き終えたあと、完成したテンプレートには次のものも必要です。

1.  **データとスクリプト**：図解テンプレートの入力データとデータ計算アルゴリズムを定義します。つまり、データをどのように計算してプロットするかを示します。
2.  **図解文書**：その図解のヘルプとして説明する内容です。
3.  **多言語**：図解テンプレートを二つ以上の言語に設定した場合は、多言語の部分を翻訳する必要があります。直前の【図解文書】と、図解キャンバス上のテキストオブジェクトなどが対象です。

図解テンプレートの仕上げは図解の操作画面でもできますが、図解の編集ウィンドウで行う方が便利です。

### データとスクリプト

データとスクリプトは図解テンプレートの要です。図の中でデータがどのように計算され、最終的に図へ現れるかを定義するからです。

必要なパラメータは二つです。図解テンプレートの **変数パラメータ** と **計算アルゴリズム（スクリプト）** です。次のとおりです。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/diagram_data_and_script.webp')}
    alt="図解・データとスクリプト"
    style={{width: '100%'}}
  />
</div>

図解テンプレートの **変数パラメータ** では、上部に列を追加し、その図解が必要とする入力列を表せます。任意のパラメータが二つあります。

1. Unit は入力列の単位です。表示上の説明にのみ使い、データアルゴリズムには影響しません。
2. Group は入力列のグループです。表示上の説明にのみ使い、データアルゴリズムには影響しません。

補足です。**データテーブルで定義した列見出しは、下のスクリプトから直接呼び出せる登録済み変数として扱われます。** したがって、入力列の変数をスクリプトの中で繰り返し定義する必要はありません。

**計算アルゴリズム（スクリプト）** は、既定では `JavaScript` で記述します。既定のスクリプト例は `return [X,Y]` です。データテーブルで定義した入力列 `X` と `Y` を、二次元座標軸へ返します。

たとえば TAS 図では、パラメータは `SiO2, Na2O, K2O` です。スクリプトの内容は次のようになります。

```javascript
// 変数 K2O + Na2O を用いて計算します
var result1 = K2O + Na2O;
// SiO2 を使用します
var result2 = SiO2;
// 2 つの計算値を返します。既定の二次元座標図では、戻り値は 2 つだけです。
// 1 番目が X の戻り値、2 番目が Y の戻り値です。
return [result2, result1]
```

スクリプトは、次のように書くこともできます。

```javascript
var result = K2O + Na2O
return [SiO2, result]
```

戻り値の位置は固定です。`[x, y]` では、1 番目の値は常に X（下軸）、2 番目は Y（左軸）です。

:::info

三元図では、最終的な戻り値の形式は `[A, B, C]` です。1 番目の値は A（下軸）、2 番目は B（左軸）、3 番目は C（右軸）です。

:::

### 図解文書

図解文書は、ほかの研究者がその図解の基本情報と使い方をすばやく理解するために必要な手順です。

ヘルプ文書のページで、図解文書を作成します。通常の文書に足る簡単なツールバー機能を用意しています。もちろん `Office Word` で文書を書き、内容をここに貼り付けることもできます。書式の大部分はそのまま使えます。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/diagram_help_document.webp')}
    alt="図解・ヘルプ文書"
    style={{width: '100%'}}
  />
</div>

図解文書の書き方として、次の基準に沿うことをおすすめします。

*   **はじめに**：図解テンプレートの基本的な概念と機能を説明し、ユーザーがすばやく理解できるようにします。
*   **データ形式**：有効なデータを読み取るために必要な入力データの形式と列見出しを指定します。
*   **参考文献**：図解テンプレートとその内容を作成するときに用いた文献を列挙します。
*   **貢献者**：図解テンプレートの作成に関わった人の名前です。個人のウェブサイトを載せることも歓迎します。

### 多言語

多言語を設定する方法は二つあります。

一つ目は、図解画面の上部機能バーにある **言語の切り替え** です。第二言語に固有の内容を設定できます。

二つ目は、図解の編集ウィンドウで多言語の内容を編集する方法です。次の図のとおりです。

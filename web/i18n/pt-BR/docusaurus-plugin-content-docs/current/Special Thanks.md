# 🙏 Agradecimentos especiais

O GeoChemistry Nexus existe graças ao apoio da comunidade.

## Contribuidores

Agradecemos a cada pessoa que participa do projeto pelo GitHub Issues, pela área de discussão ou por e-mail, incluindo, entre outras formas:

* Relatar bugs e propor funções
* Contribuir com código, testes e documentação
* Compartilhar ou construir em conjunto modelos de diagramas discriminantes, geotermobarômetros e outros

* Participar da localização para vários idiomas, entre outras contribuições

Todos os contribuidores que autorizarem a divulgação entram na lista de contribuidores do projeto. Se você tiver uma página pessoal ou um link relacionado, avise-nos para que também possamos exibi-lo.

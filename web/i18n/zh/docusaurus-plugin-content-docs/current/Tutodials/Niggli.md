# Niggli 标准矿物计算

**Niggli 标准矿物计算**对同一行全岩氧化物做两套结果：

1. **尼格里参数**：`si`、`al`、`fm`、`c`、`alk`、`k`、`mg`、`qz`，另有只在计算详情中显示的 `ti`、`p`。
2. **Barth–Niggli 分子标准矿物（Catanorm）**：以阳离子百分比（cat%）表示的标准矿物、端元组成，以及硅不饱和时的去硅历程。

Catanorm 由 Paul Niggli（1948）与 Tom F. W. Barth（1948）建立。它按阳离子当量分配，减轻铁等重元素在质量百分比里所占的比重，因此比 CIPW 的 wt% 更接近薄片中的矿物体积关系。质量百分比标准矿物见 [CIPW 标准矿物计算](./CIPW)。

算法参考 GCDkit 的分子标准矿物流程，并重新实现；其中白榴石进一步去硅的产物记入钾霞石 `Kp`。

## 界面

顶栏与 CIPW 相同：**Fe³⁺/ΣFe**、**说明**、**示例**、**导出**、**清空**、**执行计算**。Fe³⁺/ΣFe 的范围是 `0`–`1`，默认 `0.15`（Le Maitre, 2002）。

**示例**填入三行：花岗岩、玄武岩、响岩（Phonolite）。前两行是硅较高的常见火山岩，响岩用于查看霞石、白榴石一类的不饱和结果。

工作表从左到右分为五段：

| 区域 | 分组 | 单位 | 内容 |
| --- | --- | --- | --- |
| 样品 | — | — | 样品名称，不参与计算，横向滚动时保持可见 |
| 氧化物 | 主量元素；其他氧化物 / 挥发分 | wt% | 输入区 |
| 尼格里参数 | 尼格里参数 | 无量纲 | `si`、`al`、`fm`、`c`、`alk`、`k`、`mg`、`qz` |
| 诊断 | 诊断 | — | 硅饱和状态、铝饱和状态、矿物总和 |
| 标准矿物 | 标准矿物 | cat% | 阳离子百分比。最后一列是 `Sum(总和)` |

样品列冻结。表格初始 500 行，支持双击填充柄向下填充。输入改变后，已计算的行会变成过期状态，需要重新点击 **执行计算**。

### 行头状态

| 圆点 | 含义 |
| --- | --- |
| 灰色空心 | 已有输入，尚未计算 |
| 青绿实心 | 计算成功，没有警告 |
| 橙色实心 | 计算成功，但使用了 FeOT 估算铁价态 |
| 红色实心 | 计算失败。诊断列写有「计算错误」和原因 |
| 橙色空心 | 计算之后修改了氧化物，结果已过期 |

同时填写了 FeO 和 Fe₂O₃ 的样品，计算成功后是青绿点。只有 FeOT 时会出现铁价态警告，行头为橙色。

## 输入

每一行一个样品，单位是氧化物质量百分比（wt%）。只读取大于 0 的单元格；空白和 0 视为未提供。

主量元素，到 `K2O` 为止：

`SiO2`、`TiO2`、`Al2O3`、`Fe2O3`、`FeO`、`FeOT`、`MnO`、`MgO`、`CaO`、`Na2O`、`K2O`

其他氧化物 / 挥发分：

`CO2`、`P2O5`、`F`、`S`

本模块不读取 `ZrO2`、`Cr2O3`、`Cl`、`SO3`。这四项若需要进入标准矿物，使用 CIPW 模块。

### 铁的处理

铁在换成阳离子之前处理。拆分时把铁先还原成 Fe 原子：全铁摩尔数 = 铁的质量 / FeO 摩尔质量，再按 Fe³⁺/ΣFe 分成三价与二价，三价铁的一半写入 Fe₂O₃。

| 填写情况 | 处理 |
| --- | --- |
| 同时有 `Fe2O3` 和 `FeO` | 使用实测值。即使旁边还有 `FeOT`，也不再拆分 |
| 有 `FeOT`，且没有同时具备 Fe₂O₃ 和 FeO | 用 `FeOT` 按当前比值拆分，并在详情中警告 |
| 只有 `Fe2O3`，没有 `FeO` 也没有 `FeOT` | 把这份 Fe₂O₃ 当作全铁，再按比值拆成 Fe₂O₃ 和 FeO |
| 只有 `FeO`，没有 `Fe2O3` 也没有 `FeOT` | 把这份 FeO 当作全铁，再按比值拆成 Fe₂O₃ 和 FeO |

因此，只化验了 FeO 或只化验了 Fe₂O₃ 时，结果会随顶栏比值变化。若这两项都是实测值，请两列都填写。

`MnO` 保留到阳离子换算。它进入尼格里参数的 `fm` 和 `mg`，进入 Catanorm 后并入 Fe²⁺。

## 尼格里参数

参数用氧化物的**分子数**计算，分子数 = wt% / 摩尔质量。这里的 `al` 是 Al₂O₃ 的分子数，一份 Al₂O₃ 算 1，和后面 Catanorm 里「一份 Al₂O₃ 算 2 个 Al」不是同一个基数。

```text
al  = n(Al2O3)
fm  = n(FeO) + 2 n(Fe2O3) + n(MnO) + n(MgO)
c   = n(CaO)
alk = n(Na2O) + n(K2O)
base = al + fm + c + alk

si  = 100 × n(SiO2) / base
al、fm、c、alk 同样化为占 base 的 100 分额
ti  = 100 × n(TiO2) / base
p   = 100 × n(P2O5) / base
k   = n(K2O) / (n(Na2O) + n(K2O))
mg  = n(MgO) / (n(MgO) + n(FeO) + 2 n(Fe2O3) + n(MnO))
```

石英指数 `qz`：

```text
al > alk  时    qz = si − (100 + 4 al)
al ≤ alk  时    qz = si − (100 + 3 al + alk)
```

第二条用于铝不超过碱的样品。软件内「说明」窗口只列出了第一条。

`si`、`al`、`fm`、`c`、`alk`、`ti`、`p`、`qz` 保留 2 位小数，`k` 和 `mg` 保留 3 位小数。表格只放前一组里的八列；`ti` 和 `p` 在计算详情中。`qz` 为正时，详情里会加上正号。

`al + fm + c + alk` 在表格中应为 100。`si` 可以远大于 100，因为硅不在这个 100 分额里面。`k`、`mg` 是 0 到 1 的比值。

## 诊断列

| 列 | 含义 |
| --- | --- |
| **硅饱和状态** | 硅过饱和、硅饱和、硅不饱和 |
| **铝饱和状态** | 过铝质、准铝质、过碱质 |
| **矿物总和** | Catanorm 阳离子百分比之和，保留 2 位小数 |

硅饱和状态由最终矿物判定，阈值是 `0.001 cat%`：

- 有石英 `Q`：硅过饱和。
- 没有石英，但有霞石 `Ne`、白榴石 `Lc`、钾霞石 `Kp` 或橄榄石 `Ol`：硅不饱和。
- 其余：硅饱和。

`qz` 的正负用来看硅相对于尼格里基数是过剩还是不足。表格里的「硅饱和状态」看的是标准矿物，两列可以对照，它们的判定基数不同。

铝饱和状态用归一化后的阳离子判断，发生在矿物分配之前：

- **过铝质**：Al > Na + K + Ca
- **准铝质**：Na + K < Al ≤ Na + K + Ca
- **过碱质**：Al ≤ Na + K

## 标准矿物

矿物列的单位是阳离子百分比。`Plag` 等于 `Ab + An`，总和 `Sum` 计入 `Plag`，不再把 `Ab` 和 `An` 加第二次。核对闭合程度时看 `Sum` 或诊断列的矿物总和。

| 缩写 | 矿物 | 缩写 | 矿物 |
| --- | --- | --- | --- |
| `Q` | 石英 | `Hy` | 正辉石 |
| `C` | 刚玉 | `Ol` | 橄榄石 |
| `Or` | 正长石 | `Cs` | 硅钙石 |
| `Plag` | 斜长石 | `Wo` | 硅灰石 |
| `Ab` | 钠长石 | `Mt` | 磁铁矿 |
| `An` | 钙长石 | `Hm` | 赤铁矿 |
| `Lc` | 白榴石 | `Il` | 钛铁矿 |
| `Ne` | 霞石 | `Tn` | 榍石 |
| `Kp` | 钾霞石 | `Pf` | 钙钛矿 |
| `Ac` | 霓石 | `Ru` | 金红石 |
| `Ns` | 偏硅酸钠 | `Ap` | 磷灰石 |
| `Ks` | 偏硅酸钾 | `Fr` | 萤石 |
| `Di` | 透辉石 | `Py` | 黄铁矿 |
| | | `Cc` | 方解石 |

端元比例不单独占结果列，全部写在计算详情里。

## 计算详情

选中成功行后，右侧检查器按六段显示：

1. **岩石分类与饱和状态**：硅饱和状态、铝饱和状态、标准矿物总和。不饱和时硅饱和度高亮，过碱质时铝饱和度高亮。
2. **尼格里参数**：`si`、`al`、`fm`、`c`、`alk`、`ti`、`p`、`k`、`mg`、`qz`。
3. **矿物端元**，有对应矿物时才出现：
   - 斜长石 `An% = 100 × An / (Ab + An)`
   - 透辉石固定为 Wo 50%，其余 50% 按镁铁比分成 En 与 Fs
   - 橄榄石 Fo、Fa；Fo 等于下面的镁指数
   - 镁指数 `Mgr = 100 × En / (En + Fs)`，在正辉石并入透辉石之前计算
4. **去硅反应历程**：硅有余时写明石英的 cat%；硅亏损时逐步写出消耗了哪一种矿物、亏损是否已经消除。
5. **主要标准矿物**：大于 `1 cat%` 的矿物，从高到低，不含重复的 `Plag`。大于 `10 cat%` 的条目高亮。
6. **警告**：当前实现在由 FeOT 估算铁价态时写入警告。

## 计算过程

### 1. 阳离子基数

每种氧化物先变成阳离子量：`(wt% / 摩尔质量) × 化学式中的阳离子数`。SiO₂、TiO₂、FeO、MnO、MgO、CaO、CO₂、F、S 的阳离子数是 1；Al₂O₃、Fe₂O₃、Na₂O、K₂O、P₂O₅ 是 2。

全部阳离子相加后缩放到 100，作为 Catanorm 的分配池。总和接近 0 时该行失败，提示阳离子总和不足。这一步**不再**把氧化物 wt% 归一化到 100；未填写的 H₂O、烧失量不进入这个 100。

### 2. 副矿物与盐类

Mn 先并入 Fe²⁺。随后按阳离子计量：

| 顺序 | 矿物 | 计量要点 |
| --- | --- | --- |
| 1 | 方解石 `Cc` | 矿物量 = `2 × CO2`，消耗等量 Ca |
| 2 | 磷灰石 `Ap` | P 相对 F 较少时，`Ap = 3P`，并消耗一部分 F；否则把剩余 F 全部并入磷灰石 |
| 3 | 萤石 `Fr` | 剩余 F：`Fr = 1.5 × F`，消耗 `0.5 × F` 的 Ca |
| 4 | 黄铁矿 `Py` | `Py = 1.5 × S`，消耗 `0.5 × S` 的 Fe²⁺ |
| 5 | 钛铁矿 `Il` | Ti 与 Fe²⁺ 中较少的一方决定产量，矿物量是该量的 2 倍 |

CO₂、P、F、S 会优先占用 Ca 或 Fe²⁺。这些挥发分明显高于能结合的阳离子时，后面的钙镁矿物会失真，应用矿物总和和去硅记录核对。

### 3. 长石、似长石前身与钛矿物

分配单位是阳离子。正长石、钠长石、钙长石在端元充足时都是 5 个阳离子一组。

1. K 与 Al、Si 生成正长石 `Or`（每个 K 配 1 个 Al 和 3 个 Si）。剩余 K 生成偏硅酸钾 `Ks`。
2. Na 与 Al、Si 生成钠长石 `Ab`。剩余 Na 再与 Fe³⁺ 生成霓石 `Ac`（每个 Na 配 1 个 Fe³⁺ 和 2 个 Si）。仍剩余的 Na 生成偏硅酸钠 `Ns`。
3. 剩余 Al 与 Ca 生成钙长石 `An`。Ca 不足时按铝限制，每个限制性 Al 对应 0.5 个 Ca 和 1 个 Si。
4. 剩余 Ti 与 Ca、Si 生成榍石 `Tn`（3 个阳离子）。仍剩余的 Ti 为金红石 `Ru`。
5. 最后剩余的 Al 为刚玉 `C`。

### 4. 铁氧化物与辉石

Fe³⁺ 与 Fe²⁺ 生成磁铁矿 `Mt`：Fe³⁺ 不超过二倍 Fe²⁺ 时，`Mt = 1.5 × Fe³⁺`。剩余 Fe³⁺ 为赤铁矿 `Hm`。

剩余 Ca、Mg、Fe²⁺ 分别变成硅灰石 `Wo`、顽火辉石分子和铁辉石分子，各为阳离子数的 2 倍，并消耗等量的一份 Si。顽火辉石与铁辉石分子相加为正辉石 `Hy`。此时计算镁指数。

`Wo` 与 `Hy` 再等阳离子结合成透辉石 `Di`：量少的一方全部进入 `Di`，`Di` 的阳离子数是它的 2 倍；多的一方留下 `Wo` 或 `Hy`。

### 5. 石英或七步去硅

剩余 Si ≥ 0 时，全部成为石英 `Q`，计算到此结束。

Si < 0 时，亏损 `D = −Si`。下面每一步要么把亏损减到 0 并结束，要么把该矿物用完后进入下一步。系数是阳离子百分比：

| 步 | 反应 | 每消除 1 份 Si 亏损 |
| --- | --- | --- |
| 1 | 正辉石 → 橄榄石 | 消耗 4 `Hy`，生成 3 `Ol` |
| 2 | 榍石 → 钙钛矿 | 消耗 3 `Tn`，生成 2 `Pf` |
| 3 | 钠长石 → 霞石 | 消耗 2.5 `Ab`，生成 1.5 `Ne` |
| 4 | 正长石 → 白榴石 | 消耗 5 `Or`，生成 4 `Lc` |
| 5 | 白榴石 → 钾霞石 | 消耗 4 `Lc`，生成 3 `Kp` |
| 6 | 硅灰石 → 硅钙石 | 消耗 4 `Wo`，生成 3 `Cs` |
| 7 | 透辉石 → 硅钙石 + 橄榄石 | 消耗 4 `Di`，各生成 1.5 `Cs` 和 1.5 `Ol` |

第 5 步的产物是 `Kp`。去硅完成后，斜长石 `Plag = Ab + An`，再按前文的规则判断硅饱和状态。

# CIPW 标准矿物计算

**CIPW 标准矿物计算**把全岩主量元素氧化物（wt%）换算成一组理想化的标准矿物。结果用于火成岩对比、硅饱和度与铝饱和度判别。CIPW Norm 由 Cross、Iddings、Pirsson 与 Washington 于 1902 年提出。本模块在类 Excel 表格中批量计算，并给出每一行的诊断与质量平衡。

![CIPW 标准矿物计算界面](/img/v0.9.0/cipw-result.png)

## 界面

页面由顶栏和数据工作表组成。顶栏左侧是 **Fe³⁺/ΣFe**，右侧是 **说明**、**示例**、**导出**、**清空** 和 **执行计算**。

工作表从左到右分为四段，列头上方有分组名称：

| 区域 | 分组 | 单位 | 作用 |
| --- | --- | --- | --- |
| 样品 | — | — | 样品名称，只作标识，不参与计算。该列冻结，横向滚动时保持可见 |
| 氧化物 | 主量元素；其他氧化物 / 挥发分 | wt% | 白色输入区 |
| 诊断 | 诊断 | — | `SiO2 饱和度`、`Al2O3 状态`、`质量平衡误差(%)` |
| 标准矿物 | CIPW 标准矿物 | wt% | 浅色结果区。表头为缩写加中文名，例如 `Q(石英)` |

输入区与结果区之间有一条窄分隔列。结果列在计算前为空。表格初始提供 500 行。双击填充柄可以像 Excel 一样向下填充。

### 顶栏

| 控件 | 作用 |
| --- | --- |
| **Fe³⁺/ΣFe** | 仅在使用全铁 `FeOT` 时，按该比值拆分 FeO 与 Fe₂O₃。范围 `0`–`1`，默认 `0.15`（Le Maitre, 2002），显示两位小数 |
| **说明** | 打开软件内的算法说明 |
| **示例** | 填入三行示例：花岗岩、玄武岩、安山岩，并带有实测 Fe₂O₃、FeO 与 MnO |
| **导出** | 把当前表格存为 UTF-8 CSV，默认文件名 `CIPW_Results.csv` |
| **清空** | 确认后清除全部输入、结果和计算详情 |
| **执行计算** | 对所有含有效氧化物的行计算 |

### 行头状态

行号旁的圆点表示该行状态：

| 圆点 | 含义 |
| --- | --- |
| 灰色空心 | 已有输入，尚未计算 |
| 青绿实心 | 计算成功，且没有警告、质量平衡也通过 |
| 橙色实心 | 计算成功，但存在警告，或质量平衡误差大于 `1×10⁻⁶` |
| 红色实心 | 该行计算失败。诊断列写有「错误」和原因 |
| 橙色空心 | 计算之后又改过氧化物，当前结果已过期 |

示例数据都含有 MnO。MnO 会并入 FeO 并产生警告，所以示例行计算后是橙色，这是预期结果。修改样品名不会使结果过期；修改任一氧化物输入会。

## 输入

每一行是一个全岩样品，填写氧化物的质量百分比（wt%）。软件只读取**大于 0** 的单元格，空白和 0 都视为未提供。空行自动跳过。

可以从表格软件直接粘贴。列顺序固定，粘贴时按下面的表头对齐。

### 氧化物列

主量元素：

`SiO2`、`TiO2`、`Al2O3`、`Fe2O3`、`FeO`、`FeOT`、`MnO`、`MgO`、`CaO`、`Na2O`、`K2O`、`P2O5`

其他氧化物 / 挥发分：

`ZrO2`、`Cr2O3`、`CO2`、`S`、`F`、`Cl`、`SO3`

`FeOT` 是以 FeO 当量表示的全铁。`S`、`F`、`Cl` 按元素质量百分比填写。

### 铁的处理

| 填写情况 | 处理 |
| --- | --- |
| 同时有 `FeO` 和 `Fe2O3`，没有 `FeOT` | 使用实测配分，铁处理模式为「实测值」 |
| 只有 `FeO` 或只有 `Fe2O3` | 缺的一项按 0，模式为「部分假设」，并给出警告 |
| 只有 `FeOT` | 按 Fe³⁺/ΣFe 拆分，模式为「从 FeOT 估算」 |
| `FeOT` 与 `FeO` 或 `Fe2O3` 同时出现 | 忽略 `FeOT`，模式为「输入不一致」，并给出警告 |
| 没有任何铁数据 | FeO 与 Fe₂O₃ 都按 0，模式为「缺失」，并给出警告 |

仅有 `FeOT` 时的拆分是：

```text
Fe2O3 = FeOT × (Fe³⁺/ΣFe) × 1.11134
FeO   = FeOT × (1 − Fe³⁺/ΣFe)
```

系数 `1.11134` 对应 Fe₂O₃ 与两倍 FeO 的摩尔质量比，用来把三价铁从 FeO 当量换回 Fe₂O₃ 的质量百分比。

`MnO` 在计算前按摩尔质量比换成 FeO 当量，并加入 FeO：

```text
FeO 当量 = MnO × 71.844 / 70.937
```

只要填写了 MnO，计算详情里就会出现「MnO 已按摩尔比转换为 FeO 当量」。

## 输出

### 诊断列

| 列 | 取值 |
| --- | --- |
| **SiO2 饱和度** | 过饱和、饱和、不饱和 |
| **Al2O3 状态** | 过碱性、准铝质、过铝质 |
| **质量平衡误差(%)** | 矿物质量与输入氧化物闭合的偏差。小于 `0.01` 时用科学计数法，否则保留 4 位小数 |

三个饱和度的含义：

- **过饱和**：分配结束后仍有 SiO₂，记为石英 `Q`。
- **饱和**：SiO₂ 恰好用完，既无石英，也无需去硅。
- **不饱和**：SiO₂ 不足，进入下面的去硅反应。若整条反应链仍消不掉硅亏损，会追加警告，并说明残余亏损（mol/100 g）。这时的标准矿物不可靠。

铝饱和状态在长石分配之前，用当时剩余的氧化物摩尔数判断：

- **过碱性**：Na₂O + K₂O > Al₂O₃
- **过铝质**：Al₂O₃ / (CaO + Na₂O + K₂O) > 1
- **准铝质**：其余情况

磷灰石、方解石、萤石、石盐和芒硝已经先消耗了相应的 CaO 或 Na₂O，所以这里用的是剩余量。

### 标准矿物

结果按下面的顺序排列。中文名与软件表头一致。

| 缩写 | 矿物 | 缩写 | 矿物 |
| --- | --- | --- | --- |
| `Q` | 石英 | `Fo` | 镁橄榄石 |
| `Or` | 正长石 | `Fa` | 铁橄榄石 |
| `Ab` | 钠长石 | `Mt` | 磁铁矿 |
| `An` | 钙长石 | `Hm` | 赤铁矿 |
| `Le` | 白榴石 | `Ilm` | 钛铁矿 |
| `Ne` | 霞石 | `Cm` | 铬铁矿 |
| `Kp` | 假白榴石 | `Ru` | 金红石 |
| `Cor` | 刚玉 | `Tn` | 榍石 |
| `Ac` | 霓石 | `Pf` | 钙钛矿 |
| `Di` | 透辉石 | `Z` | 锆石 |
| `Hd` | 钙铁辉石 | `Ap` | 磷灰石 |
| `Wo` | 硅灰石 | `Cc` | 方解石 |
| `Cs` | 斜硅钙石 | `Py` | 黄铁矿 |
| `En` | 顽火辉石 | `Fl` | 萤石 |
| `Fs` | 铁辉石 | `Hl` | 石盐 |
| `ns` | 偏硅酸钠 | `Th` | 芒硝 |
| `ks` | 偏硅酸钾 | | |

正长石、钠长石和霓石在内部按化学式单位计数：1 mol K₂O 生成 2 mol `Or`，1 mol Na₂O 生成 2 mol `Ab` 或 `Ac`。写出的始终是质量百分比。

## 计算详情

选中已成功计算的行后，右侧检查器显示：

- 样品名。样品列为空时显示「第 N 行」。
- 硅饱和度与铝饱和度。不饱和时硅饱和度高亮。
- **铁处理模式**。只要不是「实测值」就高亮。
- **质量平衡误差**，保留 6 位小数。超过 `1×10⁻⁶` 时高亮。
- **矿物总量**，即各标准矿物 wt% 之和，保留 4 位小数。黄铁矿、萤石、石盐形成时释放的氧不计入这个总量，但会计入质量平衡。
- **主要矿物**：含量大于 `0.01 wt%` 的矿物，从高到低排列；大于 `10 wt%` 的条目高亮。
- **警告**：铁数据缺失或不一致、由 FeOT 估算、MnO 换算、残余硅亏损等。

检查器右上角可以把这一份详情导出为 CSV，或复制到剪贴板。

## 计算过程

下面按当前计算代码的实际顺序说明。磷灰石最先占用钙，然后才形成挥发分矿物；榍石和金红石放在钙长石之后。

矿物摩尔质量全部由氧化物摩尔质量按化学式推导，避免手工取整造成质量不平衡。计算使用的数值容差是 `1×10⁻¹²`。任一步使 SiO₂ 以外的氧化物变为明显负值时，该行失败。

### 1. 无水归一化与铁、锰

把所有已提供且非负的氧化物归一化到 100%。按上一节处理铁，再把 MnO 换成 FeO 当量，然后**再归一化一次**。总量不大于 0 时该行失败。

### 2. 换成摩尔数

每种氧化物的摩尔数 = 归一化后的 wt% / 摩尔质量。随后的分配都在 mol/100 g 尺度上进行。

### 3. 磷灰石

磷灰石最先占用钙。1 mol `P2O5` 结合 `10/3` mol `CaO`（不含 OH 或 F）：

```text
Ap = min(P2O5, CaO / (10/3))
```

### 4. 挥发分矿物

按下面的顺序，能结合多少就生成多少：

| 矿物 | 计量 |
| --- | --- |
| 方解石 `Cc` | `min(CO2, CaO)` |
| 萤石 `Fl` | `min(F/2, CaO)`，即 1 mol CaO 结合 2 mol F |
| 黄铁矿 `Py` | `min(S/2, FeO)`，即 1 mol FeO 结合 2 mol S |
| 石盐 `Hl` | `min(Cl, 2×Na2O)` |
| 芒硝 `Th` | `min(SO3, Na2O)` |

### 5. 锆石、铬铁矿、钛铁矿

- 锆石 `Z`：全部 `ZrO2` 与等量 `SiO2`。
- 铬铁矿 `Cm`：`min(Cr2O3, FeO)`。
- 钛铁矿 `Ilm`：`min(TiO2, FeO)`。

这一步只用掉能和 FeO 结合的钛。剩余 TiO₂ 留到钙长石之后。

### 6. 长石、刚玉与剩余碱

先记录铝饱和状态，再分配：

| 矿物 | 条件与产物 |
| --- | --- |
| 正长石 `Or` | `min(K2O, Al2O3)`，消耗 6 倍 SiO₂，产物摩尔数为该值的 2 倍 |
| 钠长石 `Ab` | `min(Na2O, Al2O3)`，同样消耗 6 倍 SiO₂，产物为 2 倍 |
| 钙长石 `An` | `min(CaO, Al2O3)`，消耗 2 倍 SiO₂ |
| 刚玉 `Cor` | 剩余 Al₂O₃ |
| 霓石 `Ac` | `min(剩余 Na2O, Fe2O3)`，消耗 4 倍 SiO₂，产物为 2 倍 |
| 偏硅酸钠 `ns` | 剩余 Na₂O 与等量 SiO₂ |
| 偏硅酸钾 `ks` | 剩余 K₂O 与等量 SiO₂ |

长石阶段允许 SiO₂ 先记成负值，留给后面的去硅统一处理。

### 7. 榍石与金红石

榍石只用钙长石之后剩下的 CaO，并且**不用当时的 SiO₂ 余量来限制榍石**：

```text
Tn = min(剩余 TiO2, 剩余 CaO)
```

`Tn` 同时消耗等量 SiO₂。最后仍剩下的 TiO₂ 记为金红石 `Ru`。

### 8. 铁氧化物

```text
Mt = min(Fe2O3, FeO)
Hm = 剩余 Fe2O3
```

### 9. 辉石与硅灰石

设 `MgFe = MgO + FeO`。单斜辉石总量为 `min(CaO, MgFe)`，再按镁铁比拆成透辉石 `Di` 和钙铁辉石 `Hd`，每份辉石消耗 2 份 SiO₂。

剩余的 MgO、FeO 全部成为顽火辉石 `En` 和铁辉石 `Fs`，各消耗 1 份 SiO₂。镁和铁都用完之后，若还有 CaO，则全部成为硅灰石 `Wo`。

### 10. 硅饱和度与去硅

去硅顺序为：紫苏辉石 → 榍石 → 钠长石 → 正长石 → 硅灰石 → 透辉石/钙铁辉石 → 白榴石。每一步只消耗当时还缺的 SiO₂。

| 顺序 | 反应 | 释放的 SiO₂ |
| --- | --- | --- |
| 1 | 2 顽火辉石/铁辉石 → 1 镁橄榄石/铁橄榄石 | 每 2 mol 辉石释放 1 mol |
| 2 | 榍石 `Tn` → 钙钛矿 `Pf` | 1 mol `Tn` 释放 1 mol |
| 3 | 钠长石 `Ab` → 霞石 `Ne` | 1 mol `Ab` 释放 2 mol |
| 4 | 正长石 `Or` → 白榴石 `Le` | 1 mol `Or` 释放 1 mol |
| 5 | 2 硅灰石 `Wo` → 1 斜硅钙石 `Cs` | 每 2 mol `Wo` 释放 1 mol |
| 6 | 透辉石/钙铁辉石 → 斜硅钙石 + 橄榄石 | 1 mol 辉石释放 1 mol；镁进入 `Fo`，铁进入 `Fa` |
| 7 | 白榴石 `Le` → 假白榴石 `Kp` | 1 mol `Le` 释放 1 mol |

SiO₂ 有剩余时生成石英，状态为过饱和。SiO₂ 恰好为零时为饱和。进入上表则为不饱和。

### 11. 质量百分比与质量平衡

标准矿物质量 = 摩尔数 × 由化学式推导的摩尔质量，再相对于归一化后的氧化物总量换成 wt%。

黄铁矿、萤石和石盐里的 S、F、Cl 置换了氧化物中的氧。释放的氧不进入任何矿物，质量平衡时加回去：

```text
释放氧的摩尔数 = Fl + Py + Hl / 2
质量平衡误差 = |100 − (矿物 wt% 之和 + 释放氧的 wt%)|
```

误差大于 `1×10⁻⁶` 时，该行记为警告。

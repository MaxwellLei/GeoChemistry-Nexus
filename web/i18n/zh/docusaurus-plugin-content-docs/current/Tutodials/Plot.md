# 图解

在图解模块，我们将整合更多基础地球科学图解模板，包括但不限于：构造环境判别图、岩石分类图等。**我们的最终目标是为地球科学创建一个全面的图框-绘图工具包，为研究人员提供最大的便利。** 🧪

:::info

如果您是从事地质图解等相关领域研究的科研人员，并希望推广自己的图解成果，欢迎与我们联系！我们将助力您的图解成果触达更广泛的科研群体，进一步提升学术成果的传播效率与影响力。

:::

## 快速开始

我们的软件图解模块主要由两部分组成：图解模板库和图解操作界面。您可首先在图解模板库中选择所需的图解类型，随后进入相应的操作界面，完成数据输入、图解处理及结果导出等操作。

### 模板库

我们将图解模块分为三大类：**在线云模板**，**我的模板**和**工具图解模板**。

**在线云模板**：由我们持续更新和维护。您无需更新软件，在联网情况下，即可获取更新图解模板，确保始终拥有最全面和权威的模板资源。

**我的模板**：适用于需要针对特定研究需求创建自定义模板的场景。您不仅可以自己创建这些模板，还可以将其导出以便与其他研究人员轻松分享，促进学术交流和传播。

> *未来，我们计划建立一个专门的图解模板社区，用户可以轻松创建、上传、分享和下载各种 **个人自定义模板**，进一步增强系统的灵活性和可扩展性。*

**工具图解模板**：将固定的常规图解单独剥离出来，目前包含：**稀土元素蛛网图，微量元素蛛网图，哈克多联图解**，以及常规的二维和三元散点图。

#### 界面

默认情况下，绘图模块进入时显示内置地球科学模板库。界面分为三个主要部分：

*   **左侧 - 图解分类**：显示所有模板层级和相应的模板，包括自定义模板列表。
*   **右侧 - 图解卡片**：显示当前层级下的图解卡片，包括名称和预览图像。
*   **顶部 - 导航栏**：软件采用无边框设计，所以顶部的导航栏承接了每个页面的部分功能，在图解界面，顶部导航栏会显示当前图解模板路径，以及图解模板搜索等功能。

![graphical_interface](/img/v0.9.0/en-US/graphical_interface.webp)

选择合适的图解模板，点击图解模板卡片即可进入图解操作界面。对于图解模板卡片，你也可以右键进行导出，删除，收藏等更多操作。

:::tip

可以通过按下右 <kbd>Alt</kbd> 按键来对图解模板进行快捷删除/收藏。

:::

#### 顶部菜单栏

顶部**文件**菜单栏包含：

1.  **新建图解**：用于创建自定义图解模板。
2.  **打开图解**：用于临时打开图解模板；仅支持 `.diag.zip` 文件。
3.  **导入图解**：用于将外部图解模板包（`.diag.zip`）导入本地我的模板列表。

### 图解操作界面

#### 界面

图解界面分为五个主要部分：

-   **工具栏**：包括快捷按钮和三个功能选项卡：绘图、数据和编辑。
-   **图层列表（对象）**：模板上的绘图元素列表。点击元素允许你修改其属性。
-   **绘图画布**：用于查看图表、导入数据、视觉设置和查看模板说明的中心区域。
-   **状态栏**：显示基本绘图信息，包括当前图表语言和坐标信息。
-   **属性面板**：显示所选绘图元素（如颜色、大小）的属性，以实现所需的视觉效果。

![graphical_operation_interface](/img/v0.9.0/en-US/graphical_operation_interface.webp)

#### 图解工具栏

工具栏由一系列**快捷按钮**组成。主要是：

1. 返回图解模板库
2. 切换操作状态（图解模式，数据模式，编辑模式）
3. 图解各种属性面板和操作工具等

详细功能参见下图。

![graphical_toolbar](/img/v0.9.0/en-US/graphical_toolbar.webp)

### 图层列表

绘图元素分为 7 大类：

-   **Line (线条)**：定义基本的图解边界或线段。
-   **Text (文本)**：标签和注释。
-   **Polygon (多边形)**：图表内的封闭形状。
-   **Arrow (箭头)**：定向绘图对象。
-   **Function (函数)**：允许用户输入自定义数学函数和定义域。
-   **Axes (坐标轴)**：图表的坐标轴。
-   **Data Point (数据点)**：代表导入数据的元素。

**默认渲染顺序（从上到下）：`数据点 > 文本 > 箭头 > 函数 > 线条 > 多边形 > 坐标轴`**。

![tutorial_plot5](/img/v0.9.0/en-US/diagrammatic_object_selection_example.webp)

当您在图层面板中选择一个元素时，它将在画布上高亮显示，而其他元素变为半透明以减少干扰。属性面板随后将显示该元素的相关属性。 🔍

您可以修改这些属性以达到您想要的视觉风格。

:::tip

要取消选择所有元素，只需**在画布上的任意位置右键点击**或使用工具栏上的**取消选择**按钮。

:::

## 使用示例

### 示例

1. 从 **图解模板库** 中选择一个图解模板进入图解擦欧总页面。例如：选择 TAS 图解。
2. 当我们需要输入数据的时候，需要从图解模式，切换到数据模式。
   
   ![tutorial_plot6](/img/v0.9.0/en-US/diagram_data_input.webp)


对于 TAS 图解，必须要输入的是四列数据：`Category`, `SiO2`, `K2O`, 和 `Na2O`。其中`Category` 标题列用于对数据进行分组并生成图例；`Sample`列用标识数据样本标签，不会参与任何计算（可以为空）；其他元素的单位是 `wt.%`。而当然，如果你不清楚这个图解到底输入的数据是什么，什么单位，图解怎么用等，可以点击图解区域右上角的图解帮助按钮查看关于该图解的说明文档。

3. 了解需求后，输入你的数据点击数据面板右上角的投点按钮以绘制数据点。如果数据输入有问题，在修改数据后，重新点击投点即可。![tutorial_plot8](/img/v0.9.0/en-US/data_plotting.webp)
4. **导出图解**。我们提供了一个**快捷复制图解投图结果到粘贴板功能按钮**。还有一个**正式导出功能**。在正式导出面板中，我们支持导出图片格式为 `jpg`，`png`，`bmp`，`svg`。在科研绘图需要矢量图的情况下，我们推荐使用 `svg` 格式。同时我们也支持**直接将结果联动到第三方作图软件中**，无需经过导出再导入这一中间步骤。第三方软件内置推荐的是：**CoreIDRAW，Inkscape，Adobe llustrator**。我们推荐使用 Inkscape 联动进行后期二次科研修图会更佳。当然我们也支持自定义一个其他第三方作图软件，前提是该软件支持`svg` 矢量图格式。研究人员只需在设置中，指定作图软件程序路径即可。
   ![tutorial_plot8](/img/v0.9.0/en-US/export_diagram.webp)

### 补充说明

图解模板本身支持多语言切换，即：一份图解可以切换成多种语言版本，以满足国际化需要。

例如：发表中国期刊发表论文的图解需要使用中文语言版本，在英文 SCI/IE 等期刊上发表需要使用英文版本的图解。你可以通过点击图解工具栏右上角的图解来一键切换对应语言版本的图解。

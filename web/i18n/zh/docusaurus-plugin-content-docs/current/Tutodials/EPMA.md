# EPMA 矿物计算

**EPMA 矿物计算**用于处理电子探针分析得到的矿物成分。通过将一批分析点的氧化物含量，按所选矿物计算方法换算成矿物化学结果，供矿物鉴定、成分对比和后续地质解释使用。

## 界面

EPMA矿物计算主要分类两个界面，即**EPMA矿物计算模板库**和**EPMA计算界面**。

您可以在EPMA矿物计算模板库中搜索，筛选并选择您合适的矿物EPMA计算，在最右侧的说明面板，您可以查看关于这些计算模板的基础信息。点击**进入计算**即可进行计算。

## 使用示例

例如，我们选择了其中一个橄榄石的EPMA计算模板，然后点击进入计算界面。可以看到整体分为上下两个部分，顶部栏中您可以选择查看该计算模板的详细说明文档，或者加载示例数据。



在您按照表格需要的需要，输入对应的数据即可点击顶部栏的**执行计算**按钮。

其中白灰色的区域是您要输入的区域，蓝紫色的区域是结果输出区域。您可以自由的查看数据输出，或者点击**检查**按钮来查看中间的计算过程输出。



需要说明的是每行行头前面的带颜色的圆点，代表的是每行的计算状态，其中计算状态包括：

* **灰色**：该行存在数据，但是未计算
* **绿色**：该行已经正常完成计算，无警告，无错误
* **橙色**：已经计算完成，但是存在警告
* **红色**：该行计算错误

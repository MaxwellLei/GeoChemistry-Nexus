# 🌍 简介

**GeoChemistry Nexus 是一款面向地球化学、岩石学、矿物学与矿床学等领域研究人员的一体化科研工作平台。**

软件将判别图解绘制、地质温压计计算、EPMA 矿物化学计算、CIPW 标准矿物计算、Niggli 标准矿物计算等常用科研计算整合于统一的工作环境中，减少不同软件与工具之间的切换，让地质数据处理、计算分析与可视化工作更加连贯高效。

同时，GeoChemistry Nexus 通过云端模板生态，支持图解模板与计算算法的持续更新、共享与复用，让科研工具能够不断扩展，逐步构建开放、灵活且可持续发展的地学科研工作环境。

**3 分钟快速上手** **GeoChemistry Nexus** ⏱️。

## 前置条件 🛠️

目前，**GeoChemistry Nexus 仅支持 Windows 操作系统**，暂不提供 macOS 和 Linux 原生版本。

- **Windows 用户**：请确保操作系统版本为 Windows 7 或更高版本
- **macOS / Linux 用户**：目前尚未提供原生运行方案。如需使用，可尝试通过虚拟机安装 Windows 后运行 GeoChemistry Nexus，但实际兼容性与运行性能取决于虚拟机环境。

### 🚀 跨平台支持计划

我们正在规划软件的跨平台适配工作，未来将探索基于 `Avalonia UI` 的技术迁移方案，以逐步支持 macOS 和 Linux 等操作系统。

## 以此开始 🚀

[点击这里](https://github.com/MaxwellLei/GeoChemistry-Nexus/releases) 访问下载页面。选择合适的版本，选择适合的版本，下载对应的安装包。

下载完成后，按照安装向导完成安装。安装成功后，双击 `GeoChemistry Nexus.exe` 即可启动软件，开始使用！ 🖱️

### 关于软件错误与反馈 💬

GeoChemistry Nexus 仍在持续开发与完善中。作为开发者，我也难免会有考虑不周或实现上的疏漏，软件在功能设计、计算逻辑、数据处理及界面交互等方面，都可能存在尚未发现的问题。尽管我会尽力保证软件的可靠性与计算准确性，但无法承诺软件在所有情况下都完全没有错误。

# 制作一个图解模板

对于在线图解模板库中尚未收录的图解模板，您可以选择制作一个自定义图解模板。通过自定义模板并将其打包成模板包，你可以快速与其他研究人员分享。

你也可以选择将你的模板提供给开发者以收录到在线图解模板库中。我们衷心感谢任何参与者的贡献。

## 快速创建

现在，您可以通过菜单栏选择 `文件` -> `新建图解模板` 来创建一个新的图解模板，如下所示：

对于新的自定义图表模板，主要有三个部分需要配置：

1.  **默认支持语言**：你可以从右侧的选择框中选择内置的语言快捷选项。我们提供：简体中文、繁体中文、美式英语、日语、俄语、韩语、德语等十种语言。

    > 需要说明的是：默认语言的作用是在如果其他语言未翻译或遇到错误，将回退到的语言。另外，在新版中，现在我们不在允许用户自定义语言代码。如果您需要您的语言支持，请联系开发者。

2.  **图解模板分类（层级）**：我们提供内置的快捷分类结构。此设置影响你的模板在图表模板列表中的层级位置。

3.  **图表模板类型**：目前支持两种类型：**二维坐标系** 和 三元图。

完成设置后，点击【确定】进入自定义绘图界面。接下来，我们将操作重心放在【编辑】功能栏上。点击【编辑】后，系统将显示二次确认对话框以编辑图表。确认后，你将进入编辑模式，在这里可以查看和使用编辑功能栏中的各种工具。

## 绘制图解

在编辑模式下，允许进行以下操作：

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/graphical_toolbar.webp')}
    alt="绘制图解"
    style={{width: '100%'}}
  />
</div>

* **保存**：保存图表模板。点击后，程序默认会根据当前绘图状态生成相应的缩略图。
* **另存为**：将图表模板保存到不同的文件位置。
* **添加线条**：启用后，进入“添加线条”模式。点击绘图区域的第一个点开始画线，点击第二个点完成线条对象。
* **添加文本**：也称为注释。启用后，进入“添加文本”模式。点击绘图中的特定位置即可创建。默认文本为 `Text`。你可以通过图层面板中的属性部分修改位置或内容。
* **添加多边形**：启用后，进入“添加多边形”模式。通过连续左键点击创建顶点来添加封闭多边形，右键点击闭合形状。
* **添加箭头**：启用后，进入“添加箭头”模式。添加过程类似于创建线条。
* **添加函数**：点击后，添加一个默认函数 `sin(x)`，定义域范围为 [-10, 10]。你可以在属性面板中自定义公式。
* **撤销/重做**：如果没有创建或删除绘图对象，这些功能将被禁用。默认情况下，历史记录中仅存储最后 10 次操作。
* **删除**：删除绘图对象。首先选择对象（例如文本），然后点击删除将其移除。

### 添加函数

添加函数和前面的对象不同，**点击添加函数按钮后，会立即添加一个默认的函数对象**。其中，默认函数是 `sin(x)`。您可以在属性面板中修改函数公式来定义您的函数。

对于函数对象的属性，两个最重要的参数是：**定义域** 和 **采样点**。

* **定义域定义了函数的在画布中的显示范围**。
* **采样点控制函数在画布中的绘制精度**，进而影响鼠标捕捉选择算法的准确性。默认值为 `1000`。精度越高，函数渲染约精细，但是也会带来程序的渲染负担。

## 完善图解模板

完成基本图形绘制后，一个完整的模板还需要：

1.  **数据与脚本**：用来定义图解模板的输入数据和数据计算算法，即指示数据如何计算并完成投图。
2.  **图解文档**：用来说明该图解的帮助说明内容。
3.  **多语言**：如果图解模板设置为两种以上的语言，则需对多语言部分进行翻译。包括上一个的【图解文档】以及图解画布中的文本对象等内容。

对于图解模板的完善，尽管可以在图解操作界面中完成，但是我们还是建议您在图解的编辑窗口中进行将会更加便捷。

### 数据与脚本

数据与脚本是图解模板的关键部分，因为它定义了图解中数据是如何计算并最终呈现在图上的。

它需要两个参数：图解模板的**变量参数** 和 **计算算法（脚本）**，如下所示：

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/diagram_data_and_script.webp')}
    alt="图解-数据与脚本"
    style={{width: '100%'}}
  />
</div>

对于图解模板的**变量参数**，你可以在顶部添加对应的列，来表示该图解需要的输入列。其中含有两个可选参数 

1. Unit 表示输入列的单位，仅作展示说明，并不会影响数据算法。
2. Group 表示输入列的分组，仅作展示说明，并不会影响数据算法。

需要说明的是，**您在数据表格中定义的列标题，将会被默认为下面脚本可以直接调用的已注册变量**。这就意味着，您不需要在脚本中重复定义输入列的变量。

对于**计算算法（脚本）**，默认使用 `JavaScript` 语言编写。默认的脚本示例内容为 `return [X,Y]`，即将数据表格中定义输入列 `X` 和 `Y` 返回给二维坐标轴。

例如，对于 TAS 图，参数应为：`SiO2, Na2O, K2O`。脚本内容将是：

```javascript
// 使用变量 K2O + Na2O 计算
var result1 = K2O + Na2O;
// 使用 SiO2
var result2 = SiO2;
// 返回两个计算值。注意，对于默认的二维坐标图像，只有两个返回值。
// 第一个位置代表 X 返回值，第二个代表 Y 返回值。
return [result2, result1]
```

或者，你可以将脚本编写如下：

```javascript
var result = K2O + Na2O
return [SiO2, result]
```

注意返回值的位​​置是固定的。在 `[x, y]` 中，第一个值始终是 X（底轴），第二个是 Y（左轴）。

:::info

对于三元图，最终返回格式为 `[A, B, C]`，其中第一个值是 A（底轴），第二个是 B（左轴），第三个是 C（右轴）。

:::

### 图解文档

图解文档是帮助其他研究人员快速了解该图解基本信息和用法的必要步骤。

在帮助文档页面进行图解文档的编写。我们提供简单的工具栏功能以满足常规文档需求。当然，您也可以在`Office Word` 中编写文档内容，然后将内容粘贴在这里，他们的绝大部分格式都是通用适配的。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/diagram_help_document.webp')}
    alt="图解-帮助文档"
    style={{width: '100%'}}
  />
</div>

对于图解文档的编写格式，我们建议遵循以下标准：

*   **简介**：解释图解模板的基本概念和功能，帮助用户快速理解。
*   **数据格式**：指定有效数据读取所需的输入数据格式和列标题。
*   **参考文献**：列出用于创建图解模板及其内容的参考文献。
*   **贡献者**：参与图解模板制作的人员名称。甚至鼓励你包含您的个人网站。

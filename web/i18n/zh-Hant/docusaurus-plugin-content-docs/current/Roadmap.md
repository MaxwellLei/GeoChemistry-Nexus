# 🛣️ 路線圖

GeoChemistry Nexus 的目標是逐步建成 **資料 · 圖解 · 計算 · 協作** 一體化的地球化學與岩石學科研工具鏈。

## ✅ 已完成


### 核心工作流程
- [x] **首頁**：快速連結、實用小工具
- [x] **判別圖解**：以範本庫內建大量判別圖解，包括但不限於：構造環境判別圖、岩石分類圖等等；除此之外支援微量元素和稀土元素蛛網圖，並且內建大量標準化方案；支援哈克圖解多聯圖投圖；
- [x] **地質溫壓計**：內建線上多礦物地質溫壓計算範本及類 Excel 自訂函數
- [x] **EPMA 礦物計算**：內建線上即時更新的各種礦物 EPMA 計算範本，下載即可使用。
- [x] **CIPW 標準礦物計算**：全岩主量資料標準化計算與結果匯出
- [x] **niggli 標準礦物計算**：全岩主量資料標準化計算與結果匯出
### 平台能力
- [x] **效能相依**：極低的記憶體佔用，極小的安裝空間需求，在不含 `.NET` 執行階段時，軟體本機僅 9 MB。
- [x] **範本生態**：線上範本雲端動態更新；自訂範本建立、匯入與打包分享；可查看計算過程細節以便核對。
- [x] **多語言**：介面在地化（中 / 英 / 德 /  俄 / 日 / 韓等）；圖解範本多語言一鍵切換
- [x] **匯出與整合**：PNG / JPG / BMP / SVG 匯出；支援與 CorelDRAW、Inkscape、Adobe Illustrator 等第三方軟體協作

## 🔭 中長期願景
### 機器學習輔助分析
引入常用機器學習流程，輔助地球化學資料判別與分類，輸出模型評估、變數重要性及 ROC 曲線、混淆矩陣等視覺化結果——**無需使用者自行設定 Python 環境**。
### 「新圖解」式判別模型
支援載入可擴充的機器學習判別模型（例如以大量資料訓練的新型判別圖），讓研究者直接套用「新圖解」進行分析，而不必掌握完整的 ML 開發堆疊。
### AI 科研助手（分階段）
1. **第一階段**：以內建說明文件與知識庫為基礎的 RAG 問答，依照關鍵詞與情境給出操作建議  
2. **第二階段**：進一步輔助資料處理與分析流程，簡化重複性操作

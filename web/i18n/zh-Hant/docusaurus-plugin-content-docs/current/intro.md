# 🌍 簡介

**GeoChemistry Nexus 是一款面向地球化學、岩石學、礦物學與礦床學等領域研究人員的一體化科研工作平台。**

軟體將判別圖解繪製、地質溫壓計計算、EPMA 礦物化學計算、CIPW 標準礦物計算、Niggli 標準礦物計算等常用科研計算整合於統一的工作環境中，減少不同軟體與工具之間的切換，讓地質資料處理、計算分析與視覺化工作更加連貫高效。

同時，GeoChemistry Nexus 透過雲端模板生態，支援圖解模板與計算演算法的持續更新、共享與複用，讓科研工具能夠不斷擴展，逐步構建開放、靈活且可持續發展的地學科研工作環境。

**3 分鐘快速上手** **GeoChemistry Nexus** ⏱️。

## 前置條件 🛠️

目前，**GeoChemistry Nexus 僅支援 Windows 作業系統**，暫不提供 macOS 和 Linux 原生版本。

- **Windows 使用者**：請確保作業系統版本為 Windows 7 或更高版本
- **macOS / Linux 使用者**：目前尚未提供原生執行方案。如需使用，可嘗試透過虛擬機器安裝 Windows 後執行 GeoChemistry Nexus，但實際相容性與執行效能取決於虛擬機器環境。

### 🚀 跨平台支援計畫

我們正在規劃軟體的跨平台適配工作，未來將探索基於 `Avalonia UI` 的技術遷移方案，以逐步支援 macOS 和 Linux 等作業系統。

## 以此開始 🚀

[點擊這裡](https://github.com/MaxwellLei/GeoChemistry-Nexus/releases) 存取下載頁面。選擇合適的版本，下載對應的安裝套件。

下載完成後，按照安裝精靈完成安裝。安裝成功後，按兩下 `GeoChemistry Nexus.exe` 即可啟動軟體，開始使用！ 🖱️

### 關於軟體錯誤與回饋 💬

GeoChemistry Nexus 仍在持續開發與完善中。作為開發者，我也難免會有考慮不周或實作上的疏漏，軟體在功能設計、計算邏輯、資料處理及介面互動等方面，都可能存在尚未發現的問題。儘管我會盡力保證軟體的可靠性與計算準確性，但無法承諾軟體在所有情況下都完全沒有錯誤。

如果您在使用過程中發現任何 Bug、計算異常、不合理的結果，或有更好的功能建議，歡迎隨時透過 GitHub Issues 回饋。每一條回饋和建議，都是 GeoChemistry Nexus 持續改進的重要動力。

**軟體的完善離不開每一位使用者的幫助。感謝您的理解、支持與參與！**

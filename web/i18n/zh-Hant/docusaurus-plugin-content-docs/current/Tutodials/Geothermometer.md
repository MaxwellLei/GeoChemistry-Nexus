# 地質溫壓計

在早期的版本中，此模組簡稱為 **GTM**。後來改成地質溫度計，到如今正式定名為：地質溫壓計。

早期版本包含鋯石、閃鋅礦、石英、磷釔礦、綠泥石和黑雲母等礦物的地質溫度計計算。新版本的地質溫壓計還在更新適配中，不久將會同步。

## 介面

地質溫壓計模組整體可以分為兩個部分：

1. 左側是 **溫壓計範本清單**，您可以在這裡尋找適合您的溫壓計範本，或者您可以建立自己的溫壓計計算範本。
2. 右側是 **目前選取的溫壓計範本的說明文件**

## 功能

地質溫壓計模組設計之初就 **仿照 Excel 的形式**，來降低使用者的上手成本。**主要分為兩種形式來使用溫壓計**：

1. **線上溫壓計範本**：預設 **線上溫壓計範本** 使用者不可修改，但是可以查看演算法實作邏輯。您可以在不更新軟體的情況下，連線取得更多最新的地質溫壓計範本。研究人員可以搜尋、篩選並選擇適合自己的範本，並按照指南內容進行資料填寫和計算。**這種方式更直接、更快速，無需程式設計知識**。
2. **獨立計算視窗**：研究人員可以透過頂端功能表列，**檔案 -> 開啟獨立表格，來開啟獨立計算視窗**。在獨立視窗中，研究人員可以自行撰寫程式，使用不同的地質溫壓計進行組合計算。各溫壓計對應的函數，請參見進階教學部分。**這種方式更複雜，相對靈活**。

當然，地質溫壓計模組也允許研究人員建立自己的自訂地質溫壓計。可以將製作好的地質溫壓計範本匯出，分發給其他研究人員快速使用。

## 使用範例

### 使用線上溫壓計範本

首先，在地質溫度計模組內，從左側邊欄篩選並選擇相應的計算範本：

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/select_and_apply_thermobarometer_template.webp')}
    alt="選擇地質溫壓計"
    style={{width: '100%'}}
  />
</div>

你可以在右側面板查看該範本的說明文件，頂列也會顯示目前選取的地質溫壓計範本的標題和標籤。在你選擇好對應的溫壓計範本後，你可以點選頂列的 **套用** 按鈕，來進入溫壓計計算介面。

在溫壓計介面，可以看到對應的輸入欄，當然你也可以點選頂列的 **範例** 按鈕來載入範例資料。您只需要根據欄標題的要求填入相應的資料，然後 **複製計算公式** 或者 **使用「點選並拖曳」填滿控點**（類似於 Excel）自動完成計算（如下面的動畫範例所示）。

> 需要說明的是，`Sample` 欄不參與計算，只做註解以標識資料的樣本

### 獨立視窗－自訂函數

如前面所講述，可以透過功能表列，**檔案 -> 開啟自由表格**，來開啟獨立自由視窗。

獨立視窗表格是一個空白表格，並包含一些簡單的工具列按鈕。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/thermobarometer_free_form.webp')}
    alt="溫壓計自由計算表格"
    style={{width: '100%'}}
  />
</div>

使用獨立視窗表格就和我們日常 **使用 Excel 表格一樣，可以輸入任意數值，透過輸入 `=函數名稱(傳遞參數)` 來呼叫函數**。

不同的是，我們的地質溫壓計計算被註冊為了對應的計算函數，研究人員可以根據需求更靈活地自訂內容計算。您甚至可以 **在同一個表格中比較多個溫壓計的結果**。

:::note

需要注意的是：**在獨立視窗表格下，無法查看對應資料列的中間計算過程**。

:::

# EPMA 礦物計算

**EPMA 礦物計算**用於處理電子探針分析得到的礦物成分。透過將一批分析點的氧化物含量，按所選礦物計算方法換算成礦物化學結果，供礦物鑑定、成分對比和後續地質解釋使用。

## 介面

EPMA礦物計算主要分為兩個介面，即**EPMA礦物計算模板庫**和**EPMA計算介面**。

您可以在EPMA礦物計算模板庫中搜尋、篩選並選擇適合的礦物EPMA計算。在最右側的說明面板，您可以查看這些計算模板的基礎資訊。點擊**進入計算**即可進行計算。

## 使用範例

例如，我們選擇了其中一個橄欖石的EPMA計算模板，然後點擊進入計算介面。可以看到整體分為上下兩個部分，頂部列中您可以選擇查看該計算模板的詳細說明文件，或者載入範例資料。

在您按照表格的需要輸入對應的資料後，即可點擊頂部列的**執行計算**按鈕。

其中白灰色的區域是您要輸入的區域，藍紫色的區域是結果輸出區域。您可以自由查看資料輸出，或者點擊**檢查**按鈕來查看中間的計算過程輸出。

需要說明的是每行行首前面的帶顏色圓點，代表的是每行的計算狀態，其中計算狀態包括：

* **灰色**：該行存在資料，但是未計算
* **綠色**：該行已經正常完成計算，無警告，無錯誤
* **橙色**：已經計算完成，但是存在警告
* **紅色**：該行計算錯誤

# Niggli 標準礦物計算

**Niggli 標準礦物計算**對同一列全岩氧化物做兩套結果：

1. **尼格里參數**：`si`、`al`、`fm`、`c`、`alk`、`k`、`mg`、`qz`，另有只在計算詳細資料中顯示的 `ti`、`p`。
2. **Barth–Niggli 分子標準礦物（Catanorm）**：以陽離子百分比（cat%）表示的標準礦物、端元組成，以及矽不飽和時的去矽歷程。

Catanorm 由 Paul Niggli（1948）與 Tom F. W. Barth（1948）建立。它按陽離子當量分配，減輕鐵等重元素在質量百分比裡所佔的比重，因此比 CIPW 的 wt% 更接近薄片中的礦物體積關係。質量百分比標準礦物見 [CIPW 標準礦物計算](./CIPW)。

演算法參考 GCDkit 的分子標準礦物流程，並重新實作；其中白榴石進一步去矽的產物記入鉀霞石 `Kp`。

## 介面

頂列與 CIPW 相同：**Fe³⁺/ΣFe**、**說明**、**範例**、**匯出**、**清空**、**執行計算**。Fe³⁺/ΣFe 的範圍是 `0`–`1`，預設 `0.15`（Le Maitre, 2002）。

**範例**填入三列：花崗岩、玄武岩、響岩（Phonolite）。前兩列是矽較高的常見火山岩，響岩用於查看霞石、白榴石一類的不飽和結果。

工作表從左到右分為五段：

| 區域 | 分組 | 單位 | 內容 |
| --- | --- | --- | --- |
| 樣品 | — | — | 樣品名稱，不參與計算，水平捲動時保持可見 |
| 氧化物 | 主量元素；其他氧化物 / 揮發分 | wt% | 輸入區 |
| 尼格里參數 | 尼格里參數 | 無因次 | `si`、`al`、`fm`、`c`、`alk`、`k`、`mg`、`qz` |
| 診斷 | 診斷 | — | 矽飽和狀態、鋁飽和狀態、礦物總和 |
| 標準礦物 | 標準礦物 | cat% | 陽離子百分比。最後一欄是 `Sum(總和)` |

樣品欄凍結。表格最初 500 列，支援在填滿控點上按兩下向下填滿。輸入改變後，已計算的列會變成過期狀態，需要重新點選 **執行計算**。

### 列首狀態

| 圓點 | 含義 |
| --- | --- |
| 灰色空心 | 已有輸入，尚未計算 |
| 青綠實心 | 計算成功，沒有警告 |
| 橙色實心 | 計算成功，但使用了 FeOT 估算鐵價態 |
| 紅色實心 | 計算失敗。診斷欄寫有「計算錯誤」和原因 |
| 橙色空心 | 計算之後修改了氧化物，結果已過期 |

同時填寫了 FeO 和 Fe₂O₃ 的樣品，計算成功後是青綠點。只有 FeOT 時會出現鐵價態警告，列首為橙色。

## 輸入

每一列一個樣品，單位是氧化物質量百分比（wt%）。只讀取大於 0 的儲存格；空白和 0 視為未提供。

主量元素，到 `K2O` 為止：

`SiO2`、`TiO2`、`Al2O3`、`Fe2O3`、`FeO`、`FeOT`、`MnO`、`MgO`、`CaO`、`Na2O`、`K2O`

其他氧化物 / 揮發分：

`CO2`、`P2O5`、`F`、`S`

本模組不讀取 `ZrO2`、`Cr2O3`、`Cl`、`SO3`。這四項若需要進入標準礦物，使用 CIPW 模組。

### 鐵的處理

鐵在換成陽離子之前處理。拆分時把鐵先還原成 Fe 原子：全鐵莫耳數 = 鐵的質量 / FeO 莫耳質量，再按 Fe³⁺/ΣFe 分成三價與二價，三價鐵的一半寫入 Fe₂O₃。

| 填寫情況 | 處理 |
| --- | --- |
| 同時有 `Fe2O3` 和 `FeO` | 使用實測值。即使旁邊還有 `FeOT`，也不再拆分 |
| 有 `FeOT`，且沒有同時具備 Fe₂O₃ 和 FeO | 用 `FeOT` 按目前比值拆分，並在詳細資料中警告 |
| 只有 `Fe2O3`，沒有 `FeO` 也沒有 `FeOT` | 把這份 Fe₂O₃ 當作全鐵，再按比值拆成 Fe₂O₃ 和 FeO |
| 只有 `FeO`，沒有 `Fe2O3` 也沒有 `FeOT` | 把這份 FeO 當作全鐵，再按比值拆成 Fe₂O₃ 和 FeO |

因此，只化驗了 FeO 或只化驗了 Fe₂O₃ 時，結果會隨頂列比值變化。若這兩項都是實測值，請兩欄都填寫。

`MnO` 保留到陽離子換算。它進入尼格里參數的 `fm` 和 `mg`，進入 Catanorm 後併入 Fe²⁺。

## 尼格里參數

參數用氧化物的**分子數**計算，分子數 = wt% / 莫耳質量。這裡的 `al` 是 Al₂O₃ 的分子數，一份 Al₂O₃ 算 1，和後面 Catanorm 裡「一份 Al₂O₃ 算 2 個 Al」不是同一個基數。

```text
al  = n(Al2O3)
fm  = n(FeO) + 2 n(Fe2O3) + n(MnO) + n(MgO)
c   = n(CaO)
alk = n(Na2O) + n(K2O)
base = al + fm + c + alk

si  = 100 × n(SiO2) / base
al、fm、c、alk 同樣化為佔 base 的 100 分額
ti  = 100 × n(TiO2) / base
p   = 100 × n(P2O5) / base
k   = n(K2O) / (n(Na2O) + n(K2O))
mg  = n(MgO) / (n(MgO) + n(FeO) + 2 n(Fe2O3) + n(MnO))
```

石英指數 `qz`：

```text
al > alk  時    qz = si − (100 + 4 al)
al ≤ alk  時    qz = si − (100 + 3 al + alk)
```

第二條用於鋁不超過鹼的樣品。軟體內「說明」視窗只列出了第一條。

`si`、`al`、`fm`、`c`、`alk`、`ti`、`p`、`qz` 保留 2 位小數，`k` 和 `mg` 保留 3 位小數。表格只放前一組裡的八欄；`ti` 和 `p` 在計算詳細資料中。`qz` 為正時，詳細資料裡會加上正號。

`al + fm + c + alk` 在表格中應為 100。`si` 可以遠大於 100，因為矽不在這個 100 分額裡面。`k`、`mg` 是 0 到 1 的比值。

## 診斷欄

| 欄 | 含義 |
| --- | --- |
| **矽飽和狀態** | 矽過飽和、矽飽和、矽不飽和 |
| **鋁飽和狀態** | 過鋁質、準鋁質、過鹼質 |
| **礦物總和** | Catanorm 陽離子百分比之和，保留 2 位小數 |

矽飽和狀態由最終礦物判定，閾值是 `0.001 cat%`：

- 有石英 `Q`：矽過飽和。
- 沒有石英，但有霞石 `Ne`、白榴石 `Lc`、鉀霞石 `Kp` 或橄欖石 `Ol`：矽不飽和。
- 其餘：矽飽和。

`qz` 的正負用來看矽相對於尼格里基數是過剩還是不足。表格裡的「矽飽和狀態」看的是標準礦物，兩欄可以對照，它們的判定基數不同。

鋁飽和狀態用歸一化後的陽離子判斷，發生在礦物分配之前：

- **過鋁質**：Al > Na + K + Ca
- **準鋁質**：Na + K < Al ≤ Na + K + Ca
- **過鹼質**：Al ≤ Na + K

## 標準礦物

礦物欄的單位是陽離子百分比。`Plag` 等於 `Ab + An`，總和 `Sum` 計入 `Plag`，不再把 `Ab` 和 `An` 加第二次。核對閉合程度時看 `Sum` 或診斷欄的礦物總和。

| 縮寫 | 礦物 | 縮寫 | 礦物 |
| --- | --- | --- | --- |
| `Q` | 石英 | `Hy` | 正輝石 |
| `C` | 剛玉 | `Ol` | 橄欖石 |
| `Or` | 正長石 | `Cs` | 矽鈣石 |
| `Plag` | 斜長石 | `Wo` | 矽灰石 |
| `Ab` | 鈉長石 | `Mt` | 磁鐵礦 |
| `An` | 鈣長石 | `Hm` | 赤鐵礦 |
| `Lc` | 白榴石 | `Il` | 鈦鐵礦 |
| `Ne` | 霞石 | `Tn` | 榍石 |
| `Kp` | 鉀霞石 | `Pf` | 鈣鈦礦 |
| `Ac` | 霓石 | `Ru` | 金紅石 |
| `Ns` | 偏矽酸鈉 | `Ap` | 磷灰石 |
| `Ks` | 偏矽酸鉀 | `Fr` | 螢石 |
| `Di` | 透輝石 | `Py` | 黃鐵礦 |
| | | `Cc` | 方解石 |

端元比例不單獨佔結果欄，全部寫在計算詳細資料裡。

## 計算詳細資料

選取成功列後，右側檢查器按六段顯示：

1. **岩石分類與飽和狀態**：矽飽和狀態、鋁飽和狀態、標準礦物總和。不飽和時矽飽和度醒目提示，過鹼質時鋁飽和度醒目提示。
2. **尼格里參數**：`si`、`al`、`fm`、`c`、`alk`、`ti`、`p`、`k`、`mg`、`qz`。
3. **礦物端元**，有對應礦物時才出現：
   - 斜長石 `An% = 100 × An / (Ab + An)`
   - 透輝石固定為 Wo 50%，其餘 50% 按鎂鐵比分成 En 與 Fs
   - 橄欖石 Fo、Fa；Fo 等於下面的鎂指數
   - 鎂指數 `Mgr = 100 × En / (En + Fs)`，在正輝石併入透輝石之前計算
4. **去矽反應歷程**：矽有餘時寫明石英的 cat%；矽虧損時逐步寫出消耗了哪一種礦物、虧損是否已經消除。
5. **主要標準礦物**：大於 `1 cat%` 的礦物，從高到低，不含重複的 `Plag`。大於 `10 cat%` 的項目醒目提示。
6. **警告**：目前實作在由 FeOT 估算鐵價態時寫入警告。

## 計算過程

### 1. 陽離子基數

每種氧化物先變成陽離子量：`(wt% / 莫耳質量) × 化學式中的陽離子數`。SiO₂、TiO₂、FeO、MnO、MgO、CaO、CO₂、F、S 的陽離子數是 1；Al₂O₃、Fe₂O₃、Na₂O、K₂O、P₂O₅ 是 2。

全部陽離子相加後縮放到 100，作為 Catanorm 的分配池。總和接近 0 時該列失敗，提示陽離子總和不足。這一步**不再**把氧化物 wt% 歸一化到 100；未填寫的 H₂O、燒失量不進入這個 100。

### 2. 副礦物與鹽類

Mn 先併入 Fe²⁺。隨後按陽離子計量：

| 順序 | 礦物 | 計量要點 |
| --- | --- | --- |
| 1 | 方解石 `Cc` | 礦物量 = `2 × CO2`，消耗等量 Ca |
| 2 | 磷灰石 `Ap` | P 相對 F 較少時，`Ap = 3P`，並消耗一部分 F；否則把剩餘 F 全部併入磷灰石 |
| 3 | 螢石 `Fr` | 剩餘 F：`Fr = 1.5 × F`，消耗 `0.5 × F` 的 Ca |
| 4 | 黃鐵礦 `Py` | `Py = 1.5 × S`，消耗 `0.5 × S` 的 Fe²⁺ |
| 5 | 鈦鐵礦 `Il` | Ti 與 Fe²⁺ 中較少的一方決定產量，礦物量是該量的 2 倍 |

CO₂、P、F、S 會優先佔用 Ca 或 Fe²⁺。這些揮發分明顯高於能結合的陽離子時，後面的鈣鎂礦物會失真，應用礦物總和和去矽記錄核對。

### 3. 長石、似長石前身與鈦礦物

分配單位是陽離子。正長石、鈉長石、鈣長石在端元充足時都是 5 個陽離子一組。

1. K 與 Al、Si 生成正長石 `Or`（每個 K 配 1 個 Al 和 3 個 Si）。剩餘 K 生成偏矽酸鉀 `Ks`。
2. Na 與 Al、Si 生成鈉長石 `Ab`。剩餘 Na 再與 Fe³⁺ 生成霓石 `Ac`（每個 Na 配 1 個 Fe³⁺ 和 2 個 Si）。仍剩餘的 Na 生成偏矽酸鈉 `Ns`。
3. 剩餘 Al 與 Ca 生成鈣長石 `An`。Ca 不足時按鋁限制，每個限制性 Al 對應 0.5 個 Ca 和 1 個 Si。
4. 剩餘 Ti 與 Ca、Si 生成榍石 `Tn`（3 個陽離子）。仍剩餘的 Ti 為金紅石 `Ru`。
5. 最後剩餘的 Al 為剛玉 `C`。

### 4. 鐵氧化物與輝石

Fe³⁺ 與 Fe²⁺ 生成磁鐵礦 `Mt`：Fe³⁺ 不超過二倍 Fe²⁺ 時，`Mt = 1.5 × Fe³⁺`。剩餘 Fe³⁺ 為赤鐵礦 `Hm`。

剩餘 Ca、Mg、Fe²⁺ 分別變成矽灰石 `Wo`、頑火輝石分子和鐵輝石分子，各為陽離子數的 2 倍，並消耗等量的一份 Si。頑火輝石與鐵輝石分子相加為正輝石 `Hy`。此時計算鎂指數。

`Wo` 與 `Hy` 再以等陽離子結合成透輝石 `Di`：量少的一方全部進入 `Di`，`Di` 的陽離子數是它的 2 倍；多的一方留下 `Wo` 或 `Hy`。

### 5. 石英或七步去矽

剩餘 Si ≥ 0 時，全部成為石英 `Q`，計算到此結束。

Si < 0 時，虧損 `D = −Si`。下面每一步要麼把虧損減到 0 並結束，要麼把該礦物用完後進入下一步。係數是陽離子百分比：

| 步 | 反應 | 每消除 1 份 Si 虧損 |
| --- | --- | --- |
| 1 | 正輝石 → 橄欖石 | 消耗 4 `Hy`，生成 3 `Ol` |
| 2 | 榍石 → 鈣鈦礦 | 消耗 3 `Tn`，生成 2 `Pf` |
| 3 | 鈉長石 → 霞石 | 消耗 2.5 `Ab`，生成 1.5 `Ne` |
| 4 | 正長石 → 白榴石 | 消耗 5 `Or`，生成 4 `Lc` |
| 5 | 白榴石 → 鉀霞石 | 消耗 4 `Lc`，生成 3 `Kp` |
| 6 | 矽灰石 → 矽鈣石 | 消耗 4 `Wo`，生成 3 `Cs` |
| 7 | 透輝石 → 矽鈣石 + 橄欖石 | 消耗 4 `Di`，各生成 1.5 `Cs` 和 1.5 `Ol` |

第 5 步的產物是 `Kp`。去矽完成後，斜長石 `Plag = Ab + An`，再按前文的規則判斷矽飽和狀態。

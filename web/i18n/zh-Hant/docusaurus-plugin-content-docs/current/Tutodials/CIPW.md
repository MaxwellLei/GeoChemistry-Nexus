# CIPW 標準礦物計算

**CIPW 標準礦物計算**把全岩主量元素氧化物（wt%）換算成一組理想化的標準礦物。結果用於火成岩對比、矽飽和度與鋁飽和度判別。CIPW Norm 由 Cross、Iddings、Pirsson 與 Washington 於 1902 年提出。本模組在類 Excel 表格中批次計算，並給出每一列的診斷與質量平衡。

## 介面

頁面由頂列和資料工作表組成。頂列左側是 **Fe³⁺/ΣFe**，右側是 **說明**、**範例**、**匯出**、**清空** 和 **執行計算**。

工作表從左到右分為四段，欄標題上方有分組名稱：

| 區域 | 分組 | 單位 | 作用 |
| --- | --- | --- | --- |
| 樣品 | — | — | 樣品名稱，只作標識，不參與計算。該欄凍結，水平捲動時保持可見 |
| 氧化物 | 主量元素；其他氧化物 / 揮發分 | wt% | 白色輸入區 |
| 診斷 | 診斷 | — | `SiO2 飽和度`、`Al2O3 狀態`、`質量平衡誤差(%)` |
| 標準礦物 | CIPW 標準礦物 | wt% | 淺色結果區。欄標題為縮寫加中文名，例如 `Q(石英)` |

輸入區與結果區之間有一條窄分隔欄。結果欄在計算前為空。表格最初提供 500 列。在填滿控點上按兩下可以像 Excel 一樣向下填滿。

### 頂列

| 控制項 | 作用 |
| --- | --- |
| **Fe³⁺/ΣFe** | 僅在使用全鐵 `FeOT` 時，按該比值拆分 FeO 與 Fe₂O₃。範圍 `0`–`1`，預設 `0.15`（Le Maitre, 2002），顯示兩位小數 |
| **說明** | 開啟軟體內的演算法說明 |
| **範例** | 填入三列範例：花崗岩、玄武岩、安山岩，並帶有實測 Fe₂O₃、FeO 與 MnO |
| **匯出** | 把目前表格存為 UTF-8 CSV，預設檔名 `CIPW_Results.csv` |
| **清空** | 確認後清除全部輸入、結果和計算詳細資料 |
| **執行計算** | 對所有含有效氧化物的列計算 |

### 列首狀態

列號旁的圓點表示該列狀態：

| 圓點 | 含義 |
| --- | --- |
| 灰色空心 | 已有輸入，尚未計算 |
| 青綠實心 | 計算成功，且沒有警告、質量平衡也通過 |
| 橙色實心 | 計算成功，但存在警告，或質量平衡誤差大於 `1×10⁻⁶` |
| 紅色實心 | 該列計算失敗。診斷欄寫有「錯誤」和原因 |
| 橙色空心 | 計算之後又改過氧化物，目前結果已過期 |

範例資料都含有 MnO。MnO 會併入 FeO 並產生警告，所以範例列計算後是橙色，這是預期結果。修改樣品名稱不會使結果過期；修改任一氧化物輸入會。

## 輸入

每一列是一個全岩樣品，填寫氧化物的質量百分比（wt%）。軟體只讀取**大於 0** 的儲存格，空白和 0 都視為未提供。空列自動略過。

可以從試算表軟體直接貼上。欄順序固定，貼上時按下面的欄標題對齊。

### 氧化物欄

主量元素：

`SiO2`、`TiO2`、`Al2O3`、`Fe2O3`、`FeO`、`FeOT`、`MnO`、`MgO`、`CaO`、`Na2O`、`K2O`、`P2O5`

其他氧化物 / 揮發分：

`ZrO2`、`Cr2O3`、`CO2`、`S`、`F`、`Cl`、`SO3`

`FeOT` 是以 FeO 當量表示的全鐵。`S`、`F`、`Cl` 按元素質量百分比填寫。

### 鐵的處理

| 填寫情況 | 處理 |
| --- | --- |
| 同時有 `FeO` 和 `Fe2O3`，沒有 `FeOT` | 使用實測配分，鐵處理模式為「實測值」 |
| 只有 `FeO` 或只有 `Fe2O3` | 缺的一項按 0，模式為「部分假設」，並給出警告 |
| 只有 `FeOT` | 按 Fe³⁺/ΣFe 拆分，模式為「從 FeOT 估算」 |
| `FeOT` 與 `FeO` 或 `Fe2O3` 同時出現 | 忽略 `FeOT`，模式為「輸入不一致」，並給出警告 |
| 沒有任何鐵資料 | FeO 與 Fe₂O₃ 都按 0，模式為「缺失」，並給出警告 |

僅有 `FeOT` 時的拆分是：

```text
Fe2O3 = FeOT × (Fe³⁺/ΣFe) × 1.11134
FeO   = FeOT × (1 − Fe³⁺/ΣFe)
```

係數 `1.11134` 對應 Fe₂O₃ 與兩倍 FeO 的莫耳質量比，用來把三價鐵從 FeO 當量換回 Fe₂O₃ 的質量百分比。

`MnO` 在計算前按莫耳質量比換成 FeO 當量，並加入 FeO：

```text
FeO 當量 = MnO × 71.844 / 70.937
```

只要填寫了 MnO，計算詳細資料裡就會出現「MnO 已按莫耳比轉換為 FeO 當量」。

## 輸出

### 診斷欄

| 欄 | 取值 |
| --- | --- |
| **SiO2 飽和度** | 過飽和、飽和、不飽和 |
| **Al2O3 狀態** | 過鹼性、準鋁質、過鋁質 |
| **質量平衡誤差(%)** | 礦物質量與輸入氧化物閉合的偏差。小於 `0.01` 時用科學記號，否則保留 4 位小數 |

三種飽和度的含義：

- **過飽和**：分配結束後仍有 SiO₂，記為石英 `Q`。
- **飽和**：SiO₂ 恰好用完，既無石英，也無需去矽。
- **不飽和**：SiO₂ 不足，進入下面的去矽反應。若整條反應鏈仍消不掉矽虧損，會追加警告，並說明殘餘虧損（mol/100 g）。這時的標準礦物不可靠。

鋁飽和狀態在長石分配之前，用當時剩餘的氧化物莫耳數判斷：

- **過鹼性**：Na₂O + K₂O > Al₂O₃
- **過鋁質**：Al₂O₃ / (CaO + Na₂O + K₂O) > 1
- **準鋁質**：其餘情況

磷灰石、方解石、螢石、石鹽和芒硝已經先消耗了相應的 CaO 或 Na₂O，所以這裡用的是剩餘量。

### 標準礦物

結果按下面的順序排列。中文名與軟體欄標題一致。

| 縮寫 | 礦物 | 縮寫 | 礦物 |
| --- | --- | --- | --- |
| `Q` | 石英 | `Fo` | 鎂橄欖石 |
| `Or` | 正長石 | `Fa` | 鐵橄欖石 |
| `Ab` | 鈉長石 | `Mt` | 磁鐵礦 |
| `An` | 鈣長石 | `Hm` | 赤鐵礦 |
| `Le` | 白榴石 | `Ilm` | 鈦鐵礦 |
| `Ne` | 霞石 | `Cm` | 鉻鐵礦 |
| `Kp` | 假白榴石 | `Ru` | 金紅石 |
| `Cor` | 剛玉 | `Tn` | 榍石 |
| `Ac` | 霓石 | `Pf` | 鈣鈦礦 |
| `Di` | 透輝石 | `Z` | 鋯石 |
| `Hd` | 鈣鐵輝石 | `Ap` | 磷灰石 |
| `Wo` | 矽灰石 | `Cc` | 方解石 |
| `Cs` | 斜矽鈣石 | `Py` | 黃鐵礦 |
| `En` | 頑火輝石 | `Fl` | 螢石 |
| `Fs` | 鐵輝石 | `Hl` | 石鹽 |
| `ns` | 偏矽酸鈉 | `Th` | 芒硝 |
| `ks` | 偏矽酸鉀 | | |

正長石、鈉長石和霓石在內部按化學式單位計數：1 mol K₂O 生成 2 mol `Or`，1 mol Na₂O 生成 2 mol `Ab` 或 `Ac`。寫出的始終是質量百分比。

## 計算詳細資料

選取已成功計算的列後，右側檢查器顯示：

- 樣品名稱。樣品欄為空時顯示「第 N 列」。
- 矽飽和度與鋁飽和度。不飽和時矽飽和度醒目提示。
- **鐵處理模式**。只要不是「實測值」就醒目提示。
- **質量平衡誤差**，保留 6 位小數。超過 `1×10⁻⁶` 時醒目提示。
- **礦物總量**，即各標準礦物 wt% 之和，保留 4 位小數。黃鐵礦、螢石、石鹽形成時釋出的氧不計入這個總量，但會計入質量平衡。
- **主要礦物**：含量大於 `0.01 wt%` 的礦物，從高到低排列；大於 `10 wt%` 的項目醒目提示。
- **警告**：鐵資料缺失或不一致、由 FeOT 估算、MnO 換算、殘餘矽虧損等。

檢查器右上角可以把這一份詳細資料匯出為 CSV，或複製到剪貼簿。

## 計算過程

下面按目前計算程式碼的實際順序說明。磷灰石最先佔用鈣，然後才形成揮發分礦物；榍石和金紅石放在鈣長石之後。

礦物莫耳質量全部由氧化物莫耳質量按化學式推導，避免手工取整造成質量不平衡。計算使用的數值容差是 `1×10⁻¹²`。任一步使 SiO₂ 以外的氧化物變為明顯負值時，該列失敗。

### 1. 無水歸一化與鐵、錳

把所有已提供且非負的氧化物歸一化到 100%。按上一節處理鐵，再把 MnO 換成 FeO 當量，然後**再歸一化一次**。總量不大於 0 時該列失敗。

### 2. 換成莫耳數

每種氧化物的莫耳數 = 歸一化後的 wt% / 莫耳質量。隨後的分配都在 mol/100 g 尺度上進行。

### 3. 磷灰石

磷灰石最先佔用鈣。1 mol `P2O5` 結合 `10/3` mol `CaO`（不含 OH 或 F）：

```text
Ap = min(P2O5, CaO / (10/3))
```

### 4. 揮發分礦物

按下面的順序，能結合多少就生成多少：

| 礦物 | 計量 |
| --- | --- |
| 方解石 `Cc` | `min(CO2, CaO)` |
| 螢石 `Fl` | `min(F/2, CaO)`，即 1 mol CaO 結合 2 mol F |
| 黃鐵礦 `Py` | `min(S/2, FeO)`，即 1 mol FeO 結合 2 mol S |
| 石鹽 `Hl` | `min(Cl, 2×Na2O)` |
| 芒硝 `Th` | `min(SO3, Na2O)` |

### 5. 鋯石、鉻鐵礦、鈦鐵礦

- 鋯石 `Z`：全部 `ZrO2` 與等量 `SiO2`。
- 鉻鐵礦 `Cm`：`min(Cr2O3, FeO)`。
- 鈦鐵礦 `Ilm`：`min(TiO2, FeO)`。

這一步只用掉能和 FeO 結合的鈦。剩餘 TiO₂ 留到鈣長石之後。

### 6. 長石、剛玉與剩餘鹼

先記錄鋁飽和狀態，再分配：

| 礦物 | 條件與產物 |
| --- | --- |
| 正長石 `Or` | `min(K2O, Al2O3)`，消耗 6 倍 SiO₂，產物莫耳數為該值的 2 倍 |
| 鈉長石 `Ab` | `min(Na2O, Al2O3)`，同樣消耗 6 倍 SiO₂，產物為 2 倍 |
| 鈣長石 `An` | `min(CaO, Al2O3)`，消耗 2 倍 SiO₂ |
| 剛玉 `Cor` | 剩餘 Al₂O₃ |
| 霓石 `Ac` | `min(剩餘 Na2O, Fe2O3)`，消耗 4 倍 SiO₂，產物為 2 倍 |
| 偏矽酸鈉 `ns` | 剩餘 Na₂O 與等量 SiO₂ |
| 偏矽酸鉀 `ks` | 剩餘 K₂O 與等量 SiO₂ |

長石階段允許 SiO₂ 先記成負值，留給後面的去矽統一處理。

### 7. 榍石與金紅石

榍石只用鈣長石之後剩下的 CaO，並且**不用當時的 SiO₂ 餘量來限制榍石**：

```text
Tn = min(剩餘 TiO2, 剩餘 CaO)
```

`Tn` 同時消耗等量 SiO₂。最後仍剩下的 TiO₂ 記為金紅石 `Ru`。

### 8. 鐵氧化物

```text
Mt = min(Fe2O3, FeO)
Hm = 剩餘 Fe2O3
```

### 9. 輝石與矽灰石

設 `MgFe = MgO + FeO`。單斜輝石總量為 `min(CaO, MgFe)`，再按鎂鐵比拆成透輝石 `Di` 和鈣鐵輝石 `Hd`，每份輝石消耗 2 份 SiO₂。

剩餘的 MgO、FeO 全部成為頑火輝石 `En` 和鐵輝石 `Fs`，各消耗 1 份 SiO₂。鎂和鐵都用完之後，若還有 CaO，則全部成為矽灰石 `Wo`。

### 10. 矽飽和度與去矽

去矽順序為：紫蘇輝石 → 榍石 → 鈉長石 → 正長石 → 矽灰石 → 透輝石/鈣鐵輝石 → 白榴石。每一步只消耗當時還缺的 SiO₂。

| 順序 | 反應 | 釋出的 SiO₂ |
| --- | --- | --- |
| 1 | 2 頑火輝石/鐵輝石 → 1 鎂橄欖石/鐵橄欖石 | 每 2 mol 輝石釋出 1 mol |
| 2 | 榍石 `Tn` → 鈣鈦礦 `Pf` | 1 mol `Tn` 釋出 1 mol |
| 3 | 鈉長石 `Ab` → 霞石 `Ne` | 1 mol `Ab` 釋出 2 mol |
| 4 | 正長石 `Or` → 白榴石 `Le` | 1 mol `Or` 釋出 1 mol |
| 5 | 2 矽灰石 `Wo` → 1 斜矽鈣石 `Cs` | 每 2 mol `Wo` 釋出 1 mol |
| 6 | 透輝石/鈣鐵輝石 → 斜矽鈣石 + 橄欖石 | 1 mol 輝石釋出 1 mol；鎂進入 `Fo`，鐵進入 `Fa` |
| 7 | 白榴石 `Le` → 假白榴石 `Kp` | 1 mol `Le` 釋出 1 mol |

SiO₂ 有剩餘時生成石英，狀態為過飽和。SiO₂ 恰好為零時為飽和。進入上表則為不飽和。

### 11. 質量百分比與質量平衡

標準礦物質量 = 莫耳數 × 由化學式推導的莫耳質量，再相對於歸一化後的氧化物總量換成 wt%。

黃鐵礦、螢石和石鹽裡的 S、F、Cl 置換了氧化物中的氧。釋出的氧不進入任何礦物，質量平衡時加回去：

```text
釋出氧的莫耳數 = Fl + Py + Hl / 2
質量平衡誤差 = |100 − (礦物 wt% 之和 + 釋出氧的 wt%)|
```

誤差大於 `1×10⁻⁶` 時，該列記為警告。

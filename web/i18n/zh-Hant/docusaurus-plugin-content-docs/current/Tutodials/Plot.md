# 圖解

在圖解模組，我們將整合更多基礎地球科學圖解範本，包括但不限於：構造環境判別圖、岩石分類圖等。**我們的最終目標是為地球科學建立一個全面的圖框－繪圖工具包，為研究人員提供最大的便利。** 🧪

:::info

如果您是從事地質圖解等相關領域研究的科研人員，並希望推廣自己的圖解成果，歡迎與我們聯絡！我們將助力您的圖解成果觸及更廣泛的科研群體，進一步提升學術成果的傳播效率與影響力。

:::

## 快速開始

我們的軟體圖解模組主要由兩部分組成：圖解範本庫和圖解操作介面。您可首先在圖解範本庫中選擇所需的圖解類型，隨後進入相應的操作介面，完成資料輸入、圖解處理及結果匯出等操作。

### 範本庫

我們將圖解模組分為三大類：**線上雲端範本**、**我的範本**和**工具圖解範本**。

**線上雲端範本**：由我們持續更新和維護。您無需更新軟體，在連線情況下，即可取得更新的圖解範本，確保始終擁有最全面和權威的範本資源。

**我的範本**：適用於需要針對特定研究需求建立自訂範本的情境。您不僅可以自己建立這些範本，還可以將其匯出以便與其他研究人員輕鬆分享，促進學術交流和傳播。

> *未來，我們計畫建立一個專門的圖解範本社群，使用者可以輕鬆建立、上傳、分享和下載各種 **個人自訂範本**，進一步增強系統的靈活性和可擴充性。*

**工具圖解範本**：將固定的常規圖解單獨獨立出來，目前包含：**稀土元素蛛網圖、微量元素蛛網圖、哈克多聯圖解**，以及常規的二維和三元散佈圖。

#### 介面

預設情況下，繪圖模組進入時顯示內建地球科學範本庫。介面分為三個主要部分：

*   **左側 － 圖解分類**：顯示所有範本層級和相應的範本，包括自訂範本清單。
*   **右側 － 圖解卡片**：顯示目前層級下的圖解卡片，包括名稱和預覽影像。
*   **頂端 － 導覽列**：軟體採用無框設計，所以頂端的導覽列承接了每個頁面的部分功能。在圖解介面，頂端導覽列會顯示目前圖解範本路徑，以及圖解範本搜尋等功能。

![graphical_interface](/img/v0.9.0/en-US/graphical_interface.webp)

選擇合適的圖解範本，點選圖解範本卡片即可進入圖解操作介面。對於圖解範本卡片，你也可以按右鍵進行匯出、刪除、收藏等更多操作。

:::tip

可以透過按下右側 <kbd>Alt</kbd> 按鍵來對圖解範本進行快速刪除／收藏。

:::

#### 頂端功能表列

頂端 **檔案** 功能表包含：

1.  **新增圖解**：用於建立自訂圖解範本。
2.  **開啟圖解**：用於暫時開啟圖解範本；僅支援 `.diag.zip` 檔案。
3.  **匯入圖解**：用於將外部圖解範本套件（`.diag.zip`）匯入本機我的範本清單。

### 圖解操作介面

#### 介面

圖解介面分為五個主要部分：

-   **工具列**：包括快速按鈕和三個功能索引標籤：繪圖、資料和編輯。
-   **圖層清單（物件）**：範本上的繪圖元素清單。點選元素允許你修改其屬性。
-   **繪圖畫布**：用於查看圖表、匯入資料、視覺設定和查看範本說明的中心區域。
-   **狀態列**：顯示基本繪圖資訊，包括目前圖表語言和座標資訊。
-   **屬性面板**：顯示所選繪圖元素（如顏色、大小）的屬性，以實現所需的視覺效果。

![graphical_operation_interface](/img/v0.9.0/en-US/graphical_operation_interface.webp)

#### 圖解工具列

工具列由一系列 **快速按鈕** 組成。主要是：

1. 返回圖解範本庫
2. 切換操作狀態（圖解模式、資料模式、編輯模式）
3. 圖解各種屬性面板和操作工具等

詳細功能參見下圖。

![graphical_toolbar](/img/v0.9.0/en-US/graphical_toolbar.webp)

### 圖層清單

繪圖元素分為 7 大類：

-   **Line (線條)**：定義基本的圖解邊界或線段。
-   **Text (文字)**：標籤和註解。
-   **Polygon (多邊形)**：圖表內的封閉形狀。
-   **Arrow (箭頭)**：定向繪圖物件。
-   **Function (函數)**：允許使用者輸入自訂數學函數和定義域。
-   **Axes (座標軸)**：圖表的座標軸。
-   **Data Point (資料點)**：代表匯入資料的元素。

**預設繪製順序（從上到下）：`資料點 > 文字 > 箭頭 > 函數 > 線條 > 多邊形 > 座標軸`**。

![tutorial_plot5](/img/v0.9.0/en-US/diagrammatic_object_selection_example.webp)

當您在圖層面板中選取一個元素時，它將在畫布上醒目顯示，而其他元素變為半透明以減少干擾。屬性面板隨後將顯示該元素的相關屬性。 🔍

您可以修改這些屬性以達到您想要的視覺風格。

:::tip

要取消選取所有元素，只需 **在畫布上的任意位置按一下右鍵** 或使用工具列上的 **取消選取** 按鈕。

:::

## 使用範例

### 範例

1. 從 **圖解範本庫** 中選擇一個圖解範本進入圖解操作頁面。例如：選擇 TAS 圖解。
2. 當我們需要輸入資料的時候，需要從圖解模式切換到資料模式。
   
   ![tutorial_plot6](/img/v0.9.0/en-US/diagram_data_input.webp)


對於 TAS 圖解，必須要輸入的是四欄資料：`Category`、`SiO2`、`K2O` 和 `Na2O`。其中 `Category` 標題欄用於對資料進行分組並產生圖例；`Sample` 欄用於標識資料樣本標籤，不會參與任何計算（可以為空）；其他元素的單位是 `wt.%`。而當然，如果你不清楚這個圖解到底輸入的資料是什麼、什麼單位、圖解怎麼用等，可以點選圖解區域右上角的圖解說明按鈕查看關於該圖解的說明文件。

3. 了解需求後，輸入你的資料，點選資料面板右上角的投點按鈕以繪製資料點。如果資料輸入有問題，在修改資料後，重新點選投點即可。![tutorial_plot8](/img/v0.9.0/en-US/data_plotting.webp)
4. **匯出圖解**。我們提供了一個 **將圖解投圖結果快速複製到剪貼簿的功能按鈕**。還有一個 **正式匯出功能**。在正式匯出面板中，我們支援匯出圖片格式為 `jpg`、`png`、`bmp`、`svg`。在科研繪圖需要向量圖的情況下，我們建議使用 `svg` 格式。同時我們也支援 **直接將結果連動到第三方繪圖軟體中**，無需經過匯出再匯入這一中間步驟。第三方軟體內建建議的是：**CorelDRAW、Inkscape、Adobe Illustrator**。我們建議使用 Inkscape 連動進行後期二次科研修圖會更佳。當然我們也支援自訂一個其他第三方繪圖軟體，前提是該軟體支援 `svg` 向量圖格式。研究人員只需在設定中指定繪圖軟體程式路徑即可。
   ![tutorial_plot8](/img/v0.9.0/en-US/export_diagram.webp)

### 補充說明

圖解範本本身支援多語言切換，即：一份圖解可以切換成多種語言版本，以滿足國際化需要。

例如：在中國期刊發表論文的圖解需要使用中文語言版本，在英文 SCI/IE 等期刊上發表需要使用英文版本的圖解。你可以透過點選圖解工具列右上角的圖解語言，一鍵切換對應語言版本的圖解。

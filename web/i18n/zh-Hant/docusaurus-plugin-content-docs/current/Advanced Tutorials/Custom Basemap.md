# 製作圖解範本

對於線上圖解範本庫中尚未收錄的圖解範本，您可以選擇製作一個自訂圖解範本。透過自訂範本並將其打包成範本套件，你可以快速與其他研究人員分享。

你也可以選擇將你的範本提供給開發者以收錄到線上圖解範本庫中。我們衷心感謝任何參與者的貢獻。

## 快速建立

對於新的自訂圖表範本，主要有三個部分需要設定：

1.  **預設支援語言**：你可以從右側的選取方塊中選擇內建的語言快速選項。我們提供：簡體中文、繁體中文、美式英語、日語、俄語、韓語、德語等十種語言。

    > 需要說明的是：預設語言的作用是，在其他語言未翻譯或遇到錯誤時，作為所回退到的語言。另外，在新版中，現在我們不再允許使用者自訂語言代碼。如果您需要支援您的語言，請聯絡開發者。

2.  **圖解範本分類（層級）**：我們提供內建的快速分類結構。此設定影響你的範本在圖表範本清單中的層級位置。

3.  **圖表範本類型**：目前支援兩種類型：**二維座標系** 和 三元圖。

完成設定後，點選【確定】進入自訂繪圖介面。接下來，我們將操作重心放在【編輯】功能列上。點選【編輯】後，系統將顯示再次確認對話方塊以編輯圖表。確認後，你將進入編輯模式，在這裡可以查看和使用編輯功能列中的各種工具。

## 繪製圖解

在編輯模式下，允許進行以下操作：

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/graphical_toolbar.webp')}
    alt="繪製圖解"
    style={{width: '100%'}}
  />
</div>

* **儲存**：儲存圖表範本。點選後，程式預設會根據目前繪圖狀態產生相應的縮圖。
* **另存新檔**：將圖表範本儲存到不同的檔案位置。
* **新增線條**：啟用後，進入「新增線條」模式。點選繪圖區域的第一個點開始畫線，點選第二個點完成線條物件。
* **新增文字**：也稱為註解。啟用後，進入「新增文字」模式。點選繪圖中的特定位置即可建立。預設文字為 `Text`。你可以透過圖層面板中的屬性部分修改位置或內容。
* **新增多邊形**：啟用後，進入「新增多邊形」模式。透過連續按左鍵建立頂點來新增封閉多邊形，按右鍵閉合形狀。
* **新增箭頭**：啟用後，進入「新增箭頭」模式。新增過程類似於建立線條。
* **新增函數**：點選後，新增一個預設函數 `sin(x)`，定義域範圍為 [-10, 10]。你可以在屬性面板中自訂公式。
* **復原／重做**：如果沒有建立或刪除繪圖物件，這些功能將被停用。預設情況下，歷程記錄中僅儲存最後 10 次操作。
* **刪除**：刪除繪圖物件。首先選取物件（例如文字），然後點選刪除將其移除。

### 新增函數

新增函數和前面的物件不同，**點選新增函數按鈕後，會立即新增一個預設的函數物件**。其中，預設函數是 `sin(x)`。您可以在屬性面板中修改函數公式來定義您的函數。

對於函數物件的屬性，兩個最重要的參數是：**定義域** 和 **取樣點**。

* **定義域定義了函數在畫布中的顯示範圍**。
* **取樣點控制函數在畫布中的繪製精度**，進而影響滑鼠捕捉選取演算法的準確性。預設值為 `1000`。精度越高，函數渲染越精細，但是也會帶來程式的渲染負擔。

## 完善圖解範本

完成基本圖形繪製後，一個完整的範本還需要：

1.  **資料與指令碼**：用來定義圖解範本的輸入資料和資料計算演算法，即指示資料如何計算並完成投圖。
2.  **圖解文件**：用來說明該圖解的說明文件內容。
3.  **多語言**：如果圖解範本設定為兩種以上的語言，則需對多語言部分進行翻譯。包括上一個的【圖解文件】以及圖解畫布中的文字物件等內容。

對於圖解範本的完善，儘管可以在圖解操作介面中完成，但是我們還是建議您在圖解的編輯視窗中進行將會更加便捷。

### 資料與指令碼

資料與指令碼是圖解範本的關鍵部分，因為它定義了圖解中資料是如何計算並最終呈現在圖上的。

它需要兩個參數：圖解範本的 **變數參數** 和 **計算演算法（指令碼）**，如下所示：

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/diagram_data_and_script.webp')}
    alt="圖解－資料與指令碼"
    style={{width: '100%'}}
  />
</div>

對於圖解範本的 **變數參數**，你可以在頂端新增對應的欄，來表示該圖解需要的輸入欄。其中含有兩個可選參數

1. Unit 表示輸入欄的單位，僅作展示說明，並不會影響資料演算法。
2. Group 表示輸入欄的分組，僅作展示說明，並不會影響資料演算法。

需要說明的是，**您在資料表格中定義的欄標題，將會被預設為下面指令碼可以直接呼叫的已註冊變數**。這就意味著，您不需要在指令碼中重複定義輸入欄的變數。

對於 **計算演算法（指令碼）**，預設使用 `JavaScript` 語言編寫。預設的指令碼範例內容為 `return [X,Y]`，即將資料表格中定義的輸入欄 `X` 和 `Y` 傳回給二維座標軸。

例如，對於 TAS 圖，參數應為：`SiO2, Na2O, K2O`。指令碼內容將是：

```javascript
// 使用變數 K2O + Na2O 計算
var result1 = K2O + Na2O;
// 使用 SiO2
var result2 = SiO2;
// 傳回兩個計算值。注意，對於預設的二維座標圖像，只有兩個傳回值。
// 第一個位置代表 X 傳回值，第二個代表 Y 傳回值。
return [result2, result1]
```

或者，你可以將指令碼編寫如下：

```javascript
var result = K2O + Na2O
return [SiO2, result]
```

請注意傳回值的位置是固定的。在 `[x, y]` 中，第一個值始終是 X（底軸），第二個是 Y（左軸）。

:::info

對於三元圖，最終傳回格式為 `[A, B, C]`，其中第一個值是 A（底軸），第二個是 B（左軸），第三個是 C（右軸）。

:::

### 圖解文件

圖解文件是幫助其他研究人員快速了解該圖解基本資訊和用法的必要步驟。

在說明文件頁面進行圖解文件的編寫。我們提供簡單的工具列功能以滿足一般文件需求。當然，您也可以在 `Office Word` 中編寫文件內容，然後將內容貼在這裡，它們的絕大部分格式都是通用適配的。

<div className="text--center">
  <img
    src={useBaseUrl('/img/v0.9.0/en-US/diagram_help_document.webp')}
    alt="圖解－說明文件"
    style={{width: '100%'}}
  />
</div>

對於圖解文件的編寫格式，我們建議遵循以下標準：

*   **簡介**：解釋圖解範本的基本概念和功能，幫助使用者快速理解。
*   **資料格式**：指定有效讀取資料所需的輸入資料格式和欄標題。
*   **參考文獻**：列出用於建立圖解範本及其內容的參考文獻。
*   **貢獻者**：參與圖解範本製作的人員名稱。甚至鼓勵你包含您的個人網站。

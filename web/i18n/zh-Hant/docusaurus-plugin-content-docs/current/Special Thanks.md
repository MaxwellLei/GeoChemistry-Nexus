# 🙏 特別感謝

## 貢獻者

感謝每一位透過 GitHub Issue、討論區或電子郵件參與本項目的人，包括但不限於：

* 回報 bug、提出功能建議
* 貢獻程式碼、測試與文件
* 分享或共同建立判別圖解、溫壓計等範本

* 參與多語言在地化等等
